## 2.1 接入模型服务商(Provider)

Hope Agent 通过「**服务商 + API Key**」接入各家大模型。内置**约 50 个服务商模板、数百个预设模型**,也支持自定义任意 OpenAI 兼容或 Anthropic 端点。模板会随版本增删,以添加服务商时的实际列表为准。

Fireworks 新建模板已移除退役的 GLM 5.2 Fast 和 Kimi K2.6 Turbo/Fast。既有连接与专属部署仍保留原设置；如使用已退役的无服务器型号，请按服务商当前可用型号自行选择替代。

MiniMax 新建模板仅推荐 M3，移除 M2.5、M2.7 和 M2.7 Highspeed。厂商公告：2026-10-19 起这些型号不再对新用户开放；既有按量付费用户可用至 2026-11-18 退役，M Plan / Token Plan 请求则从 10-19 起由厂商转向 M3.1 Flash Preview。Hope 保留已保存的型号、端点、价格与回退选择；请按自己的套餐核对迁移，套餐限定的 Preview 未加入通用模板。

模板与模型补全现在提供 **Claude Haiku 5.5**、**Grok 4.7**、**MiniMax M3**，以及 Fireworks 的 **DeepSeek V4.1 Flash、GLM 5.3、GLM 5.3 Flash**。Haiku 5.5 支持百万上下文与 128K 输出，使用自适应思考，支持关闭思考；温度不随请求发送。Grok 4.7 使用 OpenAI Chat 兼容接口，支持图片、500K 上下文、64K 输出预设及最高 `xhigh` 推理档，厂商不支持关闭思考。Fireworks 三个新预设沿用 Chat 接口，输出上限保守设为官方示例的 131,072 tokens；专属部署的实际限制须另核对。

Haiku 5.5 的模板基础价为每百万输入/输出 $0.10/$0.50，输入超过 100,000 tokens 时为 $0.50/$2.50；Grok 4.7 基础价为 $2/$6，输入超过 200K 时为 $4/$12。模板和大盘只存一组基础单价，未自动计算这些阶梯、缓存或区域附加价，不能当作实际账单。xAI 新建模板已清理五个明确退役的旧 ID，既有配置仍可编辑；旧 ID 可能按替代模型计费，迁移前请核对厂商报价。

MiniMax M3 使用原有 Anthropic 兼容连接，支持图片、百万上下文与思考开关；输出预设为官方推荐的 131,072 tokens。基础输入/输出价为每百万 $0.30/$1.20，超过 512K 输入时为 $0.60/$2.40。它只有思考开关，档位不改变思考深度；视频上传和 M3.1 Flash Preview 未作为预设能力加入。新模板移除该兼容接口未声明支持的 VL-01，旧配置仍可编辑。

Google 直连新建模板已移除弃用并转向新型号的 Gemini 3.7 / 3.5 Flash，以及仅限过去使用过的用户访问的 Gemini 2.5 系列。可选择稳定版 Gemini 3.8 Flash 或 3.6 Flash；既有连接和其他网关候选保留。

Google 模板现提供 GA 稳定型号 `gemini-4-argon`。Hope 通过 Gemini 的 OpenAI Chat 兼容端点使用它，声明文本和图片输入、1,048,576 个统一输入/输出上下文令牌、同步输出上限 65,536，并支持函数调用与流式响应。推理档位按官方兼容规则映射为 `low / medium / high`；`minimal` 映射到 `low`，`xhigh` 和 `max` 映射到 `high`。未设置或显式关闭推理参数时会省略该字段，由 Google 默认使用 `medium`，这不会关闭模型思考。Hope 不调用 Interactions API 的后台长输出，因此不会使用超过 65,536 的 long decode，也不声明音频、视频或 PDF 输入能力。

Gemini 4 Argon 标准付费价目前为每百万输入/输出令牌 $2/$10，至 2026-11-30；2026-12-01 起为 $4/$20。该模型不向 Free tier 或 Google AI Pro 计划开放。模板和大盘只记录当前基础价，缓存折扣、其他推理档位费用及实际账单需以 Google 账户为准。[型号与限制](https://ai.google.dev/gemini-api/docs/models/gemini-4-argon)、[OpenAI 兼容参数](https://ai.google.dev/gemini-api/docs/openai)、[价格](https://ai.google.dev/gemini-api/docs/pricing)。

**入口**:设置 → **模型配置** → **服务商** 标签页 → 点右上角「**添加服务商**」。

添加向导首页提供五条路径:

1. **用 ChatGPT 登录(Codex)**——顶部主按钮,用账号登录而非 API Key,详见 [2.4](#24-用-chatgpt--codex-账号登录)。
2. **连接远程服务器**——连到一台已经跑着 Hope Agent 服务的机器,复用它的配置,见 [01 · 从手机或另一台电脑访问](01-快速上手.md#14-从手机或另一台电脑访问)。
3. **本地模型助手**——未装 Ollama 时出现,一键安装本地模型,详见 [2.9](#29-本地模型一键安装)。
4. **选择内置模板**——可搜索的服务商网格,已配置的会打绿色「已配置」角标。
5. **自定义服务商**——接入任意兼容端点。

### 用内置模板(推荐)

点一个模板(如 Anthropic、OpenAI、DeepSeek、通义千问),进入配置页填 **API Key**(部分本地 / 无鉴权端点的 Key 标注为「可选」),可点「测试连接」验证,再「完成」保存。模板已经帮你预填好了端点地址、API 类型、思考风格和模型列表,通常不用改。

新增服务商后,系统会自动把它的第一个模型设为当前默认模型,你可以立刻开始对话。

> **DeepSeek 视觉模型**:新建 DeepSeek 直连服务商时可直接选择 **DeepSeek V4.1 Flash**。它支持图片输入、百万级上下文和推理。已有 DeepSeek 配置不会被自动改写;需要时可手动添加模型 ID `deepseek-flash`,或重新创建连接。

连接测试和实际模型请求不会自动跟随端点重定向。如果测试提示“端点返回重定向”，请向服务商确认最终 API 地址后更新 Base URL；系统不会把密钥或请求内容自动转发到重定向目标，也不会把这种响应显示为连接成功。

### 自定义服务商

如果你的服务商没有现成模板,选「自定义服务商」走三步向导:

1. 选 **API 类型**(Anthropic / OpenAI Chat / OpenAI Responses,见 [2.3](#23-四种-api-类型));不确定就选 **OpenAI Chat**,兼容性最好。
2. 填服务商名、**Base URL**、API Key(可选)、思考风格和计价货币(USD / CNY),可测试连接。
3. 添加模型:在模型 ID 中输入模型名、ID 或服务商名,即可检索所有内置模板的模型。选择候选后自动填入 ID、显示名、输入类型、上下文窗口、最大输出和推理能力,仍可手动修改;上下方向键选择,回车确认,Esc 关闭候选。

新增和编辑模型都支持上述补全,不会替换你当前中转站的地址、API 类型、密钥或推理参数格式。如果目录有同币种报价且与当前价格不同,会显示来源和单价,由你选择保留当前价格或使用目录价格;不同币种不会直接覆盖。模型 ID 不会被系统自动纠错或改成首字母大写；输入完整 ID 时，大小写完全匹配的候选优先显示。

> 候选来自内置模板,不是对中转站实际可用模型的在线探测。同名模型在不同服务商的上下文限制可能不同,请核对候选来源,并以你的服务商支持的 ID、能力和实际报价为准。

在向导的模型步骤或服务商编辑页，点「**发现模型**」可查询当前端点的在线模型列表。先勾选要新增的模型，填写上下文与最大输出令牌上限，并确认它们支持文本对话和工具调用；列表不会自动全选。已有模型不重复加入，也不覆盖原配置。确认后仍需保存服务商才会生效；新条目默认纯文本且关闭推理，能力与价格可在保存前编辑。

如果 Base URL 指向本机或局域网，在新增向导的连接步骤显式开启「允许私网访问」后再发现；该选项默认关闭，会随服务商保存，发现不会自行放宽网络策略。

发现只读取模型列表，不发送测试对话，也不证明模型可用于聊天。接口不支持、权限不足或网络策略阻止时可继续手动添加；列表不完整时会提示。本版只提取 ID 和显示名，不根据名称推断用途、令牌上限或价格。ChatGPT OAuth 服务商沿用原有目录，不使用此入口。

### 服务商的常用设置

在服务商列表里可以拖拽排序、启用 / 禁用、编辑、删除(右侧「⋮」菜单)。编辑页里还有这些字段:

| 设置项 | 默认值 | 作用 |
| --- | --- | --- |
| 计价货币 | 美元(USD) | 模型单价的币种(USD / CNY),只影响成本统计的换算;内置的通义 / 火山 / 腾讯等已标为人民币 |
| 允许访问私有网络 | 关 | 仅当 Base URL 是内网地址(如本地 Ollama / LM Studio)时出现;开启后放行 localhost,并把该主机加入安全白名单 |
| User-Agent | `claude-code/0.1.0` | 请求头里的 UA,一般不用改 |
| 思考风格 | 模板值 | 决定推理参数怎么发,见 [2.6](#26-温度与思考强度) |
| 模型列表 | 模板预设 | 每个模型可配 ID、显示名、输入类型、上下文窗口、最大输出、是否推理、单价 |

> **关于 API Key 的安全**:桌面 GUI 属于本机可信环境,Key 字段是带「眼睛」图标的密码框,可以本地明文查看,编辑时留空表示保留原有 Key。**但 Provider 列表与 API Key 不能通过对话让 AI 修改**——这是刻意的安全设计,AI 读取时看到的是打码后的值。详见 [13 · 设置与安全](13-设置与安全.md)。

## 2.2 一把服务商配多把 API Key(自动轮换)

给同一个服务商挂多把 API Key,某把限流或失效时会**自动切到下一把**,让用量更均衡、更抗限流。

**入口**:**编辑已有服务商**页里的「认证配置 / Auth Profiles」区块。注意——初次接入向导只填单把 Key,多把 Key 需要保存后再回来编辑该服务商添加。

每条 Key 配置包含:标签名(便于区分)、API Key、启用开关,以及可选的独立 Base URL。

**Anthropic 多工作区密钥**：在对应密钥条目打开“多工作区密钥”，填写以 `wrkspc_` 开头的工作区 ID。开启后未填写有效 ID 将无法保存或发送。此功能用于 Anthropic 官方 HTTPS 端点；限定在单个工作区的旧密钥保持关闭。不同工作区请分开创建服务商，自动轮换仅在声明相同工作区的密钥之间进行。该绑定和 API Key 一样只能在设置界面修改。


**它怎么工作**:遇到限流、过载、鉴权、计费类错误会自动换 Key,并给失败的 Key 一段冷却时间;网络超时这类「换了也没用」的错误则只重试同一把。同一个会话会尽量「黏」在同一把 Key 上,以便命中模型的 prompt 缓存、省成本。

> 用 ChatGPT / Codex 账号登录的服务商不参与 Key 轮换(它没有可轮换的 Key),见 [2.4](#24-用-chatgpt--codex-账号登录)。

## 2.3 四种 API 类型

API 类型告诉 Hope Agent 用哪套协议和服务商通信。**用内置模板时它已经预填好,你不用关心**;只有自定义端点时才需要按服务商文档选对。

| 类型 | 说明 | 什么时候用 |
| --- | --- | --- |
| **OpenAI Chat** | 最通用的 `/v1/chat/completions` 协议 | 绝大多数第三方 / 国内 / 聚合服务商(DeepSeek、通义、智谱、Moonshot、火山、OpenRouter、本地 Ollama 等)。**自定义时的首选** |
| **Anthropic** | Claude 官方的 Messages API | Anthropic 及采用其协议的服务 |
| **OpenAI Responses** | OpenAI 的新协议 `/v1/responses` | OpenAI 官方(默认)、GitHub Copilot |
| **Codex** | 用 ChatGPT 账号登录,而非 API Key | 见 [2.4](#24-用-chatgpt--codex-账号登录);**不能手动选,只能通过登录产生** |

跨协议自动切换模型时(比如主模型失败降级到另一家),系统会自动做消息格式转换,你无需关心。

---

聚合渠道也提供当前稳定模型：OpenRouter 新增 GPT-6 四项、Claude Opus / Sonnet / Haiku 5.5、Grok 4.7、GLM 5.3 / Flash、DeepSeek V4.1 Flash、MiniMax M3 和 Kimi K3。价格按公开目录的基础路由报价估算，实际账单可能受路由、缓存与长输入分档影响；模型允许的文件或视频输入不代表 Hope 已支持。

Together 新增 GLM 5.3 / Flash、Kimi K3、MiniMax M3 和 DeepSeek V4.1 Flash，采用渠道公布的上下文与单价、保守 **16K 输出预设**（不是厂商硬上限）。当前只声明文本输入；沿用渠道默认推理，不发送仅适用于 GPT-OSS 的 `reasoning_effort`，未接入 Together 的推理开关。

MiniMax M3 未设置思考强度时保留官方默认关闭，选择强度才启用自适应思考，明确关闭则发送关闭参数。

## 2.4 用 ChatGPT / Codex 账号登录

不想手填 API Key?可以用 ChatGPT 账号直接登录,把 GPT 系列当主对话模型,消耗你的订阅额度。

**登录**:设置 → 添加服务商 → 首页顶部「**使用 ChatGPT (Codex) 登录**」主按钮,会弹出系统浏览器完成授权(5 分钟内完成)。登录成功后自动保存配置,显示绿色「已配置」角标。

也可以用命令行登录(适合远程 / 无图形界面的机器):

```bash
hope-agent auth codex login          # 本机登录
hope-agent auth codex login --no-open # 只打印授权链接(配合 SSH 端口转发)
hope-agent auth codex status         # 查看登录状态
hope-agent auth codex logout         # 登出(会删除 Codex 服务商与本地凭据)
```

**重新登录**:Codex 服务商卡片的「⋮」菜单里有「重新登录」(而不是「删除」,避免误删);token 过期时界面也会引导你重新登录。

- 登录后使用的具体模型可在设置里切换,默认选择所有账号档位都可用的那一档。
- 内建 Codex 目录已包含 `gpt-6-astra`、`gpt-6.1-sol`、`gpt-6-sol`、`gpt-6-luna`；升级时补齐缺失条目，保留已选模型、自定义参数与禁用状态。可用性仍由 ChatGPT 套餐、工作区开关及官方上线范围决定。
- Codex OAuth 的 `gpt-6.1-sol` 上下文预设为 ChatGPT Work/Codex 官方说明的 **500K**；其它 GPT-6 OAuth 预设沿用官方 Codex 内建目录的 **272K**，OpenAI API 目录仍为 **1.05M**。上游 Codex 清单另列 872K 最大窗口，但 Hope 不把它当默认预算。沿用 **16K 输出预留**，不是服务端输出硬上限。GPT-6 推理档位为 `low` 至 `max`；`minimal` 和“关闭”按接口映射为 `low`，“关闭”仍隐藏思考展示；未设置强度时保留模型默认。`Ultra` 是 Codex 的任务委派能力，Hope 不把它当成推理请求参数发送。套餐、工作区设置和上线资格仍由服务端裁决。
- 新目录不再提供已退役的 GPT-5.4、GPT-5.3-Codex-Spark，以及 2026-10-14 在 Codex 退役的 GPT-5.5；既有配置保留，GPT-5.5 的 API 候选不受这次 Codex 退役影响。
- Codex 凭据只存在本机(`~/.hope-agent/credentials/auth.json`),绝不写入日志。
- Codex 登录与 [11 · MCP 接入外部工具](11-连接与扩展.md#111-mcp接入外部工具) 的账号登录是两套完全独立的机制,互不影响。

## 2.5 选主模型与备用模型链

**入口**:设置 → 模型配置 → **全局模型** 标签页。

- **默认模型**:两级下拉(先选服务商、再选模型),是所有新会话默认使用的模型。
- **备用模型链(Fallback)**:可添加多个、拖拽排序;当主模型调用失败时,按这个顺序自动尝试下一个,详见 [2.7](#27-自动容错failover)。

服务商或模型较多时，两级菜单都可在浮层内滚动；可用鼠标滚轮或键盘导航选择末尾项目。Agent 的计划模式模型选择也支持同样的操作。

**几个要点**:

- 会话在创建时会「固定」当时的模型;之后你改全局默认**不会影响已经存在的会话**,只影响新会话。想给单个会话临时换模型,用对话里的 `/model` 命令或输入框的模型入口。
- 每个 Agent 也可以单独配自己的模型链;Agent 没配就跟随全局。
- 备用链只是本轮临时降级,下一轮仍从主模型重新开始。

## 2.6 温度与思考强度

两个影响回答风格的旋钮,都按「**会话 > Agent > 全局**」三层覆盖(会话级优先级最高)。

**入口**:设置 → 全局模型。

- **思考强度(Think)**：最多支持 `none / minimal / low / medium / high / xhigh / max` 七档，全局默认 `medium`。请求发送时按模型、协议与端点映射到受支持档位，对话里可用 `/thinking high` 快速调整。
- **温度**:控制回答的随机性,滑块 0.00–2.00,默认 1.00。带「重置」按钮回到继承状态。

直连 **GPT-6** 时，有工具的对话请选择 OpenAI Responses。四项模型均保留 `max`；Astra / GPT-6.1 Sol 的“关闭”映射为 `low`，GPT-6 Sol / Luna 则发送 `none`，`minimal` 均映射为 `low`。未设置强度时保留模型默认；推理启用时不发送温度。Codex 登录的参数差异见 [2.4](#24-用-chatgpt--codex-账号登录)。新预设只影响新建连接；已有服务商需自行添加模型或调整协议。

**Claude Fable 5.1** 的原始思考签名会随会话保存。若动态前缀、压缩或切换模型导致部分历史思考无法继续使用，回复中会出现提示；本地原始块仍保留，但不保证跨模型保留全部推理状态。

**思考风格(Thinking Style)** 是服务商级(也可按模型覆盖)的设置,决定推理参数「怎么发送」,内置模板已预填,通常不用动。共 5 种:

| 风格 | 适用 |
| --- | --- |
| OpenAI(`reasoning_effort`) | OpenAI / DeepSeek / Mistral / xAI 等 |
| Anthropic（按模型使用自适应思考、开关或 `budget_tokens`） | Claude、MiniMax、Kimi 等 |
| Zai | 智谱 Z.AI |
| Qwen(`enable_thinking`) | 通义千问 / 阿里云百炼 |
| None | 不发送思考参数(部分自定义端点) |

> 如果某个模型本身不是推理模型,系统会自动不发送思考参数;你不用手动区分。

## 2.7 自动容错(Failover)

这是内建的能力,**没有独立开关**,跟着你的模型链([2.5](#25-选主模型与备用模型链))和多 Key([2.2](#22-一把服务商配多把-api-key自动轮换))自动生效。任何模型调用失败时,系统会自动判断错误类型并处理,你基本无感,偶尔会看到对话里的「模型已降级」提示。

处理策略随场景不同:

- **主对话**:最多重试、允许换 Key、失败换下一个模型(最强容错)。
- **后台任务**(如生成标题、提取记忆):轻量重试(用户不必久等)。
- **上下文摘要**:快速失败降级(你正在等回复,宁可快)。

常见错误的处理方式:限流 / 过载 → 退避重试 + 换 Key;网络超时 → 只重试;上下文超长 → 自动压缩后重试;鉴权失败 → 换 Key(Codex 则提示重新登录);模型不存在 → 直接换下一个备用模型。

> **Codex 用账号登录,没有多把 Key 可换**,所以它一旦鉴权失败会直接尝试模型链里的下一个模型,并提示你重新登录 Codex。

## 2.8 后台模型与视觉模型

在「全局模型」面板底部,可以为两类特殊用途单独指定模型,独立于主对话模型:

- **视觉桥模型(Vision)**——当你的主模型看不懂图片(不支持视觉)、却收到图片时,用这个模型把图转成文字描述注入对话,替代「直接丢图」。**默认关闭**,需要手动指定一个支持图片的模型才开启。转录的文字会被当作「不可信外部数据」处理,不会被当成对 AI 的指令。
- **自动化默认模型链(Automation)**——为「只需调一次模型、不需要完整 AI 人格」的后台任务(生成会话标题、Recap 报告、记忆整理、知识空间维护、技能评审等)指定统一的默认模型链。各功能面板里若单独设了模型,则优先用它自己的;否则用这里的全局默认;再否则跟随主对话模型。

两者都是纯模型引用、不含凭据,风险等级为中(MEDIUM)。

## 2.9 本地模型一键安装

不需要账号或 API Key。先从官网下载并手工安装 Ollama,再在设置里选一个适合你硬件的本地模型,应用会完成 **模型下载 → 注册服务商 → 设为默认**。首次下载需要联网;装好后可本地离线使用。应用暂不执行无法核验固定版本和完整下载链的安装脚本。

### 省心入口:本地模型助手卡片

**位置**:模型设置页,或首次向导的 Provider 步骤里。

卡片会根据你的硬件自动推荐一个模型(显示大小、上下文窗口、是否推理型),可以「展开备选」换其它候选。一个主按钮会随 Ollama 状态自适应:

- 没装 Ollama → 打开 [官网下载页](https://ollama.com/download),所有平台均先手工安装,再返回应用刷新状态。
- 装了没运行 / 推荐模型没下载 → 「安装模型」。
- 都就绪 → 显示「已启用」。

模型下载完成后会**自动**把该模型加入服务商列表并设为全局默认。模型下载过程有进度弹窗(阶段、字节、预计剩余时间、日志),可以后台化,也可以取消;外部 Ollama 安装器的进度不由应用管理。

### 显式管理:本地模型标签页

顶部状态区显示 Ollama 状态(未安装 / 已安装 / 运行中),已装模型列表里每个模型都能:启动 / 停止(加载到内存或卸载)、加入服务商、设为默认、加入 Embedding 配置、删除等。还能搜索 Ollama 模型库、手动输入名字下载。

> **推荐依据**:预算取 macOS 统一内存的 60%、或 Windows/Linux 独显显存的 60%(不足则回落系统内存的 60%),再扣约 1 GiB 运行时开销,按预算从大到小选第一个装得下的模型。
>
> **App 不接管 Ollama 进程**:只在需要时尝试启动它,应用退出时**不会杀掉 Ollama**,不影响你其它用到 Ollama 的工具。删除模型前会列出所有引用并让你确认。

## 2.10 记忆向量模型(Embedding)

配置一个 Embedding(向量)模型,可以让[记忆](04-记忆系统.md)和[知识空间](05-知识空间.md)做**语义检索**(按意思找,而不只是按关键词)。不配则退化为纯关键词检索。

**入口**:设置 → 记忆 / Embedding 模型面板。三种配置方式:

1. **本地快捷卡**:先手工安装 Ollama,再一键下载推荐向量模型,自动设为默认并重建向量。
2. **模板快速新建**:OpenAI / Google Gemini / Jina / Cohere / SiliconFlow / Voyage / Mistral / Ollama。
3. **自定义**:填服务商类型、Base URL、API Key、模型名、维度。

> **切换默认 Embedding 模型会触发全量重建向量(reembed)**,并需要二次确认——因为不同模型的向量空间不通用。记忆与知识空间共用同一个「模型库」,但各自独立选用哪个。
>
> Embedding 模型选择**只能在 GUI 里改**,不能通过对话让 AI 修改(它携带 API Key,且换模型有重建向量的重副作用)。

## 2.11 语音转写(STT)

独立于主模型的「语音转文字」引擎,用于:桌面麦克风输入(可边说边出字)、以及 IM 渠道里收到的语音消息自动转写。

**入口**:设置 → **语音识别** 面板。

- **主模型**:桌面语音输入首选的转写模型(流式模型会标注 `streaming`,可边说边出字)。
- **默认识别语言**:可填写 `zh-CN`、`en-US` 等 BCP-47 标签;Azure Speech 必填,其他支持自动识别的服务商可留空。
- **IM 兜底模型**:IM 自动转写专用(只能选非流式模型);不设则用主模型。
- **服务商**:「添加服务商」支持 OpenAI、Groq、ElevenLabs、xAI、DashScope(百炼)、Deepgram、AssemblyAI、Azure、讯飞、火山等 10 种协议;本地后端(whisper.cpp / faster-whisper / FunASR / sherpa-onnx)可一键探测接入。

**桌面录音怎么用**:聊天输入框的麦克风按钮点击录音;也支持在应用窗口内按住 `Ctrl+Shift+H` 说话、松开转写,文字插入到光标处。录音时显示波形和实时耗时。

**IM 自动转写**:默认关闭,开关在**每个 IM 渠道账号**的编辑对话框里(不在语音识别面板)。开启后,IM 里收到的语音会自动转成文字(前面加 `[语音转录]` 前缀)注入对话。

> 语音服务商列表与 Key 同样**只能在 GUI 改**,AI 只能读到打码摘要;唯一能用对话调整的是「IM 自动转写」开关。单次音频上限 25 MiB。

## 2.12 AI 画图与音频生成

图片和音频生成共用一套「**服务商 → 多模型 → 功能默认链**」配置,供对话里的 `image_generate` / `audio_generate` 工具和[设计空间](06-设计空间.md)使用。

### 第一步:配置服务商与模型

**入口**:设置 → **模型配置** → **媒体生成模型** 标签页。点「添加服务商」从 27 个内置模板一键接入,模板按模态分组并支持搜索——品牌名和模型 ID 都能搜(例如输入 `seedream` 或 `flux` 直接定位到对应服务商):

- **图像**:OpenAI(gpt-image)、Google(Gemini,支持改图和多参考图)、Fal(Flux)、SiliconFlow(Qwen-Image)、智谱(CogView)、通义万相、火山引擎(Seedream)、腾讯混元、阶跃星辰、百度千帆、商汤日日新、Black Forest Labs(FLUX)、Stability AI、Replicate、Together、xAI(Grok Image)、Recraft、快手可灵、科大讯飞
- **音频**:ElevenLabs(TTS + 音乐 + 音效)、MiniMax(语音 + 音乐)、OpenAI(TTS)、Cartesia、Deepgram、Fish Audio、Hume、火山豆包语音、Stability(音效)、快手可灵
- **自建端点**:「自定义(OpenAI 兼容)」

部分服务商的凭据格式需注意:快手可灵与火山豆包语音同时支持新旧两套鉴权,填 `ak:sk`(可灵)或 `app_id:access_key`(豆包语音)即按旧版签发;科大讯飞需填 `appid:apikey:apisecret` 三件套。

和语言模型一样,**一个服务商填一次 Key、挂多个模型**,图像和音频模型可以混挂在同一个服务商下。模板自带的预设模型会带上能力信息(支持的尺寸、宽高比、分辨率、是否支持改图 / 蒙版重绘、音频类型、时长范围、是否需要音色),这些能力决定了后续哪些参数会在界面上亮起。也可以「添加自定义模型」手工填模型 ID 并标注能力。

服务商卡片可拖拽排序——顺序即**自动挑选和失败切换的优先级**。ElevenLabs / OpenAI / Cartesia / MiniMax 可「拉取音色」列出账号可用音色,并设一个服务商级默认音色;其余语音服务商保留手填音色 ID。API Key 在面板里是密码框;AI 通过对话读取时会打码,而且**不能写入服务商条目**。

### 第二步:配置默认调用链与工具参数

媒体服务商的连接测试、生成请求和音色列表不会自动跟随端点重定向。如果提示重定向，请向服务商确认最终 API 地址并更新 Base URL 后重试；不要把该提示当作连接成功。

**入口**:设置 → **工具设置** → **媒体生成** 标签页。为**图像、语音、音乐、音效**四类各配一条默认调用链(主模型 + 若干备用,主模型失败自动降级到备用)。留空则「跟随服务商顺序(自动)」,下方小字会提示实际会用到哪个模型。

| 设置项 | 默认值 | 作用 |
| --- | --- | --- |
| 图像默认尺寸 | 1024×1024 | 调用未指定时的出图尺寸 |
| 图像默认宽高比 / 分辨率 | 未指定 | 调用未指定时的兜底(模型支持才生效) |
| 图像请求超时 | 180 秒 | 单次生成超时(30–900) |
| 音频默认时长 | 未指定 | 音乐 / 音效未指定时长时的兜底 |
| 音频请求超时 | 300 秒 | 单次生成超时(30–900) |

两个图像 / 音频总开关也在这里,关掉后对应的工具不再出现在 AI 的工具列表里。

### 在对话和设计空间里用

对话里直接说「画一张……」触发 `image_generate`,说「生成一段旁白 / 背景音乐 / 音效」触发 `audio_generate`(可指定语音 / 音乐 / 音效、音色和时长)。有参考图时,能力数据里声明支持改图的模型会自动切到对应的改图端点;蒙版重绘只会投给声明支持蒙版的模型,做不到的候选会被跳过、自动换下一个。

[设计空间](06-设计空间.md)的图像 / 音频产物走同一套配置,生成对话框里可直接选宽高比、分辨率、音频类型、音色和时长(按模型能力显示)。**还没配任何服务商时**,这些入口会显示引导卡片,点一下就跳到上面第一步的设置页。

> 通过对话调设置时,AI 只能改默认调用链和上表里的参数;服务商条目(含 API Key)**只能在 GUI 里改**。

图像新建模板已移除退役的 DALL·E 3 和 Google Imagen 4 / 旧 Gemini 图像预设，Google 使用 `gemini-3.1-flash-image` / `gemini-3-pro-image`。现有配置需由你按服务商当前可用性选择替换；GPT Image 1 将于 2026-10-23 下线，新建 OpenAI 图像模板已仅保留 GPT Image 2；已存配置不会自动迁移，请在截止前核对替代模型与所需参数。OpenAI 直连聊天模板也不再推荐同日退役的 `o1` / `o1-pro` / `o3-mini` / `o4-mini`，并移除已退役的 `o3-deep-research` / `o4-mini-deep-research`；已有模型和默认链由你自行调整。目录更新不代表真实图像质量已验收。

## 2.13 Web 搜索与网页抓取

### Web 搜索(web_search)

为对话里的 `web_search` 工具配置搜索服务商。

**入口**:设置 → **网页搜索** 面板。10 项搜索服务可拖拽排序(排第一的是主用,其余启用的作兜底):

- **免费无需 Key**:免费多引擎搜索、DuckDuckGo(均标注「可靠性有限」)
- **自托管**:SearXNG(填实例 URL,含 Docker 一键部署)
- **需 Key**:Tavily(全球推荐)、Bocha 博查(国内推荐)、Brave、Perplexity、Google CSE、Grok、Kimi

新安装默认启用**免费多引擎搜索**:先用 Brave 网页搜索,失败或没有可用结果时回退 360 网页搜索,再按服务商顺序尝试 DuckDuckGo 等兜底。无需 API Key、Python 或额外部署。旧配置保留服务商顺序,DuckDuckGo 已启用时新增项追加为兜底;其余旧配置的新增项保持关闭,可手动启用并拖到第一位。全部服务商关闭后,实际调用也会拒绝搜索。

此实现借鉴 DDGS 的多引擎回退方式,不运行原版 Python DDGS。免 Key 不能保证始终可用,上游限流、网络限制或页面变化仍可能导致失败。国家 / 语言过滤依上游能力尽力生效;设置了时效过滤时不会回退到不支持该过滤的 360 网页搜索。

Kimi 搜索使用国内 Basic 独立 REST 接口,沿用已配置的 Key。每次直接返回最多 10 条结构化链接和摘要,不调用聊天模型生成搜索 JSON、不获取完整正文。该接口不支持国家、语言或时效过滤;指定这些条件时会明确报错并尝试后续已启用的服务商,不会静默忽略过滤。官方按成功且非空结果的请求计费;真实账户费用与检索质量仍需自行核验。

命令行运行 `hope-agent server setup` 时,搜索服务步骤也可选择免费多引擎搜索,无需填写凭据。新配置默认选中该项;已有配置默认选中当前首个启用的服务商,只有确认选择后才调整顺序。

| 高级设置 | 作用 |
| --- | --- |
| 默认结果数 | 每次返回条数(1–10) |
| 超时 | 5–120 秒 |
| 缓存 TTL | 0–60 分钟 |
| 默认国家 / 语言 / 时效 | 搜索的地域、语种、新鲜度过滤 |

没有总开关,靠「是否有启用的服务商」决定是否可用。服务商 Key 可以让 AI 通过对话配置,但读取时会打码。

### 网页抓取(web_fetch)

为 `web_fetch` 工具配置抓取参数(纯参数,无需服务商)。

**入口**:设置 → **网页抓取** 面板。

| 设置项 | 默认值 | 作用 |
| --- | --- | --- |
| 最大字符数 | 50000 | 注入模型的内容上限 |
| 最大 Token 预算 | 32768 | 单次工具调用可请求的 Token 硬上限 |
| 最大响应体 | 2 MiB | 下载体积上限 |
| 超时 | 30 秒 | 1–120 秒 |
| 最大重定向 | 5 | 0–20 |
| 缓存 TTL | 15 分钟 | 0–1440 分钟 |
| 默认渲染模式 | 从不 | 选「自动」时仅在直接抓取不足时尝试隔离浏览器;也可设为「始终」 |

`web_fetch` 会在响应允许安全复用时,把首次获取的内容保存为进程内的**不可变快照**。长页面分段续读时,游标始终指向同一份内容,不会因网页中途更新而漂移,也不会重新联网抓取;续读游标最长保留 15 分钟。如果站点返回 `Set-Cookie` 或 `Cache-Control: private/no-store`,系统不会保留快照或发放续读游标;这种情况以及进程重启或游标过期后都需重新抓取。它可直接处理 HTML、JSON、XML、Markdown / CSV / 普通文本、常见字符编码和 PDF;动态页面只在渲染模式允许时才使用全新的隔离浏览器,不带你的 Cookie 或登录状态。AI 可按次选择优先缓存、实时获取或仅用缓存,并在字符 / Token 预算内返回内容;实际来源和新鲜度信息会记入工作台。

> 网页抓取不接受 Cookie、认证头或任意请求方法;需要登录态操作时请用浏览器工具。SSRF 防护强制生效,实际策略在「设置 → 安全策略」统一管理,详见 [13 · 设置与安全](13-设置与安全.md)。

## 3.1 聊天界面

- **发送**:默认 `Enter` 发送、`Shift+Enter` 换行;可在「设置 → 对话与上下文 → 基础」中切换为 `Enter` 换行、`Ctrl+Enter` 发送。
- **发送后保持阅读位置**:发出消息后,当前问题会被放在靠近顶部的位置,并为下方回复预留接近一屏空间;短回复展开时不会不断把问题顶走,长回复超过一屏后则继续跟随底部。
- **停止**:生成过程中,发送按钮会变成方形「停止」按钮,点它可以中断当前回复(等同于 `/stop`)。
- **翻历史**:光标在空输入框时,按 `↑` / `↓` 可以浏览你之前发过的消息(类似终端历史)。
- **忙时排队**:AI 正在回复时你又发消息,会进入「待发送队列」——可以编辑、删除,或作为下一个独立回合发出。是否在空闲时自动发出由设置项「自动发送排队消息」控制(默认开)。
- **上下文用量条**:输入框底部有一条细进度条(绿 → 黄 → 红),显示当前对话占用了多少上下文窗口,鼠标悬停显示「已用 / 总量」。
- **快捷切换**:`Shift+Tab` 可以快速循环切换[权限模式](07-工具与权限.md)(默认 → 智能 → 全自动)。

## 3.2 发送附件与多模态

Hope Agent 支持图片、文件、语音三类输入,随消息一起交给模型理解。

- **图片 / 文件**:点输入框工具栏的「+」按钮选择,或**直接粘贴 / 拖拽**。
- **粘贴长文本**:粘贴一大段文字会自动转成一个文本附件,避免撑爆输入框。
- **语音**:点麦克风按钮录音转文字;也可以在应用窗口内**按住 `Ctrl+Shift+H` 说话**,松开自动转写并插入到光标处。录音时显示波形和实时耗时;支持流式的转写服务会边说边出字。

> 语音功能需要先在[设置里配置语音转写(STT)](02-模型与Provider.md#211-语音转写stt),未配置时会提示。单个文件默认上限 20 MB,单条消息最多 64 个文件。

## 3.3 @ 提及与快捷输入

在输入框里用几个特殊符号可以快速引用东西:

| 输入 | 作用 |
| --- | --- |
| `/` | 触发[斜杠命令](#39-斜杠命令大全) |
| `@` | 提及一个**技能**(插入玫瑰粉色技能标签,发送时把技能说明注入本轮)或**当前工作目录的文件** |
| `[[ ]]` | 提及一篇[知识空间笔记](05-知识空间.md),发送时注入笔记内容 |
| `#` | 插入你预置的**快捷提示**(可复用的提示词片段) |

> - `@skill` 技能提及只对少数固定内置技能开放(办公三件套、数据分析、浏览器控制、macOS 控制),且主对话里需要先在设置里开启「技能提及」(默认关)。
> - `[[note]]` 笔记提及和 `@` 文件提及注入的内容,都被当作「不可信外部数据」处理,不会被当成对 AI 的指令。
> - `@` 文件在选择时就绑定当时的有效工作区。如果发送前切换了项目、会话或工作目录,该引用会失效,不会把相对路径悄悄指向另一个工作区。

## 3.4 思考块、工具块与右侧面板

### 思考块(Thinking)

模型的思考过程会显示成一个可折叠的「思考块」,带大脑图标和**实时耗时**(流式时每 100 毫秒刷新,结束后显示最终耗时)。可以点击折叠 / 展开;是否默认展开由设置项「自动展开 Think 过程」控制。

### 工具调用块

AI 每次调用工具(读文件、执行命令、搜索等)都会显示一个块,含工具名、参数、结果、**耗时**和成功 / 失败状态。连续多个已完成的工具步骤会自动折叠成一个「已处理」分组,保持界面整洁。

一些特殊工具有专属卡片,比如提问卡(`ask_user_question`)、计划卡、任务清单、技能激活块、子 Agent 块等。已回答的提问卡收起时只显示一行摘要,展开后会保留原问题、当时的上下文、每个选项的说明与推荐标记,以及你实际选择或输入的答案;超时也会明确标出。

### 右侧面板

聊天界面右侧是一个统一的可停靠标签栏,嵌在标题栏行内(「右侧面板停靠栏」)。点击标签切换;拖拽标签可重新排序(也支持键盘 `Alt+Shift+方向键` 换位);每个标签右上角有关闭按钮,鼠标中键点击也能关闭;标签条右侧的「+」下拉菜单可以开新标签(对「文件」标签,「+」永远新开一个空的文件浏览器,不会复用或聚焦已经打开的文件标签)。整个标签区域可以整体最大化 / 还原铺满窗口,也可以整体折叠隐藏(「折叠右侧面板」)——这两个操作作用于整个标签区域,不针对单个标签。

宽度默认按窗口宽度自动分配(与对话区大致 1:1,随窗口缩放动态调整,双方各有最小宽度下限),也可以手动拖拽边缘调宽(会记住手动比例,可重置回自动);窗口很窄时右侧区域会临时切换成铺满全宽的单栏视图,把对话区暂时让出去。

当前标签种类:

- **文件**——完整的迷你文件浏览器(见下文)。
- **工作台(Workspace)**——聚合当前任务进度、读写过的文件、访问过的网址、Git 状态、目标等,点输入框上方的状态条进入。
- **Diff**——展示 AI 对文件的改动(分屏 / 合并视图),详见 [07 · 工具与权限](07-工具与权限.md)。
- **计划**——[计划模式](08-自主任务.md#85-计划模式plan-mode)下的设计文档。
- **Canvas / 浏览器 / macOS 控制 / 团队 / 后台任务 / 子 Agent / Pull Request**——对应各自的功能,详见相关章节。
- **文件预览**——从消息里点文件卡片跳转出的单文件预览,和「文件」标签是两回事。

> 弹出到独立窗口有两种,别混淆:「浏览器」「macOS 控制」支持切到**应用内浮动小窗**(「悬浮小窗」按钮;小窗可拖动、可从 8 个方向调整大小,位置会被记住),再点「收回到面板」停靠回标签条;「文件」「计划」「Canvas」支持弹出成**独立的原生窗口**(「独立窗口」按钮,桌面版专属),同样可以「收回到面板」。工作台(Workspace)、Diff、团队、后台任务、子 Agent、Pull Request、文件预览这些标签没有任何弹出模式,只能停靠在标签条内。

**文件标签**是一体化的迷你文件浏览器:左侧文件树 + 右侧预览。文件树可以折叠成只看预览(预览区「隐藏文件列表」按钮),折叠后点预览头部面包屑里的目录名会自动重新展开文件树并定位到该目录。在同一个文件标签里点选新文件只会更新当前标签的预览,不会自动新开标签;要把多个文件并排对比,需要在文件树里右键文件选「在新标签中打开」,或点标签条「+」新开一个空文件标签再手动定位。预览头部的路径是可点击的面包屑:点目录名跳回文件列表并展开定位;点文件名本身是复制完整路径,不会跳转。

普通 HTML 文件(不是 Artifact / Canvas 生成的托管 HTML)预览默认显示带语法高亮的源码,头部有「查看源码」/「渲染视图」切换按钮(与 Markdown 预览共用同一组按钮,但 Markdown 默认是「渲染」态,和 HTML 默认「源码」态相反)。切到「渲染」后会先剥离脚本、`iframe`、`on*` 事件等可执行内容,链接只保留 `data:` / `blob:` / 锚点等离线安全地址,再放进空沙箱的 `iframe` 里展示——不执行页面脚本、不加载外部资源(图片等仅保留内嵌的 `data:` / `blob:` 资源)、点击链接也不会跳转离开预览。Artifact / Canvas 生成的托管 HTML 走独立的渲染路径,本来就会正常渲染执行,不受这个开关影响。

> 这里的「右侧面板」是整个标签停靠区域的统称,UI 里没有独立的产品名;「工作台」现在只是众多标签之一(聚合任务进度那个),不要把两者混为一谈。

### 消息渲染

回复支持完整 Markdown、代码高亮、数学公式(KaTeX)、Mermaid 图表。在桌面版里,AI 还能写可点击的本地路径链接(点击在文件管理器中打开)。

### 划选文字:复制与引用到对话

在文件预览(代码 / 文本、Markdown、Office 富预览)、托管 HTML / Artifact 预览和设计空间画布里,选中一段文字会在旁边浮出一个小工具条,可以「复制所选」或「引用到会话」;未选中文字时右键(右键菜单)也能唤出同一工具条,退化成「复制全部」。点「引用到会话」不会立刻发送——会在输入框上方生成一个可删除的暂存引用块,代码 / 文本类引用还带着文件路径和精确的起止行号(渲染后的 Markdown、Office 预览等按 DOM 定位,能对上行号就带、对不上就只带文本);点暂存的引用块可以跳回原文件定位,发送前也可以随时删除。图片、PDF、音视频等没有文字可选的预览不支持这个操作。

### 相关设置(设置 → 对话与上下文 → 基础)

| 设置项 | 默认值 | 作用 |
| --- | --- | --- |
| 按 Enter 发送消息 | 开 | 关闭后改为 `Enter` 换行、`Ctrl+Enter` 发送 |
| 自动发送排队消息 | 开 | AI 忙时你发的消息是否自动排队发送 |
| 自动展开 Think 过程 | 开 | 思考块流式时是否默认展开 |
| 完成后折叠中间消息 | 开 | 已完成的回合是否自动折叠 |
| 进度更新 | 开 | AI 是否在关键时刻给出简短进度更新,并在回合结束时小结 |
| 会话标题 | 开 | 是否用模型自动为会话起标题 |

## 3.5 会话管理与搜索

- **新建对话**:侧边栏「新建」或 `/new`。在项目里新建对话时会先停在草稿态,发出第一条消息才真正保存。
- **AI 主动新建 / 发消息**:模型可以调用内置工具 `sessions_create` 创建一个新的普通会话——可选关联项目(默认当前项目)、指定 Agent(省略则按项目默认 Agent 解析链或沿用当前 Agent)、带标题、内联附件(最多 64 个,只接受文本 / Base64 内容,不接受文件路径)和首条消息;带了消息或附件就会立即启动目标 Agent 的第一轮。新建出来的是**完整持久、侧边栏可见的普通会话**,和手动新建的没有区别,可以正常切换、停止、继续。`sessions_send` 则是向一个**已有**的普通会话追加消息启动新一轮;来源或目标是无痕会话、或目标不是普通会话(如定时任务 / IM / 知识空间 / 设计空间 / 子 Agent 会话)都会被拒绝。这两个工具**默认不弹审批**(和大多数非编辑类内置工具一样);如果想让 AI 每次新建 / 发消息前都停下来等你确认,可以在 Agent 设置 → 审批 里把它们加进自定义审批工具列表。
- **跨会话消息跳转**:当 AI 向另一个会话发消息时,发送方会出现可点击的送达回执,可直接打开目标会话并定位到那条消息;接收方也会显示来源入口。如果来源是侧聊,跳转时会同时恢复所属主会话和侧聊面板。这些链接重新打开应用后仍然有效;回执只表示消息已提交,不代表目标 Agent 后续一定执行成功。
- **会话列表**:侧边栏按更新时间倒序,可置顶(置顶的会话集中在侧边栏顶部一个独立的「置顶」分组,跨项目和 IM 渠道汇总显示,无置顶会话时不占位置;可折叠展开)。分「会话 / 子 Agent」两个浏览标签。定时任务、无痕、知识空间、设计空间的会话**不出现在主列表**。鼠标停留在会话行上会浮出详情卡,显示所属项目、工作目录、模型和 Git 状态(分支、改动文件数、增删行数、有无冲突),卡片上可以直接置顶或归档,不必先切换进去。
- **切换 / 改名 / 归档**:点击切换;可手动改名(手动名不会被自动标题覆盖)。归档会把对话从日常列表和搜索中隐藏,但保留消息、项目和 Agent 归属。
- **恢复 / 永久删除**:在「设置 → 已归档对话」中搜索、按类型或项目筛选并恢复。只有这里提供永久删除,且会再次确认;永久删除会一并清理消息、附件等且无法撤销。
- **在新会话中继续(Fork)**:把当前会话复制成一个新的独立会话(复制对话内容和配置,但不复制运行中的目标、持续推进、后台任务)。

### 侧聊

输入 `/side 你的问题`,或选中一段消息后点「在侧聊中提问」,可以从主会话已完成的稳定历史发起一段独立追问,不中断正在运行的主任务。一个主会话可保留多个侧聊,主会话和侧聊也可同时生成;关闭面板只是收起视图,稍后可从输入框上方的入口重新打开。

侧聊创建时继承当时的 Agent、模型、项目、工作目录、权限、沙箱和已完成历史,之后独立演进;可单独选模型、加附件和使用工具。它不进入普通侧边栏、全局搜索或普通未读统计,且暂不支持计划模式与工作流模式。主会话是它的生命周期所有者:归档只会隐藏,但永久删除主会话会一并永久删除所有侧聊。

### 搜索

- **全局搜索**(侧边栏):全文检索所有会话,命中片段高亮。
- **会话内搜索**(`Cmd+F` / `Ctrl+F`):只搜当前会话,命中后自动滚动定位并高亮。

### 未读怎么算

- **一个会话不管有多少条未读消息,都只算「1 个未读会话」**。会话行显示一个小圆点;项目、全局和 Dock 上显示的是未读会话的**数量**;系统托盘只显示有没有红点。
- 通常只有当聊天主视图选中该会话、窗口在前台、页面可见、且消息列表停在最新位置时,它才算「已读」。桌面宠物中的 Ready/Blocked 预览是明确的例外：只有按下文所述完成阅读或操作时，才推进到气泡实际展示的消息位置。
- 定时任务和 IM 渠道各有独立的未读统计,普通对话的「全部已读」不会清掉它们。

## 3.6 无痕会话

无痕会话是**不留痕迹的临时对话**,关闭即焚。

**怎么开**:点输入框工具栏或标题栏的**幽灵图标**。

无痕会话会做这些事来保护隐私:

- 切走当前无痕会话时立即彻底删除,不留任何记录。
- **不注入记忆、不做行为感知、不自动提取记忆、不进知识空间被动召回**——记忆系统对它完全「失明」。
- 不进入侧边栏列表、全局搜索和 Dashboard 统计。

> **限制**:无痕会话与「项目」「IM 渠道」「工作流模式」「进行中的目标」互斥——已经归入项目或绑定 IM 的会话无法转无痕(开关会灰化并说明原因)。无痕会话里仍然可以设置会话工作目录。

## 3.7 会话工作目录

给当前对话指定一个默认操作目录,它会:

- 注入到 AI 的提示词里,告诉它默认在哪读写文件;
- 作为 `exec`(执行命令)的实际工作目录、`read`(读文件)相对路径的解析根;
- 目录的顶层文件清单也会告诉 AI,方便它感知你在做什么。

**怎么设**:点输入框工具栏的「工作目录」按钮。桌面版弹出系统目录选择器;网页 / 服务器版弹出目录浏览框(指向服务器机器上的路径)。

目录浏览器没有已有路径时会从运行 Hope Agent 的系统用户主目录开始,也可以随时点主目录按钮返回。Hope Agent 不会为了写系统目录自动提权;如果当前位置不可写,请选择该用户拥有的目录。网页 / 服务器模式下新建目录还需先在「设置 → Server」开启「允许远程文件写入」,界面会在开关关闭时直接给出引导。

优先级是「会话设定 > 项目设定 > 默认工作区」。项目里的会话总是有一个工作目录(默认是 `~/.hope-agent/projects/{项目}/workspace/`)。

## 3.8 长对话的上下文压缩

模型能记住的对话长度是有限的(上下文窗口)。对话变长、接近上限时,Hope Agent 会**自动分层压缩**,让长对话和长任务能继续,而不会突然「失忆」或报错。压缩过程是自动的,你通常只会在顶部看到一条(完成态为灰色的)压缩提示;如果压缩没有顺利完成,提示会换成一条琥珀色横幅,标题会写明具体原因——比如「摘要生成超时」「已完成同步清理,但摘要生成超时」「需要摘要,但本次摘要未完成」「已完成同步清理,但摘要未完成」,无法归类时兜底显示「上下文压缩已暂停」,副标题带上已处理的消息数、已恢复文件数等信息——横幅右侧还有「重新压缩」按钮,点击后转圈禁用以防重复点击。

压缩先用不额外调用模型的确定性投影清理过时工具结果，再逐级到「摘要旧历史」；投影变化仍可能让部分提示缓存失效，并非完全零成本。摘要会保留已知的文件触点和受管引用；只有具备当前会话授权、可验证来源的文件内容才允许重新注入。无法证明授权时会安全跳过正文，模型可再通过正常文件工具按需读取，不会绕过沙箱读取宿主路径。

**手动命令**:

- `/compact`——手动压缩当前对话。
- `/context`——查看当前上下文占用明细。

**主要设置(设置 → 对话与上下文 → 上下文压缩)**:

| 设置项 | 默认值 | 作用 |
| --- | --- | --- |
| 启用上下文自动压缩 | 开 | 关闭后只保留最基础的截断与兜底 |
| 反应式微压缩 | 开 | 每轮结束时按需清理旧的工具结果 |
| 触发比例 | 0.75 | 上下文用量超过此比例时触发反应式清理 |
| 摘要模型 | 空(用对话模型) | 生成摘要用的模型,可指定更便宜的模型省成本 |
| 摘要触发阈值 | 0.85 | 用量超过此比例时触发摘要压缩 |

> 这些属于「行为调整」类设置(中风险),会影响上下文和成本。绝大多数用户保持默认即可。压缩还有一整套更细的参数(裁剪比率、保留最近轮次、文件恢复等),都在同一面板的「高级」区,按需调整。

## 桌面宠物（Pet）

桌面版可在「设置 → 宠物」唤醒一只常驻桌面的动画伙伴。它只显示产品主对话的 Running、Needs input、Ready、Blocked 状态：主聊天、快捷聊天、知识空间对话和设计空间对话都会接入；后台任务、Cron、IM、ACP、subagent、Memory、评测、摘要和其它额外模型请求不会单独点亮宠物。

首次看到侧边栏底部的蛋图标时，Hope 会显示一次简短提示。你可以直接「立即开启」，或进入宠物设置选择、导入和创建宠物；关闭提示后不会重复打扰。

- 气泡会动态改变原生窗口尺寸，并保持宠物脚下位置不跳；自动气泡不抢焦点，即使当前正在使用其它应用，移到宠物或气泡上仍有 hover 反馈。
- Running 正文会实时更新并带扫光，完成后显示绿色勾；摘要在固定高度内最多显示两行，Markdown 的标题、强调、代码和链接会转成易读纯文本，不直接显示 `#`、`*` 或反引号。hover 气泡可关闭、快捷回复或停止目标对话。
- 自动出现不算已读。Ready/Blocked 气泡停留阅读后移开、打开原对话、提交快捷回复、关闭，或主动收起已展开的气泡栈时，只会把该气泡已经展示到的消息标为已读并更新未读数；Running、Ask User 和授权等待不会因此被清除。
- 单击宠物会唤起 Hope 主窗口，拖动则只改变宠物位置，不会误触主窗口。单击一条活动直接回到原对话；多条活动展开为可滚动的气泡栈，待回答或授权时显示独立紧凑卡片。右键宠物会在它身上显示紧凑的「设置 / 关闭」操作；「设置」会唤起主窗口并直达宠物设置页。重启和显示器变化后会恢复到可见区域。
- 在 Import 中可扫描已有自定义宠物，或拖入任意来源的目录、zip、`pet.json + 图片`、PNG/WebP；一次拖入多个包会逐只预览。也可提供任意公网来源的直接 HTTPS zip / manifest / atlas 链接；若给的是普通网页，技能会先找到实际下载物，而不会执行网站推荐的安装器。自动化先运行 `hope-agent pet preview --source <路径或链接> --json`，待你确认名称、告警和 `packageHash` 后，再用 `hope-agent pet import` 携带该 hash 安装。所有入口都要你确认后才安装，来源不会改变目标：Hope 导入只写 Hope 宠物库。
- 内置 Hope 宠物和自定义宠物都可导出为 Codex-compatible zip。Create 默认生成含 16 个注视方向的 Codex v2 宠物，也可选择生成兼容旧客户端的 v1；v2 宠物空闲时会跟随宠物窗口内的光标方向，光标靠近中心时回到正面。这是一次用户明确触发、会计入用量的图像生成，不是常驻宠物的后台调用。宠物库中的 v1 可一键生成 v2 副本，原 v1 会保留；若原宠物正在使用，升级成功后会自动切换到 v2。
- `/pet` 切换显示，`/pet on|off|status` 可明确控制。HTTP、ACP 和 IM 不能远程弹出桌面置顶窗口。

系统开启“减少动态效果”时宠物停在静态帧。自定义宠物只保存在本机；删除前须先选择另一只，删除后可在提示条中撤销。

## 3.9 斜杠命令大全

在聊天输入框或任意 IM 渠道里输入 `/` 就能触发斜杠命令。支持模糊匹配。下面是全部内置命令(每个可安装的技能还会自动生成一个 `/技能名` 命令)。

### 会话

| 命令 | 用途 |
| --- | --- |
| `/new` | 新建会话 |
| `/fork` | 复制当前已完成的对话历史，在新会话中继续；不会复制目标、循环和工作流等运行状态 |
| `/side [问题]` | 在不中断主对话的情况下打开侧聊；可省略问题后再输入，也可选中一段消息后选择「在侧聊中提问」 |
| `/clear` | 删除当前会话的所有消息 |
| `/compact` | 压缩当前会话上下文 |
| `/stop` | 停止当前回复 |
| `/rename <标题>` | 重命名会话 |
| `/export` | 把当前会话导出为 Markdown |
| `/status` | 查看会话状态(Agent / 模型 / ID / 消息数) |
| `/usage` | 查看当前会话 Token 用量 |
| `/context` | 查看上下文窗口占用明细 |
| `/pet [on\|off\|toggle\|status]` | 唤醒、收起或查看桌面宠物状态（桌面端） |
| `/sessions` | 打开会话选择器(可带关键词搜索) |
| `/session <id>` | 切换 / 关联会话 |

### 项目与目标

| `/mode <off\|guarded\|deep\|autonomous>` | 设置[执行模式](08-自主任务.md#84-执行模式mode) |

# Hope Agent 0.43.0 — Documentation updates and corrections

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.43.0/docs/release-notes/v0.43.0.md) · **English**

> Released: 2026-09-05

> See [the changelog](https://github.com/shiwenwen/hope-agent/blob/v0.43.0/CHANGELOG.md#0430---2026-09-05) for the full list.

This update changes documentation only; application behavior is unchanged. The English and Chinese user guides now cover existing DeepSeek image understanding, stable web snapshots, cross-session navigation, side chats, native IM streaming, Hook workspace authorization, and Toolchain Doctor behavior.

It also corrects an earlier statement: ordinary long tool output cannot be fully recovered after compaction. If the tool provides a continuation cursor, you can keep reading through that cursor; otherwise, rerun the tool. Existing settings and data need no attention.

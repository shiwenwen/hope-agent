# Hope Agent v0.72.0

## 更多模型选择

在设置中添加服务商时，可选择 GPT-6.1 Terra、Kimi K3.1 Pro 及其高速型号、Unbiased Pareto 26.10 和火山方舟 DeepSeek V4.1 Flash。API 与 Codex 订阅的可用范围、上下文和费用各自独立，已有配置保留；请按账号权限与费用选择，新增预设不代表已完成真实账号验收。详见[模型与服务商](https://github.com/shiwenwen/hope-agent/blob/v0.72.0/docs/user-guide/02-模型与Provider.md)。

## 长任务与设计检查更准确

修改目标后，已经验证修复的问题保持已解决，新目标仍需重新验收。设计空间遇到尚未支持的自定义视觉场景时，会明确提示验证未完成，并阻止将默认页面截图接受为基线；默认场景的桌面、平板与手机检查仍可使用。

## 回复与兼容性修复

Google Chat 的预览与最终回复保持原有文字格式，减少链接和提及显示变化。Perplexity 搜索过滤重复或无效引用，失败与取消不再记为成功搜索；现有搜索配置保留。加密备份与微信媒体继续兼容已有格式，阶跃星辰图标适配新版主题显示。

专项评测修正了故障判分、停止状态和调用用量归属；这些修复不代表模型能力或真实设备回归已经验收。

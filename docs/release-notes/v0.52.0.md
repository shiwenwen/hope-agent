# Hope Agent 0.52.0 — 引用已有会话，连接更稳妥

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.52.0/docs/release-notes/v0.52.0.en.md)

> 发布日期：2026 年 9 月 22 日

> 完整改动列表见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.52.0/CHANGELOG.md#0520---2026-09-22)。

## 在新任务里直接引用已有会话

在输入框键入 `@`，即可搜索并选择已有的普通会话。发送后，Hope Agent 可以按你的要求读取被引用会话的上下文，或向那个会话发送任务；主对话、快捷对话和侧聊都可使用。

## 关闭 Think 后不再混入推理内容

把 Think 设为关闭后，即使兼容服务仍返回推理文字，Hope Agent 也不会再展示或保存这些内容。当前尚未开放的工具结果磁盘持久化设置也已明确为不可调整，避免设置看似生效、实际仍未启用。

## 外部连接与模型选项更可靠

MCP 服务的协议协商、重新授权和登出更稳定，ACP 连接在取消权限请求时也能更明确地结束；网页搜索跳转继续遵守网络访问限制。

DeepSeek 直连预设更新为支持图像的 `deepseek-flash`，并按服务能力发送思考档位。即将退役的 Fireworks Kimi K2.6 不再出现在新建连接的公共预设中，已有自定义配置不受影响。

Discord 附件会按 20 MiB 上限预检，超出时继续使用现有链接方式发送。

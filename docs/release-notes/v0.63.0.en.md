# Hope Agent 0.63.0 — Free search and memory writing preferences

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.63.0/docs/release-notes/v0.63.0.md) · **English**

> Released: October 6, 2026

> See the [changelog](https://github.com/shiwenwen/hope-agent/blob/v0.63.0/CHANGELOG.md#0630---2026-10-06) for the complete list of changes.

## Look up web information without applying for a key

New installations enable free multi-engine search by default, with no API key or extra software to install. If Brave web search is unavailable, it tries 360 Search and then your other enabled services. Free endpoints can still fail because of rate limits, network restrictions, or page changes. A freshness filter skips 360 Search.

Upgrading preserves your search order and disabled options. To use the new option first, open Settings → Web Search, enable Free multi-engine search, and drag it to the top. You can also select it directly when running `hope-agent server setup`, without entering credentials.

## Write memories in your preferred style

In Settings → Memory → Memory Settings, choose System default, Concise, or Detailed and add writing requirements separately for conversation extraction, manual profile consolidation, and Dreaming. Each Agent can override the global preferences in its memory settings. Existing memory and privacy switches still apply; writing preferences do not turn on disabled memory features.

## Clearer connection and setup feedback

OpenViking exports show success only after background processing has explicitly completed; unconfirmed writes remain pending reconciliation. iMessage health checks flag outdated imsg versions and show unverified when the version cannot be determined, leaving upgrades to you. The list of models offered for new configurations has also been streamlined; saved provider and model configurations remain unchanged.

This release includes the search feature originally planned for 0.62.0. Version 0.62.0 was not publicly released because its release build failed; use 0.63.0 directly.

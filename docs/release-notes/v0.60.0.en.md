# Hope Agent 0.60.0 — Check the weather with Chinese city names

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.60.0/docs/release-notes/v0.60.0.md) · **English**

> Released: October 2, 2026

> See the [changelog](https://github.com/shiwenwen/hope-agent/blob/v0.60.0/CHANGELOG.md#0600---2026-10-02) for the complete list of changes.

## Ask about the weather using Chinese city names

You can now ask about the weather in 北京 or 上海 without translating the city name into English first. When checking several cities, a missing country name from the weather service no longer causes the entire request to fail.

## Explore what Hope Agent can do

The project homepage now opens in English, with a complete Chinese documentation entry point. Refreshed screenshots of chat, knowledge spaces, design spaces, and the usage dashboard help you see which features fit your tasks.

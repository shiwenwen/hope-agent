## 不用申请 Key，也能在对话中查资料

新安装默认启用免费多引擎搜索，无需申请 API Key 或安装额外软件。你可以直接在对话中让 Hope Agent 查找网页资料；Brave 网页搜索不可用时会尝试 360 网页搜索，再尝试已启用的其他搜索服务。

升级后，你原来的搜索顺序与关闭选择会保留。要优先使用新选项，打开「设置 → 网页搜索」，启用「免费多引擎搜索」并拖到第一位。

免费搜索仍可能受限流、网络限制或页面变化影响，不能保证每次成功。国家与语言筛选尽力生效；选择时效筛选时会跳过不支持该筛选的 360 网页搜索。

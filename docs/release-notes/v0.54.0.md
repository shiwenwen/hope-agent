# Hope Agent 0.54.0 — 对话模型选择与长任务更可靠

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.54.0/docs/release-notes/v0.54.0.en.md)

> 发布日期：2026 年 9 月 24 日

> 完整改动列表见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.54.0/CHANGELOG.md#0540---2026-09-24)。

## 设计对话使用选定模型

在设计空间选择模型后，对话会实际使用该模型，并在再次打开会话时保留选择。没有单独指定模型的子任务会沿用父会话的模型；上游忙碌时的提示也更准确。

## 长时间任务更容易继续

当一次请求中已经完成多轮工具调用，Hope Agent 可以整理较早的调用记录，为后续步骤留出上下文空间，同时保留当前请求和最近的完整结果。涉及较长工具链的任务因此更不容易因上下文不足而中断。

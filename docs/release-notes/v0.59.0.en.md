# Hope Agent 0.59.0 — New models and smoother conversation continuation

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.59.0/docs/release-notes/v0.59.0.md) · **English**

> Released: October 1, 2026

> See the [changelog](https://github.com/shiwenwen/hope-agent/blob/v0.59.0/CHANGELOG.md#0590---2026-10-01) for the complete list of changes.

## Choose new OpenAI and Claude models

Search the model catalog for GPT-6.1 Sol, GPT-6 Sol/Luna, or Claude Opus/Sonnet 5.5 to select a preset and start a conversation. Check that your provider account has access to the selected model before using it.

The retired Together AI Kimi K2.6 Serverless preset has been removed from the catalog. If you used that service, choose another available model.

## Keep chatting after stopping a reply

With OpenAI Chat compatible models, you can ask another question in the same conversation even if you stopped the previous reply before it produced any content. There is no need to start a new conversation.

# Hope Agent 0.35.0 — 网页读取更稳，设计交付更完整

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.35.0/docs/release-notes/v0.35.0.en.md)

> 发布日期：2026-08-23

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.35.0/CHANGELOG.md#0350---2026-08-23)。

这一版重点补齐两条经常需要来回确认的工作流：Agent 读取长网页时会固定在同一份页面快照上继续，不会翻到后半段时内容已经悄悄变化；设计空间则从「生成一个画面」走到可以维护场景、对比固定视口、发布组件清单，并与 Figma 做有确认步骤的往返。

外部连接也更容易判断是否真的可用。设置页现在会明确显示外部 Memory、IM 渠道、ACP 后端和本机工具链的兼容或阻断原因，让问题尽量在开始任务前暴露，而不是运行到一半才失败。

## 新增

- **长网页可以稳定地分段读完**：Agent 首次读取后会保留不可变快照，继续读取时沿用同一份内容；页面更新也不会让已经拿到的游标失效。来源会进入工作台，便于回看本轮实际参考了哪些页面。
- **更多网页类型可以直接处理**：普通网页、动态渲染页面、PDF、JSON、XML 和常见文本编码会走各自合适的读取方式。你可以在「设置 → 工具 → Web Fetch」调整内容预算、缓存时间和是否允许浏览器渲染；AI 则可在每次读取时选择优先缓存、实时获取或仅用缓存。
- **设计空间新增完整交付链路**：可以保存预览场景与固定视口，执行不依赖模型的视觉差异检查，扫描代码仓库生成组件清单，并把确认后的清单发布给团队使用。
- **Figma 往返先预览、再逐次确认**：从 Hope 写入 Figma 或从 Figma 拉回新版本前，会先展示本次操作；只有你确认后才会发起外部调用。结果不确定时会要求先核对，避免重复写入。
- **固定版本评审不会随设计继续修改而漂移**：服务器模式可创建 7 天有效的仅查看或可评论凭证，始终指向创建时的设计版本，也可以随时撤销。
- **IM 对话可以明确请求一个文件**：Agent 可请求你发送一份 PDF、TXT 或 Markdown 文件；支持的渠道会给出原生上传入口，文件只交给发起请求的账号、对话和会话。
- **新增只读工具链诊断**：设置页可以检查浏览器、Docker 与常用开发工具是否存在、版本是否受支持，不会替你安装、升级或重配它们。

## 变更与修复

- **外部 Memory 连接会先检查兼容性**：设置页区分「可用」「无法验证」和「版本不安全」，并提供独立的连接测试；配置变化后不会继续沿用过期结论。
- **IM 渠道的兼容回退更明确**：Telegram、Slack、iMessage、Google Chat 与 Discord 可按账号控制新回复方式；Signal 与 WhatsApp 会显示检测到的桥接版本，已知不安全的版本会被阻止。
- **项目 Hook 改为逐工作区授权**：授权绑定准确路径与当时的配置内容；文件变化、目录移动或符号链接别名不会静默继承旧授权。
- **沙箱镜像改为不可变版本**：默认镜像固定到内容摘要，自定义镜像也必须使用 `name@sha256:<摘要>`，避免同一标签在不同时间拉到不同内容。
- **中英文用户手册补齐近期功能**：工作台、多源项目文件夹、AI 新建会话、划选引用、HTML 预览、压缩重试和评测预算等章节已与应用同步。

## 升级提示

直接更新即可；普通用户无需迁移数据。

如果你使用以下高级配置，请在更新后检查一次：

- 自定义 Docker 沙箱镜像需要改成带 `@sha256` 摘要的完整名称。
- 项目或本地 Hook 需要在「设置 → Hooks」中逐个重新信任工作区。
- 旧版 ACP 后端若没有分发描述，会保持阻止启动；在设置页补齐包或产品标识即可，版本可以留空。
- 使用外部 Memory 时，建议在设置页点击一次「测试连接」，确认兼容性状态。

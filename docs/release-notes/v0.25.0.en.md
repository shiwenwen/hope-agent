# Hope Agent 0.25.0 — Design Space Generation Entry and Pet Transparency Fixes

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.25.0/docs/release-notes/v0.25.0.md) · **English**

> Release date: 2026-07-28

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.25.0/CHANGELOG.md#0250---2026-07-28) for details.

v0.25.0 is a small release that cleans up two rough edges left by 0.24.0: the image / audio generation entry on the Design Space home screen bypassed the media capability check, so it failed outright and left an empty project behind when a media model was not configured; and the desktop pet's overlay window rendered on a white background instead of a transparent one in light mode in release builds. Both are fixed.

## Fixed

- **Image / audio generation from the Design Space home screen now goes through the full media generation dialog**: starting a generation from the Design Space home screen now behaves exactly like generating inside an artifact — you get model availability guidance up front, the parameter controls reflect what the selected model actually supports, and only supported parameters are submitted. Generating from a reference image alone, with no prompt, still works as before. Previously this entry skipped the capability and configuration checks and created the project *before* attempting generation, so when no media model was configured — or when the model did not support one of the parameters — you got a bare failure plus an empty project that had already been created.
- **The desktop pet overlay is no longer white in light mode**: in release builds, the pet window had an opaque background color written during theme bootstrap, which overrode the transparent styling that only takes effect after the app boots, leaving the overlay as a white rectangle in light mode. The pet window now stays transparent from its first rendered frame, and light / dark backgrounds for normal windows are unaffected.

## Changed

- **The macOS package is about 10 MB larger**: after 0.24.0, the macOS release build had grown to roughly 173 minutes. This release moves that platform to a higher parallel-codegen setting, bringing the build back to about 89 minutes at the cost of weaker cross-module inlining and a larger binary. Linux and Windows codegen settings are unchanged and unaffected. The bundled evaluation sidecar grows by about 1.7 MB on every platform for the same reason. Both changes affect download size only — functionality and runtime behavior are unchanged.

## Upgrade notes

There are no config migrations, no behavior changes, and no compatibility concerns in this release — just update. macOS users will notice a slightly larger download than 0.24.0; see above for why.

# Hope Agent 0.25.0 — 设计空间生成入口与宠物透明度修复

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.25.0/docs/release-notes/v0.25.0.en.md)

> 发布日期：2026-07-28

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.25.0/CHANGELOG.md#0250---2026-07-28)。

v0.25.0 是一个小版本，收拾 0.24.0 留下的两处毛病：设计空间首页的生图 / 生音入口此前绕过了媒体能力检查，模型没配好时会直接失败并留下空项目；桌面宠物的浮窗在正式版浅色模式下是白底而不是透明。两处都已修复。

## 修复

- **设计空间首页的生图 / 生音改走完整的媒体生成对话框**：从设计空间首页发起图片或音频生成时，现在与在作品里生成完全一致——先给出模型可用性提示，参数控件按该模型实际支持的能力显示，也只提交被支持的参数；只给参考图、不写提示词的用法保留不变。此前这条入口跳过了能力与配置检查，而且会先把项目建好再尝试生成，所以媒体模型没配置或该模型不支持某个参数时，用户看到的是一条直接的失败，外加一个已经建出来的空项目。
- **桌面宠物浮窗在浅色模式下不再是白底**：正式版的宠物窗口在主题初始化阶段被写入了不透明背景色，它覆盖了应用启动后才生效的透明样式，于是浮窗在浅色模式下显示成一块白色方块。现在宠物窗口从加载第一帧起就保持透明，普通窗口的浅色 / 深色背景不受影响。

## 变更

- **macOS 安装包体积增加约 10 MB**：0.24.0 之后 macOS 发版构建时间涨到了约 173 分钟，这一版把该平台切到更高的并行编译档位，构建时间压回约 89 分钟，代价是编译器跨模块内联变弱、二进制变大。Linux 与 Windows 的编译档位没有改动，不受此项影响。另外内置的评测 sidecar 出于同样原因在所有平台各增加约 1.7 MB。这两处都只影响下载体积，功能与运行表现不变。

## 升级提示

本版没有配置迁移、没有行为变更，也没有需要注意的兼容性问题，直接更新即可。macOS 用户会注意到下载包比 0.24.0 大一些，原因见上。

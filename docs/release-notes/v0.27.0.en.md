# Hope Agent 0.27.0 — Mirrored Distribution and Request Recovery

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.27.0/docs/release-notes/v0.27.0.md) · **English**

> Release date: 2026-07-31

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.27.0/CHANGELOG.md#0270---2026-07-31) for details.

v0.27.0 is about getting installed and staying running. Installers and automatic updates now also live on a Cloudflare R2 mirror, so reaching GitHub is no longer a requirement; and when a model request hits a rate limit, an overload, or a timeout, the app works its way back on its own — retrying, rotating keys, falling back to another model — and shows that as progress you can take over mid-flight, instead of stopping at a single error line. The macOS "I clicked Grant and nothing happened" permission path is fixed too.

## Added

- **Installers and automatic updates now have a Cloudflare R2 mirror, so GitHub access is no longer required**: installers for every platform are published to `https://repo.hopeagent.ai/download/` as well (the same domain as the apt / dnf repositories), every manual download entry in the README carries a stable mirror link, and past versions are kept indefinitely under their own version number rather than being replaced by newer ones. Desktop automatic updates now read the mirror first and fall back to GitHub — users who could not reach GitHub previously could neither install nor update. Installers fetched by the in-app updater are verified against the built-in public key, and the mirror goes through exactly the same check as GitHub, so a tampered mirror cannot push a non-official build through automatic updates. Manual downloads are installed by your OS and do not pass through that check — the same as manual downloads from GitHub.
- **Agent settings support restoring defaults in one click**: the Agent tab (model, subagents, approvals) and the Tools and Skills capability subtabs each gained a Restore defaults control. After a confirmation, the current tab returns to the defaults shipped with this version — but the result lands as a draft for you to review, and only takes effect when you click Save. Providers and credentials, memories, knowledge spaces, tasks, and artifacts are untouched.

## Changed

- **Model requests keep recovering after a failure, with progress you can control**: rate limits, overloads, timeouts, and unknown errors get bounded retries appropriate to the call site, then rotate through the remaining usable keys on the same provider, then fall back down the model chain — and after a timeout or unknown failure has exhausted the whole chain, one more round is attempted. Deterministic errors such as authentication, billing, and unknown-model still skip straight past pointless retries. The main chat and IM surfaces show retry, key rotation, model fallback, and full-chain recovery notices, and the desktop / web notice card offers a countdown, retry now, and switch model. Once a tool has started executing, neither the same model nor the whole chain is restarted; concurrency-safe read-only tools can still move to the next model not yet tried this turn, while tools that may change external state stop all automatic replay.
- **Adding an existing project lets you choose whether to create AGENTS.md**: when the selected directory has no project instruction file, a create option appears, enabled by default. Turn it off and the project is added on its own — saving, read-only viewing, restart migration, and ordinary metadata edits will not quietly create the file later. Saving project instructions also validates the file's existence and content hash as of the read, so external creation, deletion, or modification blocks a stale draft from overwriting it.
- **The About page now describes what the product actually does**: the opening and closing copy is rewritten, the three legacy highlights are replaced by four capability areas — execution, memory and knowledge, design delivery, and long-running cross-surface work — and the layout moves to two columns, so Goal / Workflow, multi-agent work, Knowledge Space, Design Space, scheduled tasks, and ACP are no longer missing. All 12 locales are updated. Update checks and update behavior are unchanged.
- **`@skill` mentions use lightweight inline styling**: the tinted background, border, rounded chip shape, and shadow are gone, replaced by inline typography with an icon and a restrained per-skill label color, shared between the composer and sent messages. Mentions also align to the label's real text baseline, so text typed right after a mention no longer sits vertically offset. Browser control mentions use Chrome blue; Mac control mentions use the system foreground color.
- **The running-state shimmer is slower**: the shared text shimmer cycle goes from 2.5 seconds to 4 seconds, applying to both Pet bubbles and running states in the conversation list, so it no longer sweeps past often enough to pull your attention.

## Fixed

- **The macOS system permission grant path is fixed end to end**: clicking Grant for Accessibility now actually triggers the system prompt and registers Hope Agent in the System Settings list — previously you were sent there to find no entry to enable. Screen recording now recognizes the "already enabled in System Settings, pending an app restart" state and shows a dedicated status and hint instead of reporting Not granted forever, and screen recording / input monitoring failures come with troubleshooting hints.
- **The system permission panel can reset a stale grant record in one click**: Accessibility, Screen Recording, and Input Monitoring gained a Reset record action while ungranted. After a confirmation it clears the decision macOS has stored and offers a restart entry, after which granting again works — no more typing `tccutil` by hand. This is for the case where System Settings shows Allowed but the app still reports Not granted, usually a leftover record from an older build. Already-granted items do not show the action, so a valid grant cannot be deleted by mistake.
- **Desktop streaming voice input is no longer blocked by CSP**: the PCM16 AudioWorklet is loaded from a same-origin static asset instead of a Blob URL, which Tauri's `script-src` forbids. Capture start failures, runtime errors, user cancellation, and component unmount all clean up the backend STT session, and microphone permission errors now surface consistently.
- **Markdown external-link icons no longer need a hover to load the site favicon**: web links load their site icon as they approach the viewport, without needing the pointer or focus first. Off-screen history stays lazily loaded, requests still share the existing cache, concurrency, and count limits, and a failed load keeps showing the generic web placeholder icon.
- **Leaving the memory claims page no longer bounces you back to Settings**: switching from claims to chat, Dashboard, or another top-level view now clears the leftover `#memory/...` focus state in the URL, so it is no longer reinterpreted as a fresh deep link that reopens Settings → Memory → Claims. Entering the memory page through a deep link still works.
- **Title-bar panel badges are no longer clipped**: the running-count badges on the Background Tasks and Agent panel buttons are no longer cut off at the horizontal scroll boundary.

## Upgrade notes

There are no config migrations and no breaking compatibility changes in this release — just update.

**One timing note about the mirror**: the update-check endpoints are compiled into the binary, so your current 0.26.0-or-earlier install will still check GitHub this one time. If you cannot reach GitHub, download the 0.27.0 installer from the mirror links in the README and install over your current version; from then on every automatic update will try the mirror first.

Restore defaults in Agent settings restores **the defaults shipped with this version**, not your last saved values. Review the resulting draft before clicking Save — navigating away discards it.

# Hope Agent 0.27.0 — Mirrored Distribution and Request Recovery

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.27.0/docs/release-notes/v0.27.0.md) · **English**

> Release date: 2026-07-31

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.27.0/CHANGELOG.md#0270---2026-07-31) for details.

This release is about getting installed and staying running. Installers and automatic updates now have a second address that works where GitHub does not; a model request that hits a rate limit or a timeout recovers on its own instead of stopping at an error; and on macOS, clicking Grant no longer does nothing.

## Added

- **Installers and updates have a second address, so GitHub access is no longer required**: every platform's installer is also published to `https://repo.hopeagent.ai/download/`, and every download link in the README has a mirror alternative. The desktop app checks the mirror first and falls back to GitHub. Past versions stay available, so older download links keep working after a new release. Automatic updates still verify the official signature — using the mirror does not weaken that.
- **Agent settings can be restored to defaults in one click**: the Agent tab, plus the Tools and Skills subtabs, each gained a Restore defaults control. You get a draft to review first; nothing changes until you click Save. Providers and keys, memories, knowledge spaces, tasks, and artifacts are left alone.

## Changed

- **Model requests recover on their own, and you can take over at any point**: on a rate limit, an overload, or a timeout, the app retries, switches to another key from the same provider, and falls back to a backup model when needed — with the current step visible in both the main chat and IM. The notice card offers a countdown, Retry now, and Switch model. Errors that retrying cannot fix (bad credentials, insufficient balance) are surfaced immediately instead of wasting your time. A turn that already started running a tool is never replayed automatically, so nothing runs twice.
- **Adding an existing project lets you skip creating AGENTS.md**: when the folder has no project instruction file, you are asked whether to create one (default yes). Turn it off and only the project is added — it will not be created quietly later either.
- **The About page was rewritten**: it now covers four areas — execution, memory and knowledge, design delivery, and long-running cross-device work — and includes Goal / Workflow, multi-agent work, Knowledge Space, Design Space, scheduled tasks, and ACP. All 12 languages updated.
- **`@skill` mentions are lighter**: the tinted block, border, and shadow are gone, replaced by an icon and colored text that sits better in the surrounding prose. Text typed right after a mention no longer appears vertically offset.
- **The running-state shimmer is slower**: its cycle went from 2.5 to 4 seconds, so it no longer flickers often enough to pull your attention.

## Fixed

- **Fixed: clicking Grant on macOS did nothing**: Accessibility now actually opens the system permission prompt and adds Hope Agent to the System Settings list — previously you were sent there to find nothing to enable. If you already enabled Screen Recording in System Settings but have not restarted the app, it now says "restart to take effect" instead of reporting Not granted forever.
- **A stuck permission can be reset in one click**: Accessibility, Screen Recording, and Input Monitoring gained a Reset record action while ungranted. Confirm it and macOS forgets its old decision, so granting again works — no `tccutil` in a terminal. This is for the case where System Settings says Allowed but the app insists otherwise, usually a leftover from an older build. Already-granted items do not show the action, so nothing valid gets removed by accident.
- **Fixed: desktop voice input would not start**: live voice input was blocked by a security policy on desktop and recorded nothing. It works again, the background transcription session is now closed when capture fails, errors out, or you cancel it, and microphone permission errors read consistently.
- **Fixed: link icons only appeared after hovering**: web links in messages now load the site's icon as you scroll near them.
- **Fixed: leaving the memory page sent you back to it**: after viewing claims under Settings → Memory, switching to chat or the Dashboard no longer bounces you back.
- **Fixed: a clipped corner on title-bar count badges**: the running-count badges on the Background Tasks and Agent panel buttons are now fully visible.

## Upgrade notes

There are no config migrations and no breaking changes — just update.

**The mirror does not help this time**: your current 0.26.0-or-earlier install will still check GitHub for this one update. If you cannot reach GitHub, download 0.27.0 from the mirror links in the README and install it manually; every update after that will try the mirror first.

Restore defaults in Agent settings restores **the defaults shipped with this version**, not your last saved values. Review the draft before clicking Save — leaving the page discards it.

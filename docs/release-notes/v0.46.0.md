# Hope Agent 0.46.0 — 新模型选择与更稳定的对话体验

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.46.0/docs/release-notes/v0.46.0.en.md)

> 发布日期：2026-09-08

> 完整变更见 [更新日志](https://github.com/shiwenwen/hope-agent/blob/v0.46.0/CHANGELOG.md#0460---2026-09-08)。

## 连接新模型，按工作区使用 Claude

新建连接时，现在可以选择 GPT-6 Astra 和 Claude Fable 5.1 预设。通过官方 OpenAI 服务使用 Astra 工具对话时，请选择 OpenAI Responses。Together 的 DeepSeek V4 Pro 预设也已更新，Cerebras 已退役的公共预设已移除。已有连接不会自动改动，需要时请自行添加模型或调整协议。

使用 Anthropic 多工作区密钥时，可在设置中的对应密钥条目开启“多工作区密钥”并填写工作区 ID。不同工作区请分别创建连接；已有专属工作区密钥无需开启此选项。

## 新会话沿用你的默认选择

添加新连接后，原来的默认模型会继续保留。默认连接被禁用时，新会话会选择可用的备用模型或其他已启用模型，减少反复手动切换。

## 更清楚地处理等待与思考记录

模型服务要求等待后重试时，应用会遵守其最短等待时间；服务明确阻断请求时，会停止自动重试和切换。

Claude 的原始思考记录会随对话保存。如果对话内容整理或切换模型使部分历史思考无法继续使用，回复中会给出提示，方便你判断是否需要补充上下文。

## 链接提示保持一致

带标题的网页、本地文件和其他 Markdown 链接，现在统一使用应用内的悬浮提示样式。

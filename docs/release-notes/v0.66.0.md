# Hope Agent 0.66.0 — 更多模型与 Kimi 搜索

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.66.0/docs/release-notes/v0.66.0.en.md)

> 发布日期：2026 年 10 月 15 日

> 完整改动列表见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.66.0/CHANGELOG.md#0660---2026-10-15)。

## 用 ChatGPT 账号选择 GPT-6

在模型设置中使用 ChatGPT / Codex 登录后，可以选择 GPT-6 Astra、GPT-6.1 Sol、GPT-6 Sol 和 GPT-6 Luna。升级会补齐缺失的模型，保留当前选择、自定义设置和禁用状态；实际可用型号仍取决于你的套餐和工作区权限。

## 按服务商选择更多稳定模型

模型设置新增 Claude Haiku 5.5、Grok 4.7、MiniMax M3，以及 Fireworks、OpenRouter 和 Together 的多项稳定模型候选。输入完整模型 ID 时，大小写完全匹配的候选优先显示；Together 的思考内容也能随回复显示。

不同服务商的输入能力、上下文和报价仍有差异，请按候选来源选择。目录会清理明确退役或限制新用户访问的部分候选，已有连接保留原设置；旧型号的可用性和替代计费请向服务商核对。目录价格与大盘估算不能替代实际账单。

## 继续使用 Kimi 网页搜索

已配置的 Kimi 搜索 Key 可以继续使用，搜索直接返回链接和摘要。指定国家、语言或时效过滤时，会提示该服务不支持这些条件，并尝试后续已启用的搜索服务；不会静默忽略你的要求。实际搜索质量与账户费用仍需按使用情况核验。

操作入口、思考设置差异与服务商限制见[模型与服务商手册](https://github.com/shiwenwen/hope-agent/blob/v0.66.0/docs/user-guide/02-模型与Provider.md)。

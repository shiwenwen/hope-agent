# Hope Agent 0.36.1 — Fixes launch failures after upgrading

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.36.1/docs/release-notes/v0.36.1.md) · **English**

> Released: 2026-08-26

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.36.1/CHANGELOG.md#0361---2026-08-26) for the full list.

This emergency release fixes an issue where Hope Agent could repeatedly bounce in the Dock without opening after some users upgraded from an older version.

## Fixed

- **Legacy databases recover automatically**: Hope Agent now clears invalid state left by an earlier failed upgrade before safely completing the required migration.
- **Existing data is preserved**: The repair does not delete conversations, messages, or worktree records.
- **Unaffected installations continue normally**: Installations that already completed the migration or use a new database do not receive unnecessary changes.

## Upgrade notes

Update and reopen Hope Agent. Affected users do not need to delete `sessions.db` or clear application data.

# Hope Agent 0.42.0 — DeepSeek image understanding

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.42.0/docs/release-notes/v0.42.0.md) · **English**

> Released: 2026-09-04

> See [the changelog](https://github.com/shiwenwen/hope-agent/blob/v0.42.0/CHANGELOG.md#0420---2026-09-04) for the full list.

New direct DeepSeek connections can now select DeepSeek V4 Flash Vision Exp for image understanding while retaining its million-token context window and reasoning support. Preset cost estimates for DeepSeek V4 Flash and Pro now use the current peak rates, so the Dashboard no longer understates peak-period costs.

To use the vision model with an existing DeepSeek connection, add `deepseek-v4-flash-vision-exp` under Settings → Models, or create a new DeepSeek connection.

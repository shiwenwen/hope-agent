# Hope Agent 0.24.0 — 桌面宠物与提问原地编辑

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.24.0/docs/release-notes/v0.24.0.en.md)

> 发布日期：2026-07-27

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.24.0/CHANGELOG.md#0240---2026-07-27)。

v0.24.0 把「现在跑到哪了」搬到桌面上：新增一只常驻桌面的宠物，用气泡投影主对话的运行中、待输入、失败与未读完成状态，可以直接在气泡里回复、停止任务、答题和处理审批，而且兼容 Codex 现有的宠物包。另一半是对话本身的手感：最后一条提问现在可以直接改完重发，不必再靠分支或重新打字。

## 亮点

- **新增 Codex 兼容桌面宠物**：从侧边栏底部的开关或「设置 → 桌面宠物」开启（默认关闭），一只透明浮窗宠物会常驻桌面。它把主对话的四种状态投影成气泡——运行中（带实时流式预览）、待输入、失败、未读完成——收起时只在宠物右上角显示一个数量圆点，展开后每条对话一个胶囊气泡。气泡上可以直接快捷回复、停止当前任务，`ask_user_question` 与工具审批也有专属紧凑卡片，不用切回完整对话就能处理；点击气泡正文会跳回对应对话，普通对话、知识空间与设计空间都按类型正确恢复。宠物本身可以拖着走，右键出「设置 / 关闭」，单击唤起主窗口。
- **宠物包与 Codex 互通，导入全程要你确认**：可从 Codex 现有安装目录扫描导入，也支持拖入目录 / zip / 精灵图、粘贴 `codex://` 与 `hope-agent://` 链接、由 `hope-agent://` 系统协议唤起，或在设置里用生图直接创建一只。所有入口一律走「预览 → 校验 → 确认」三步，不会静默安装或启用；已安装的宠物可以导出成 Codex 兼容的最小 zip。删除走回收站并支持 10 分钟内撤销。首次使用会在侧边栏彩蛋图标旁显示一次性、非模态的发现提示，不抢焦点。
- **最后一条提问支持原地编辑重发**：本轮回复结束或被你停止之后，把鼠标移到自己最后一条提问上即可原地编辑，改完发送就以新内容重跑这一轮。附件、Goal 元数据与 Provider 基础上下文都会原样保留，会话尾部由一次原子事务重写，不会出现新旧消息混排。此前想改一句话只能开分支或重新打字，现在直接改。

## 升级提示

- **桌面宠物默认关闭，浮窗是桌面专属**。开启入口在侧边栏底部与「设置 → 桌面宠物」。HTTP / Web 端可以管理宠物库与选择哪只宠物，但不能开关浮窗，相关窗口命令会明确返回「桌面专属」。
- **编辑重发会丢弃这条提问之后的所有消息，且不回滚文件**。发送编辑内容时，这条提问之后的回复与后续消息会被删除并按新内容重跑；但上一轮已经写入磁盘的文件修改**不会**自动撤回——编辑框会就此给出提示，需要回退文件请自行用 Git 等方式处理。另外，流式回复进行中、有排队消息、slash 命令消息，以及定时任务与子 Agent 的会话查看器都不提供编辑入口。
- **宠物只投影第一方主对话**。主聊天、QuickChat、知识空间、设计空间以及宠物快捷回复会出现在宠物上；side query、自动化、上下文压缩、记忆、Cron、IM、ACP、子 Agent 与后台任务不会。无痕对话的标题与预览始终脱敏，公共 `/api/chat` 调用不会因为传了 `uiSurface` 就被接入。

## 变更

- **撤回 0.23 的 Linux 视觉降级，毛玻璃与系统字体回来了**：0.23 为缓解 Linux 下滚动时文字周期性发虚，全局关掉了 `backdrop-filter` 并强制 Noto 字体栈。报告者在 KDE/KWin Wayland、1.0 缩放环境下复测仍能复现，说明当时「透明窗口 + 毛玻璃 + 分数缩放」的假设不成立，那次降级只是白白牺牲了 Linux 桌面版的观感。本版把毛玻璃效果与系统字体选择还给 Linux。发虚问题**尚未解决**，根因更可能是 WebKitGTK / wry 在 Wayland 下窗口尺寸与 WebView 渲染尺寸不同步，继续跟踪上游 [wry #1727](https://github.com/tauri-apps/wry/issues/1727)；0.23 里较窄的 Linux 窗口透明度防御与 Windows 启动居中修复不受影响，仍然保留。

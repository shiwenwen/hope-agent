# Hope Agent 0.65.0 — Model selection and request safety

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.65.0/docs/release-notes/v0.65.0.md) · **English**

> Released: October 13, 2026

> See the [changelog](https://github.com/shiwenwen/hope-agent/blob/v0.65.0/CHANGELOG.md#0650---2026-10-13) for the complete list of changes.

## Choose models from long lists

When a provider or model list is long, scroll the menu to reach its final entries. This works for the default model, fallback models, and an Agent's plan-mode model, including in smaller windows.

## Confirm your provider's final address

Model, image, and audio requests no longer automatically follow endpoint redirects, helping prevent keys and private inputs from being forwarded to another address. Connection tests report redirects as failures. Confirm the final API address with your provider, update the Base URL, and retry.

## More reliable PDF text reading

PDF text is read from the actual pages, with blank pages preserved. A damaged later page reports a failure instead of presenting only the earlier pages as a complete document.

This release also updates security dependencies for the desktop app, document parsing, networking, and editing. Existing configurations and conversations remain usable. Design Space keeps its existing video export approach; when browser capabilities are insufficient, follow the prompts to install export dependencies.

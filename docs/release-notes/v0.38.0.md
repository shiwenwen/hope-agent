# Hope Agent 0.38.0 — 主任务继续，侧聊随时追问

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.38.0/docs/release-notes/v0.38.0.en.md)

> 发布日期：2026-08-31

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.38.0/CHANGELOG.md#0380---2026-08-31)。

主对话正在处理任务时，也可以顺手问清一个概念、核对一段回答，或讨论另一种思路。这一版新增侧聊，让这些追问在右侧独立展开，不打断主任务。

## 随手开启一段侧聊

- **用命令或选中文字发起追问**：输入 `/side 你的问题`，或选中对话中的文字后打开侧聊，即可承接当前对话已经完成的上下文继续讨论。
- **同时保留多个讨论方向**：侧聊与主对话可以同时生成；不需要一直盯着面板，收起后仍可看到运行或完成提示，随时重新打开查看结果。
- **按追问需要选择模型与附件**：侧聊支持独立选择模型、添加附件和使用工具，适合把细节问清后再回到主任务。

## 使用提示

直接更新即可，无需手动调整设置。侧聊保存在所属主会话中，不会挤占普通会话列表；永久删除主会话也会删除其侧聊。计划与工作流模式请继续在主对话中使用。

# Hope Agent 0.37.0 — 工具调用与桌面体验更可靠

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.37.0/docs/release-notes/v0.37.0.en.md)

> 发布日期：2026-08-30

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.37.0/CHANGELOG.md#0370---2026-08-30)。

这一版修复了 OpenAI Responses 与 Codex 在工具调用后的续答问题，并恢复安装版文件预览的语法高亮，同时让桌面宠物的右键菜单在切换窗口时自然收起。

## 修复

- **OpenAI 与 Codex 工具调用不再中途报错**：知识空间等工具执行成功后，对话可以继续完成；并行调用多个工具时也能分别接续正确结果。
- **安装版文件预览重新显示语法颜色与行号**：JSON、代码和其他文本文件不再显示成难以阅读的无颜色纯文本；偶发加载失败后，后续预览也能正常恢复。
- **宠物菜单会随窗口切换自动收起**：桌面宠物的右键菜单在焦点移到其他窗口后不再残留，返回宠物窗口即可继续正常操作。

## 升级提示

直接更新即可；无需迁移数据或调整设置。

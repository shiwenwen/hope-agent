# Hope Agent 0.34.0 — 右侧面板合成一个工作台

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.34.0/docs/release-notes/v0.34.0.en.md)

> 发布日期：2026-08-19

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.34.0/CHANGELOG.md#0340---2026-08-19)。

对话右侧过去是一堆各自开合的面板：看文件、看改动、看计划、看画布、看浏览器、看子 Agent，各有各的入口和宽度。这一版把它们收进同一排标签，成为一个可以拖拽重排、整体最大化、随时收起的工作台，宽度会跟着窗口自动适配。

文件标签也补齐成了一个真正的文件浏览器：可以只看预览、可以同时开好几个文件对照着看，路径变成能点的面包屑。看不见的标签不再在后台空转，长时间开着 Hope Agent 会更安静。

## 新增

- **对话右侧改为分栏工作台**：文件、Workspace、Diff、计划、Canvas、浏览器和子 Agent 收进同一排标签，可以拖拽重排、整体最大化或收起，宽度按窗口自动适配，不必再逐个面板开合。
- **文件标签就是一个完整的文件浏览器**：左侧文件列表可以收起，把空间全留给预览；选文件只更新当前标签，需要并排对照时右键「在新标签中打开」或用 `+` 新开一个。预览顶部的路径变成可点面包屑，点某一级目录就跳回对应的文件列表。

## 变更

- **看不见的标签不再在后台空转**：切到别的标签后，工作流、循环、代码审查、验证、质量复核、后台任务输出和 PR 检查的轮询会暂停，切回来时立即刷新。标签上的角标计数不受影响，仍然照常提醒你。

## 修复

- **展开「已处理」不再冒出多余的操作按钮**：复制、编辑、分叉、详情这排按钮只属于本轮的最终回复，折叠详情里的中间步骤不再各自带一排。
- **后台任务里的子 Agent 行不再有点不开的展开箭头**：这类行只保留「查看子会话」入口，展开箭头只出现在确实有进度、输出或结果的任务上。
- **Canvas 恢复可达**：没有打开任何工作台标签时，模型创建的画布也会正常弹出；关掉的画布标签不会自己回来，关闭画布后主窗口也能重新缩窄。
- **文件标签之间不再互相牵连**：关掉一个文件标签只会询问并丢弃它自己的未保存修改；用面包屑跳目录、从引用跳文件同样会先提示保存，不再静默覆盖你正在编辑的内容。
- **新对话发出第一条消息时，已打开的文件标签与预览不再消失**，也不会在下次「新建对话」里冒出上一段草稿留下的标签。
- **窄窗口下的布局不再被改坏**：拖动侧栏不会永久改小你的宽度偏好，自动收起工作台后再打开也不会变成盖住整屏的浮层，会话信息卡在窄窗口里改为覆盖显示，不再出现按钮点了没反应。
- **工作台标签本身更可靠**：只剩浮动窗口时不会留下一条空标签条，点浮动标签会先把它停靠回来，键盘重排在两端停住，取消掉的拖拽不会在之后导致顺序错乱。
- **从 Diff 跳到某一行会重新定位并高亮**；多源文件夹或 worktree 下的「在新标签中打开」不再没有反应；收起文件列表也不会连带藏掉「独立窗口」入口。

## 升级提示

直接更新即可，无需手动迁移配置。

首次打开时，对话右侧的面板会按新的工作台重新排列，之后你的标签顺序、宽度和收起状态都会被记住。

# Hope Agent 0.38.0 — Ask on the side while your main task continues

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.38.0/docs/release-notes/v0.38.0.md) · **English**

> Released: 2026-08-31

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.38.0/CHANGELOG.md#0380---2026-08-31) for the full list.

While your main conversation works on a task, you can clarify a concept, check part of an answer, or explore another approach. This release adds side chats that open on the right and keep those questions separate without interrupting the main task.

## Start a side chat whenever you need one

- **Ask with a command or selected text**: Enter `/side your question`, or select text in the conversation and open a side chat to continue from the main conversation's completed context.
- **Keep several discussions going**: Side chats and the main conversation can generate responses at the same time. Collapse a panel and still see running or completion indicators, then reopen it whenever you want to read the result.
- **Choose the model and attachments for each question**: Side chats support their own model selection, attachments, and tools, so you can work through details before returning to the main task.

## Usage notes

Update directly; no manual settings changes are needed. Side chats belong to their main conversation and stay out of the regular conversation list. Permanently deleting the main conversation also deletes its side chats. Continue using plan and workflow modes in the main conversation.

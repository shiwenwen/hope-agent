# Hope Agent 0.71.0 — 图像与转写新预设，减少配置误操作

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.71.0/docs/release-notes/v0.71.0.en.md)

> 发布日期：2026 年 10 月 30 日

> 完整改动列表见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.71.0/CHANGELOG.md#0710---2026-10-30)。

## 新建图像服务商时有更多画幅选择

在设置中新建 Google 图像服务商，首选预设更新为 Nano Banana 2.1，可选更宽或更长的画幅。图像工具与 Agent 的图像产物生成可使用最多 14 张参考图；设计空间首页仍最多 5 张。现有模型和默认链不会自动更换，当前接入不支持蒙版重绘或视频、PDF 输入。新型号的真实画质与费用尚未验收。

## 按录音方式选择转写预设

新建 xAI 语音识别服务商时预填 Grok Voice Transcribe 2.0，用于录完后转写；新建 AssemblyAI 服务商首选 Universal-3.6 Pro Streaming，用于流式转写。已有配置由你自行决定是否更换，AssemblyAI 仍不能作为 IM 自动转写的兜底。新型号的实际识别率与费用尚未验收。

## 填写模型参数时保留草稿

在添加或编辑服务商时打开“发现模型”，误点弹窗外部不会再关闭窗口、丢失已填写的参数。完成后可点“添加”；也可用“取消”、关闭按钮或 Esc 退出。新增模型仍需保存服务商才会生效。

## 飞书排障更少暴露敏感内容

飞书获取访问令牌失败时，只显示状态或错误代码。排查时请提供代码，不要复制 App Secret 或访问令牌。这项修复只覆盖获取令牌时的报错；其他飞书接口仍需单独核验。

升级提示：已有图像与转写配置不会自动迁移；按需在设置中手动核对型号和费用。操作说明见[模型与服务商手册](https://github.com/shiwenwen/hope-agent/blob/v0.71.0/docs/user-guide/02-模型与Provider.md)。

# Hope Agent 0.26.0 — 工作区常驻与独立窗口

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.26.0/docs/release-notes/v0.26.0.en.md)

> 发布日期：2026-07-30

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.26.0/CHANGELOG.md#0260---2026-07-30)。

v0.26.0 围绕「多个工作区同时用」这件事：侧边栏的一级工作区切走再回来会停在原地而不是回首页，知识空间和设计空间还能整个弹成独立窗口，和主窗口并排放。设计空间的设备预览也从三档粗分类换成了机型列表加自定义视口。此外修掉了 Azure Speech 语音输入固定报 400 的问题。

## 新增

- **知识空间与设计空间支持桌面独立窗口**：在桌面版中右键侧边栏图标选「在独立窗口打开」，或直接双击图标即可弹出；空间标题栏也能随时把当前工作区弹出，并从独立窗口收回主窗口。同一个空间只保留一个独立窗口，重复点击会聚焦已有窗口。知识空间在弹出、收回或点系统关闭按钮之前都会先处理未保存的笔记，让你选择保存、放弃或取消。
- **设计空间设备预览新增主流机型与自定义视口**：桌面、平板和手机三个粗档位换成了分组选择器，内置 iPad、Surface、iPhone、Pixel 与 Galaxy 等常用机型的 CSS 逻辑尺寸；自定义模式可以直接填宽高，也可以拖预览框的右边、底边和右下角。选中的机型与自定义尺寸按产物分别记住。拖拽期间会固定起始显示缩放并锚定左上角，避免居中适配把手柄从指针下面挪开。

## 变更

- **侧边栏主要工作区切换后保留现场**：主对话、定时任务、数据大盘、计划、知识空间、设计空间和产物库首次打开后会保持挂载，切去别的页面再回来仍停在原会话、项目、笔记、产物或筛选位置。设置以及 Agent / 模型 / 技能 / 记忆 / 渠道等配置页仍按普通导航页处理，不承诺保留未提交的表单草稿。
- **统一一级工作区导航语义**：定时任务、数据大盘、计划、知识空间、设计空间和产物库的首页不再显示「返回主对话」按钮——一级入口之间统一用主侧栏切换。项目、任务详情这类二级页面仍然保留返回真实上一级的操作。
- **对话滚动到底按钮增加流式状态提示**：滚离最新消息、而回复仍在生成时，按钮外圈会显示一圈从细淡尾迹过渡到柔和光晕的蓝色流星动画，回复结束后恢复普通状态。按钮同时改用独立的浮层底色，在暗色模式下不再和消息列表背景融成一片。
- **桌面开发按需构建 Browser Host 与 Eval Sidecar**（面向开发者）：`pnpm desktop` 可交互选择模式；默认的 `pnpm dev:desktop` 不再等这两个可选二进制，Chrome 插件、评测与完整能力开发分别用 `pnpm dev:desktop:browser`、`pnpm dev:desktop:eval`、`pnpm dev:desktop:full`。生产构建与兼容旧入口 `pnpm tauri dev` 仍会构建两者。

## 修复

- **修复 Azure Speech 语音输入缺少识别语言而固定返回 400**：语音识别的默认参数以前只在配置里存着、没真正带到请求上，桌面端只发了采样率，于是 Azure 端点收不到必需的 `language` 参数、每次都返回 400。现在默认参数会统一应用到桌面流式、批量、IM 与知识空间转写，可以在设置里填 `zh-CN`、`en-US` 等 BCP-47 语言；Azure 缺语言、或把完整 URL 误填进 Region 时，会在联网之前就给出明确的配置错误。
- **修复独立知识空间的来源跳转**：知识空间已经弹成独立窗口时，从对话的记忆轨迹点笔记来源，现在会把完整笔记和行号 / 标题 / block 定位目标一起发给那个窗口，不再只是把窗口聚焦过来、内容还停在上一篇笔记。
- **修复常驻工作区浮层跨页面残留**：Dialog、菜单、Select、Popover、Tooltip 以及对话里的浮动面板现在都归属各自的工作区，切换侧边栏时会暂停隐藏页面的 Portal 内容并释放焦点与鼠标锁，不会再用上一个页面的遮罩盖住新页面；切回来时页面主体状态仍然完整。
- **修复常驻工作区恢复时的过期内容**：设计空间不再因为切换侧边栏而回到首页；产物库与定时任务在重新进入时会刷新列表、详情、运行记录和当前对话，兼顾保留现场与同步外部变更。
- **修复独立空间窗口标题栏布局与交互**：macOS 上动态创建的知识空间 / 设计空间窗口现在和主窗口一样使用 overlay 标题栏，工具栏直接从红绿灯右侧开始，不再多占一行；补齐了动态窗口的拖拽权限，标题栏空白处可以正常拖动窗口。Windows / Linux 继续用原生标题栏，不会引入 macOS 专用的留白。侧边栏右键菜单、空间标题栏以及对话内 Canvas / 文件 / Plan / 控制面板的弹出与收回，现在统一用同一套图标：弹出是方框右上角的对角箭头，收回是方框左下角的对角箭头，不再和登录、退出或普通网页外链的图标语义混淆。

## 升级提示

本版没有配置迁移，也没有破坏兼容性的改动，直接更新即可。

工作区常驻和一级导航的调整会改变桌面端的操作手感：一级工作区之间从此只用主侧栏切换，那几个首页上的「返回主对话」按钮不在了。独立窗口是桌面专属能力，HTTP / Web 端不提供。

如果你在用 Azure Speech 做语音输入，建议顺手去「设置 → 语音识别 → 默认识别语言」填上 `zh-CN` 之类的 BCP-47 值——之前那条固定 400 就是因为这个参数没被带上，现在缺它会在联网前直接报配置错误。

# Hope Agent v0.76.0

[简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.76.0/docs/release-notes/v0.76.0.md) · English

This release patches formula rendering in chats and knowledge notes and fixes a URL parsing issue that could cause the app to exit. Scheduled tasks use an updated expression parser and retain existing expressions and time-zone rules. You can create and open interactive Design Space components as before and keep your existing settings when upgrading.

See the [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.76.0/CHANGELOG.md#0760---2026-11-27) for all changes.

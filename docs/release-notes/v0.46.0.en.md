# Hope Agent 0.46.0 — New model choices and steadier conversations

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.46.0/docs/release-notes/v0.46.0.md) · **English**

> Released: 2026-09-08

> See [the changelog](https://github.com/shiwenwen/hope-agent/blob/v0.46.0/CHANGELOG.md#0460---2026-09-08) for the full list.

## Connect new models and use Claude by workspace

New connections now offer GPT-6 Astra and Claude Fable 5.1 presets. For Astra conversations with tools through the official OpenAI service, choose OpenAI Responses. Together’s DeepSeek V4 Pro preset has also been updated, and retired Cerebras public presets have been removed. Existing connections stay as configured; add models or adjust the protocol when needed.

For an Anthropic multi-workspace key, enable “Multi-workspace key” on the corresponding key entry in Settings and enter the workspace ID. Create separate connections for different workspaces. Existing workspace-scoped keys do not need this option.

## Keep your default choice for new conversations

Adding a connection now preserves your existing default model. If the default connection is disabled, new conversations choose an available fallback or another enabled model, reducing repeated manual switching.

## Understand retry waits and thinking history

When a model service asks the app to wait before retrying, the app respects that minimum wait. If the service explicitly blocks a request, automatic retries and switching stop.

Claude’s original thinking records are saved with the conversation. If conversation cleanup or a model switch makes some earlier thinking unusable, the reply shows a notice so you can decide whether to supply more context.

## Consistent link tooltips

Markdown links with titles now use the app’s tooltip style consistently, including web links, local files, and other links.

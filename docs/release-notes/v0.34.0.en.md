# Hope Agent 0.34.0 — The right-hand panels become one workbench

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.34.0/docs/release-notes/v0.34.0.md) · **English**

> Released: 2026-08-19

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.34.0/CHANGELOG.md#0340---2026-08-19) for the full list.

The right side of a conversation used to be a stack of panels that each opened, closed, and sized on their own — files, diffs, plans, canvas, browser, subagents. This release gathers them into a single row of tabs: one workbench you can reorder by dragging, maximize as a whole, or collapse, with a width that adapts to your window.

The file tab also grew into a real file browser: hide the list when you only want the preview, open several files side by side, and click any part of the path to jump back. Tabs you cannot see no longer poll in the background, so leaving Hope Agent open all day is quieter.

## Added

- **The right side of a conversation is now a tabbed workbench**: Files, Workspace, Diff, Plan, Canvas, Browser, and Subagents share one row of tabs that you can drag to reorder, maximize together, or collapse, sized automatically to your window instead of opened panel by panel.
- **The file tab is a complete file browser**: Collapse the file list to give the preview all the space. Selecting a file updates the current tab, and when you want two files side by side, use "Open in new tab" from the context menu or the `+` button. The path above the preview is now a breadcrumb — click any directory to jump back to that listing.

## Changed

- **Tabs you cannot see stop polling in the background**: When you switch away, polling for workflows, loops, code review, verification, quality review, background task output, and PR checks pauses and refreshes the moment you return. Tab badge counts are unaffected and keep notifying you as before.

## Fixed

- **Expanding "handled" no longer adds a second row of actions**: Copy, edit, fork, and details belong to the turn's final reply, so intermediate steps inside collapsed details no longer carry their own row.
- **Subagent rows in background tasks no longer show an arrow that does nothing**: Those rows keep only the "view subagent conversation" entry, and the expand arrow appears only where there is real progress, output, or a result.
- **Canvas is reachable again**: A canvas the model creates opens even when no workbench tab is active, a canvas tab you closed stays closed, and the main window can shrink back after you close one.
- **File tabs no longer affect each other**: Closing one file tab only asks about — and discards — its own unsaved edits. Jumping via breadcrumb or from a mention also prompts to save first instead of silently overwriting what you were editing.
- **Open file tabs and previews survive the first message of a new conversation**, and leftover tabs from an earlier draft no longer reappear the next time you start one.
- **Narrow windows no longer corrupt your layout**: Dragging the sidebar does not permanently shrink your width preference, reopening an auto-collapsed workbench no longer covers the whole screen, and the session info card overlays instead of leaving a button that does nothing.
- **The workbench tab strip is more reliable**: No empty strip is left behind when only floating windows remain, clicking a floating tab docks it back first, keyboard reordering stops at both ends, and a cancelled drag no longer scrambles the order afterwards.
- **Jumping to a line from a diff re-locates and highlights it**; "Open in new tab" works with multiple source folders and worktrees; and collapsing the file list no longer hides the "separate window" entry.

## Upgrade notes

Update directly — no manual configuration migration is needed.

The first time you open a conversation, the right-hand panels are rearranged into the new workbench. After that, your tab order, width, and collapsed state are remembered.

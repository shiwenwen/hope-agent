# Hope Agent 0.42.0 — DeepSeek 图片理解

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.42.0/docs/release-notes/v0.42.0.en.md)

> 发布日期：2026-09-04

> 完整变更见 [更新日志](https://github.com/shiwenwen/hope-agent/blob/v0.42.0/CHANGELOG.md#0420---2026-09-04)。

使用 DeepSeek 直连时，新建连接现在可直接选择 DeepSeek V4 Flash Vision Exp，让对话理解图片，同时保留百万级上下文与推理能力。DeepSeek V4 Flash 与 Pro 的预设费用改按当前高峰费率估算，大盘在高峰时段不再低报成本。

已有 DeepSeek 连接如需使用视觉模型，可在「设置 → 模型」中加入 `deepseek-v4-flash-vision-exp`，或新建一个 DeepSeek 连接。

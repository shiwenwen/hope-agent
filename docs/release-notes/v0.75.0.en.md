# Hope Agent v0.75.0

[简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.75.0/docs/release-notes/v0.75.0.md) · English

This is a dependency maintenance update with no new features or settings.

- Updates dependencies used for MCP connections while retaining existing external-tool connections and sign-in flows. Server configuration does not need to be recreated.
- Updates compression, encryption and networking dependencies. Desktop deep links and PDF support retain their existing compatible versions.

Existing settings can be kept after upgrading. This update does not add MCP Skills support or establish compatibility through testing with real accounts, devices or model services.

See the [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.75.0/CHANGELOG.md) for the full change list.

# Hope Agent v0.75.0

[简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.75.0/docs/release-notes/v0.75.0.md) · English

Hope can now follow through on delegated work in the background, notice changes in files you explicitly share, prepare options, and report back when there is a result or a decision to make.

- **Hand off the follow-through**: Tell Hope what to keep working on. Progress, unanswered questions and results stay connected to that work. Arrange a later check when waiting on an external condition, and stop any item at any time. Follow-through has an allowance and an expiry; continuing after either is reached requires your explicit decision.
- **Let Hope watch shared information**: Enable proactive research in assistant settings and select local text files you want to share. Hope can prepare findings and options grounded in those files, and you can ask follow-up questions about them. Proactive research is off by default.
- **Choose where feedback reaches you**: Proactive updates stay in Hope by default. You can separately choose desktop or dedicated Telegram notices, your timezone and quiet hours. Desktop notices require system permission; Telegram must be paired first. Desktop-delegated work needs a separate notice opt-in and permission for the relevant work chat before its status can go to Telegram. File summaries require permission for every source involved. Reply to a Telegram file summary to continue; select an item in a combined message with `2: your question`. Direct questions and approvals in Hope can use desktop reminders; they are not forwarded to Telegram. Tool approvals stay in Hope.
- **Keep interruptions useful**: Routine progress stays in Hope, and proactive external notices are held while you actively view the assistant Home. Viewed updates are not pushed again; resuming notices does not replay updates from the paused period.
- **Keep the conversation simple**: Hope uses its own logo by default. The main screen focuses on chat, with model, permission, work-item and workbench controls available when needed.

Background follow-through requires the Hope desktop app or service to remain running; server mode requires an Owner Token. Shared files must be on the host running Hope, within an authorized work chat’s working directory. If you use both the desktop app and a standalone server, update both to this release. Existing connections and settings can be kept. This release also includes maintenance updates for MCP connections and core dependencies.

See the [chat and sessions guide](https://github.com/shiwenwen/hope-agent/blob/v0.75.0/docs/user-guide/en/03-chat-and-sessions.md) for usage and the [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.75.0/CHANGELOG.md) for all changes.

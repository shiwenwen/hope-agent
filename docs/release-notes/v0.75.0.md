# Hope Agent v0.75.0

简体中文 · [English](https://github.com/shiwenwen/hope-agent/blob/v0.75.0/docs/release-notes/v0.75.0.en.md)

Hope 现在能接住一句交办，在后台持续跟进，也能从你明确共享的资料中发现变化、准备方案，并在需要你决定或已有结果时反馈。

- **把后续工作交给 Hope**：直接交代要继续处理的事，Hope 会保留跟进进展、待答问题和实际结果。需要等待外部条件时可约定复查；你能随时停止单项工作。跟进有额度和有效期，用尽或到期后需要你明确决定是否继续。
- **让 Hope 留意资料变化**：在助手设置中开启主动研究，选择愿意共享的本地文本资料。Hope 会准备有依据的发现和方案，你也可以围绕这些资料继续追问。主动研究默认关闭。
- **在合适的地方收到反馈**：主动更新默认留在 Hope。你可另选桌面或专属 Telegram 提醒，并设置自己的时区和免打扰时间；桌面需系统通知许可，Telegram 需先配对。桌面交办的状态发往 Telegram 还需另外开启提醒并授权对应工作会话。资料摘要需逐项允许发送；涉及多份资料时须全部允许。可回复 Telegram 资料摘要继续追问，合并消息用 `2: 你的问题` 选择一项。Hope 内直接提问和审批可用桌面提醒，不转发到 Telegram；工具审批仍回到 Hope 处理。
- **少一点打扰**：普通进度留在 Hope；你主动查看助手主页时，主动提醒留在 Hope。已查看的更新不会再次主动推送，恢复提醒也不会补发暂停期间的旧消息。
- **保持简洁**：Hope 默认使用自己的 logo，主界面聚焦对话；模型、权限、事项和工作台按需展开。

后台跟进需要 Hope 桌面应用或服务保持运行；服务模式须配置主人令牌。共享文件须位于运行 Hope 的主机上，且在获准工作会话的工作目录内。同时使用桌面和独立 Server 时，请两端一起更新到本版。已有连接和设置可以继续使用；本版也包含 MCP 与基础依赖维护。

使用方式见[对话与会话手册](https://github.com/shiwenwen/hope-agent/blob/v0.75.0/docs/user-guide/03-对话与会话.md)，完整变更见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.75.0/CHANGELOG.md)。

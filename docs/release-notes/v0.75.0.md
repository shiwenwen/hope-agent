# Hope Agent v0.75.0

简体中文 · [English](https://github.com/shiwenwen/hope-agent/blob/v0.75.0/docs/release-notes/v0.75.0.en.md)

本版是一次依赖维护更新，没有新增功能或设置。

- 更新 MCP 连接所用依赖，继续支持现有的外部工具连接方式与登录流程；无需重新配置服务器。
- 更新压缩、加密和网络连接相关基础依赖。桌面深链与 PDF 支持继续采用现有兼容版本。

升级后可沿用已有设置。本次更新不代表新增 MCP Skills 支持，也不包含真实账号、设备或模型服务的兼容性验收。

完整变更见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.75.0/CHANGELOG.md)。

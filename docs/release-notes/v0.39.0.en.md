# Hope Agent 0.39.0 — Follow messages between conversations

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.39.0/docs/release-notes/v0.39.0.md) · **English**

> Released: 2026-09-01

> See [the changelog](https://github.com/shiwenwen/hope-agent/blob/v0.39.0/CHANGELOG.md#0390---2026-09-01) for the full list.

After asking AI to send a message to another conversation, you can now follow it directly. Received messages also link back to their source, making it easier to trace how a discussion started.

## Open the conversation behind a message

- **Follow up from the sending conversation**: Click the send receipt to open the destination and locate the message, without searching through the conversation list.
- **Trace a received message back to its source**: Click the source link to return to the sender. If it came from a side chat, its main conversation and side chat panel open together.
- **Navigate from separate windows too**: Links in Quick Chat and other separate windows open the main window. If a message was delivered but its subsequent response was stopped, the send receipt and navigation link remain available.

## Sign-in and model settings

If sign-in information cannot be saved, the app now reports the failure instead of showing a successful login that cannot be used. Defaults for new Cloudflare connections have been corrected, retired models have been removed from Copilot's default choices, and some preset model prices and reasoning options have been adjusted.

Existing provider settings are not overwritten automatically. If you previously configured these providers yourself, check their connection settings, model names, and prices in Settings.

## Using local models for the first time

On every platform, download and install Ollama manually from its official website first. Then return to Hope Agent, refresh its status, and download your model. If Ollama is already installed, you can keep using it; model downloads and registration remain available in the app.

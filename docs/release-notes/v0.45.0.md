## 通过对话安装技能

找到想用的技能后，把公开 GitHub 仓库中的技能目录链接或本地技能目录交给 Hope Agent，即可让它准备安装预览、检查内容并安装。已有同名技能会保留；安装后会检查实际安装位置、启用状态和缺少的依赖，方便你判断还需要做什么。

安装需要当前运行环境具备 Python 和可访问的技能来源。私有仓库请先准备已授权的本地目录；受限环境无法获取远程内容时，会说明原因。

## 需要你回答时，可以一直等待

模型现在可以按每组问题选择一直等待，或在你的超时设置允许时限时等待。提问卡片与通知会说明等待方式，方便你判断是否需要立即处理。

如果问题超时，结果会把模型提供的默认方案与你实际提交的回答分开展示。未回答不会被当成你已同意，需要确认的操作仍须由你回答后继续。

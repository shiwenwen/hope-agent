## Intel Mac downloads

This release improves the reliability of delivering the Intel Mac installer. The installer is added to this release after its separate build finishes; if you use an Intel Mac, check that the Release page lists the x64 DMG before downloading. There are no new app features; if 0.55.0 is working well for you, update when convenient.

# Hope Agent 0.29.0 — IM 忙时消息不丢、按序回复

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.29.0/docs/release-notes/v0.29.0.en.md)

> 发布日期：2026-08-04

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.29.0/CHANGELOG.md#0290---2026-08-04)。

这一版专修一个 IM 场景的老问题：当一条消息发来、而对应会话正忙着回上一条时，新消息可能被「忙碌」挡掉，后端其实生成了回复，IM 那头却始终收不到。现在这条路走通了。

## 修复

- **IM 忙的时候发消息，不会再收不到回复**：如果一条 IM 消息发来时，它绑定的会话正在回上一条，这条消息不再被当作「忙碌」丢弃，而是排进一个后端保管的队列，按你发送的先后顺序一条条处理，每一条都保证会得到一轮新的回复。应用重启不会丢失排队消息，会按原顺序自动接着处理。如果你手动停止了当前回合，排队的消息会被保留（同样不丢），并在**下一条 IM 消息到达时**按原顺序恢复处理——停止后不会自动往下跑，需要再来一条消息把它唤醒。IM 收到的内容、流式输出和最终状态，和桌面 / 网页那边保持一致；正在排队的消息在桌面待处理列表里能看到，但由后端接管、只读。

## 升级提示

本版无配置迁移，直接更新即可。

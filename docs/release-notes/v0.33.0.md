# Hope Agent 0.33.0 — 定时任务变成看得见的对话，选中文字就能问

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.33.0/docs/release-notes/v0.33.0.en.md)

> 发布日期：2026-08-18

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.33.0/CHANGELOG.md#0330---2026-08-18)。

这一版把定时任务并进了日常对话：每一次运行都留下一段可以打开、翻看、追问和继续的聊天记录，你也可以把手头这个对话直接排成定时任务，让它按你现在的模型、项目和工作目录继续做下去。任务出问题时，可以直接问 AI「上次为什么失败」，也可以只停掉正在跑的这一次而不影响后续排程。

同时，AI 现在能按你的要求新开一个对话并把事情做起来；在文件预览、代码、文档和设计稿里选中一段文字就能复制或引用回对话；一个项目也可以同时关联多个文件夹。

## 新增

- **定时任务在真正的对话里运行**：每次运行都是一段可定位的普通聊天记录，带来源标记、统一未读，可以随时打开查看、追问、停止或继续。你也可以在普通聊天的标题栏直接把当前对话排成定时任务，或在新建任务时搜索并选中任意已有对话，让它沿用这个对话现在的 Agent、项目、知识空间与工作目录。
- **可以问 AI 任务上次为什么失败，也能只停掉这一次**：AI 能读取任务最近的运行情况（结果、耗时、错误和发送到哪里），列出任务时也会带上最近一次的结果。要求「停掉正在跑的那个」时，只结束当前这次运行，后续排程照常。
- **保存任务前先说清「这次发到哪」**：预检会先展示这次运行落在哪个对话、当前标题是什么，逐条列出每个投递目标的问题，并显示当前有多少任务在跑、这个任务是不是正在运行。
- **任务列表能直接找到并修复出问题的任务**：搜索同时匹配任务描述和最近一次的错误摘要，筛选新增「需要处理」，出问题的任务会在行内写明原因（自动禁用、最近失败、错过运行、发送目标失效），并给出恢复、编辑或查看运行历史的入口。
- **每次运行后可以自动清理临时工作树**：为每次运行新建工作树的任务，可以选择运行后保留、无改动则删除、总是删除。「无改动则删除」只在这次运行没有留下任何改动和提交时才清理，你正在使用的工作树不会被自动删除。
- **删除定时任务只停掉后续排程，历史仍然可用**：聊天里的任务卡片会写明任务已删除，并可一键按原来的配置复制成新任务；最近一次失败时也能在卡片上直接再跑一次。
- **AI 可以按你的要求新开一个对话并开始做事**：模型能新建普通聊天、关联到某个项目、带上附件并发出第一条消息。新开的对话和你手动创建的一样，可以查看完整历史、停止和继续。
- **选中文字即可复制或引用到对话**：在文件预览、代码、Markdown、Office 文档、设计稿和 Artifact 里选中一段文字，选区旁会浮出「复制 / 引用到对话」。引用会先落进输入框里的一个可删除的引用块，代码和文本还会带上文件路径与精确行号，仍然由你确认后再发送。
- **HTML 文件可以在预览里切换源码与渲染效果**：普通 HTML 默认显示高亮源码，一键即可查看渲染后的页面。渲染视图不会执行页面里的脚本、不加载外部资源，也不会把你带离预览。
- **项目可以同时关联多个文件夹**：主文件夹继续决定默认工作目录、相对路径和项目指令，另外可以添加、切换、搜索和编辑多个辅助文件夹；单独给某个会话换过工作目录时，项目主文件夹仍然保留。
- **桌面宠物可以从任意来源导入，并在你要求时启用**：先预览宠物包的内容并由你确认，确认后才安装；只有你明确要求「导入并启用」时才会打开宠物窗口，仅要求导入时保持原样。
- **预设 Provider 补齐了当前一代模型**：Claude Opus 5、Grok 4.6、GLM-5.3、Gemini 3.7/3.6 Flash 与 3.5 Flash-Lite、豆包 Seed 2.1 系列、文心 ERNIE 5.1/5.0、小米 MiMo V2.5、Qwen3.8/3.7 Max、Kimi K3（Coding）等新模型现在直接出现在对应 Provider 的预设列表里，新建 Provider 不必再手工填写。
- **本地评测可以先设好花多少再开跑**：整场评测和单个场景可以分别设置费用、时间、Token、请求次数与并发上限；也可以显式选择不设限运行，届时会明确告知费用不可控。

## 变更

- **上下文压缩失败时会说清原因，并可以一键重来**：长对话整理超时或没有生效时，会明确显示发生了什么、哪些内容还在，并提供「重新压缩」按钮，不再只留下一条难以判断的提示。
- **更正：普通长工具输出的完整原文不能在压缩后恢复**：该版本接入了结果元数据与有界预览，但出于安全原因，普通文本正文的持久化和分页回读仍保持关闭。压缩后，可分页工具可沿自身游标继续；其他情况需重新运行工具。

## 修复

- **停止按钮不会再卡在「停止中」**：应用崩溃或被强制退出后，对话有时仍显示上一轮在运行，点停止毫无反应、只能重启应用。现在点停止会立刻把这类残留状态收敛回真实结果，连点也只会触发一次。
- **会话列表标准模式不再为悬停按钮常驻留白**：置顶与归档按钮改为鼠标悬停时浮出，标题可用宽度恢复到整行。
- **GPT-5.6 Terra / Luna 按新价计费**：这两档已于 2026-07-30 降价（Terra $2/$12、Luna $0.20/$1.20），预设单价已同步更正。

## 升级提示

直接更新即可，无需手动迁移配置。已有的定时任务会照常运行，无需重建。

如果你在此前已经添加过含 GPT-5.6 Terra / Luna 的 Provider，请到「设置 → 模型」手动把这两个模型的单价改成新价，否则用量统计仍按旧价计算（Luna 会高估约 5 倍）。

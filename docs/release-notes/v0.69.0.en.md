# Hope Agent 0.69.0 — Model discovery and file registration

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.69.0/docs/release-notes/v0.69.0.md) · **English**

> Release date: October 23, 2026

> See the [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.69.0/CHANGELOG.md#0690---2026-10-23) for the full list of changes.

## Choose models from your provider's list

When adding a custom provider or editing an existing one, choose **Discover models** to read the current connection's model list. Select entries, enter context and maximum output limits, confirm text-chat and tool-call compatibility, then save the provider. Existing models and current selections are preserved. A listing does not establish real conversation compatibility. ChatGPT sign-in keeps its existing model catalog.

## Register files as versioned Artifacts

In **Artifacts** in the sidebar, select a file to register an HTML, Markdown or analysis deliverable as a new Artifact. Select an existing Artifact to update it from a file. Source files and version history are preserved; **First version / Updated** labels and dates identify its lifecycle. Matching names are not merged automatically. In a remote interface, upload sends the file you select on your device.

## Adjust reasoning for summaries separately

Context settings now offer a summary reasoning override. If reasoning exhausts the output budget and leaves an empty summary, select a lower level or off switch that the summary model actually supports. The default keeps the previous policy. Unsupported choices fail explicitly and preserve history without switching models or raising the output limit. Main-conversation reasoning stays unchanged.

## Try the WeCom text channel

Enter your WeCom AI bot's Bot ID and Secret in Channel Settings, then explicitly configure DM and group allowlists to receive messages and send final text replies. The first version does not support media, cards, proactive notifications or desktop reply backfills. Handle approvals and questions in the app, and run only one client per bot. Check WeCom before resending a reply with an unknown acknowledgement. Validation covers local protocol fixtures; real enterprise-tenant acceptance is still pending.

## Clearer results and error messages

External MCP tools retain structured results even when they return no text; hooks preserve deny and stop instructions. Linux installation and update downloads are available again. Desktop working-directory and project-folder pickers show only folders and accept pasted paths on Linux. Figma imports distinguish permission problems from rate-limit waits. This version also fixes desktop dependency version conflicts and updates TLS security patches.

Upgrades preserve saved models and default selections. New templates stop recommending some retiring OpenAI and MiniMax models. If you use an older model, check your provider's account eligibility and retirement schedule before choosing a replacement. Model listings, plan routing and actual charges depend on your provider account.

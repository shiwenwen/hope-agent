## Import Codex conversations from the session sidebar

You can now import Codex conversations saved on the computer running Hope Agent. Search, view, and export the imported records from your sessions. Importing again updates records from the same source without creating duplicates. Imported conversations stay read-only and cannot be continued as new chats.

## Connect more models with Requesty

Choose Requesty when adding a provider, enter your API key, and select a managed routing policy or enter a custom model ID. If you use European routing, you can set its regional service address.

# Hope Agent 0.70.0 — 更多模型选择与消息接收修复

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.70.0/docs/release-notes/v0.70.0.en.md)

> 发布日期：2026 年 10 月 27 日

> 完整改动列表见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.70.0/CHANGELOG.md#0700---2026-10-27)。

## 更容易找到入口与模型

侧栏图标下方现在常驻显示入口名称，长名称仍可悬停查看完整提示；小窗口可通过“更多”找到折叠入口。

添加服务商时，可选择 Unbiased 的 Pareto 稳定版或预览版；Google 模板新增 Gemini 4 Argon，Mistral 模板新增 Z.ai GLM 5.3 Flash。填入对应服务商的 API Key 后即可配置使用。ChatGPT 登录的新建 GPT-6.1 Sol 预设采用 500K 上下文；已保存的上下文和当前模型不会自动改写。账号资格、模型可用性和实际费用仍由服务商决定，模板参数不代表真实账号验收。

## 减少消息误触发与接收损坏

iMessage 中的编辑、撤回和未知更新类型不会再触发新回复，也不会挤占原消息的去重记录；这些变更目前不会修改或删除 Hope Agent 内的历史消息。

Signal 接收中文和 emoji 时不再因网络分片而损坏，并支持分为多行的消息；停止账号会取消连接和排队等待。无效或过大的消息会断开并重连，尚不支持断线消息重放。以上修复经过本地协议验证，真实设备与账号行为仍需独立验收。

## 外部记忆与安全维护

OpenViking 无法证明记忆列表完整时会明确停止本轮拉取和新增导出，保留本地记忆及同步状态。当前不支持超过 5000 节点的列表续扫；遇到提示时请保留连接，不要删除本地状态绕过保护。

本版还更新图表与 PDF 的内容清洗依赖、开发和测试依赖及证书信任补丁。若证书路径不再受信任，请修复服务端证书链，不要关闭证书验证。

## 升级前核对图像模型

xAI 新建图像模板保留 Grok Imagine Image 为首选，第二候选改为 Grok Imagine Image 2.0 的低质量档。已有模型与默认链保持原样；仍使用 `grok-imagine-image-quality` 的用户，应在 2026 年 11 月 2 日退役前手动核对替代型号与费用。当前 xAI 接入只支持生成，尚不支持参考图编辑，新型号的真实画质与费用未验收。

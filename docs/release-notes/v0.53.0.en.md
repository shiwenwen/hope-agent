> Released: September 23, 2026

> See the [changelog](https://github.com/shiwenwen/hope-agent/blob/v0.53.0/CHANGELOG.md#0530---2026-09-23) for the complete list of changes.

## Optional tool arguments stay optional

When tools are used through the OpenAI Responses API or a compatible service, Hope Agent now preserves omitted optional arguments. Actions such as “never time out,” which should not include a number of seconds, no longer fail because the service inserted a conflicting value.

The fix applies to built-in tools and other function tools using the same request path. Existing provider settings do not need to change.

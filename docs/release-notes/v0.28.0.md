# Hope Agent 0.28.0 — 远程与部署加固

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.28.0/docs/release-notes/v0.28.0.en.md)

> 发布日期：2026-08-03

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.28.0/CHANGELOG.md#0280---2026-08-03)。

这一版围绕「离开本机也稳、也安全」。把 Hope Agent 当服务器跑、用浏览器远程访问、接 Telegram、装进 Docker 的场景都做了加固：认证收敛到单一 Owner Token，远程不再暴露根凭据；关掉浏览器不会再打断正在跑的对话；Telegram 可以填自己的 API 地址；Docker 部署也能用隔离沙箱了。桌面端顺带修了自动更新进度和新建目录的权限体验。

## 新增

- **Telegram 可以填自己的 Bot API 地址**：新增或编辑 Telegram 账号时能填一个你自己控制的 Bot API 根地址，留空继续用官方端点。适合访问不了官方 API 的网络环境或自建反代。连接测试会直接用你填的地址实测，填错或连不上会当场报错，不会偷偷退回官方地址；也支持 `socks5` 代理。

## 变更

- **认证收敛成单一 Owner Token，远程访问不再暴露根凭据**：浏览器登录后换成受保护的会话凭证，根 Token 不再进网址或前端；远程 WebSocket 与文件预览用的是短时、权限受限的票据。配置和历史备份里的明文 Token 会自动清理迁移。保存或轮换 Token 后当前页面会自动续上，不会把自己锁在登录页外面。
- **后台活动显示成看得懂的名字**：输入区和工作台不再冒出 `subagent:batch` 这类内部标识，批量子任务显示成「任务组」。
- **子 Agent 列表更清爽**：去掉每行重复的分支图标，标题直接顶格；全局搜索里仍保留类型图标，方便区分会话类型。

## 修复

- **关掉或刷新浏览器，不会再打断正在跑的对话**：用浏览器（或局域网）发起的对话现在由服务端接管并继续跑，关页面只是少了个「围观的人」。重连或刷新后会精确回到那一轮的真实状态，不会重复发一遍你的消息；等着你点的工具审批也留着，可以重新接手。
- **Docker 部署能用隔离沙箱了**：容器里即使没装 Docker CLI，只要挂了 Docker socket 也能检测到 daemon，缺失或权限不足会明确告诉你原因。容器部署现在支持把工作区的有界副本传进匿名 volume 的 `isolated` 沙箱模式；其它依赖宿主路径映射的模式会安全拒绝，不会硬跑。
- **停止更可靠**：桌面 Stop、网页 Stop、IM 里的 `/stop`、全局停止走的是同一套逻辑，不管当前卡在等审批、等你输入、跑工具还是跑子 Agent，都能停下来。已经写出的部分内容会标成「已中断」保留，停完再开新对话也不会被上一轮的收尾动作干扰。
- **修复网页版 Agent 设置等页面打不开**：网页模式下 Agent 设置、系统提示词、日志、技能等页面因为返回格式和桌面端不一致而崩溃，现已统一。
- **修复桌面自动更新的下载进度**：下载时会一直显示真实百分比，对方不给总大小时显示明确的「进行中」而不是长期卡在 0%。不同入口的检查更新不再互相打架导致安装失败，关掉更新通知也不会每轮偷偷把安装包重下一遍。
- **新建目录不再一上来就没权限**：服务端的目录选择器现在从你自己的主目录开始（带一个「主目录」快捷入口），不再默认根目录——以前普通用户第一次新建文件夹就落在系统目录、直接没权限。遇到只读或没写权限会给出能照着做的提示。

## 升级提示

本版没有配置迁移，直接更新即可。

如果你在用远程 / 服务器模式：更新后浏览器会走一次新的登录，历史配置和备份里的明文 Owner Token 会被自动清理。这是安全加固，正常使用无需额外操作；保存或轮换 Token 后当前页面会自动续接，不会被踢回登录页。

## Install skills through conversation

Once you find a skill you want, give Hope Agent its directory link in a public GitHub repository or a local skill directory. It can prepare an installation preview, review the contents, and install the skill. Existing skills with the same name are preserved. After installation, it checks the actual location, enabled status, and missing dependencies so you can see what remains to be done.

Installation requires Python and access to the skill source in the current environment. For private repositories, prepare an authorized local directory first. If a restricted environment cannot retrieve remote content, Hope Agent explains why.

## Wait as long as your answer needs

The model can now choose to wait indefinitely for a group of questions, or use a time limit when your timeout settings allow it. Question cards and notifications explain the waiting behavior so you can decide whether to respond right away.

When questions time out, the result shows the model's fallback suggestions separately from answers you actually submitted. Silence is not treated as consent: actions that require confirmation still need your answer before proceeding.

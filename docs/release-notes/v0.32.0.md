# Hope Agent 0.32.0 — 输入按你的习惯，长任务真正停得住

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.32.0/docs/release-notes/v0.32.0.en.md)

> 发布日期：2026-08-12

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.32.0/CHANGELOG.md#0320---2026-08-12)。

这一版把两件高频操作做得更可控：写消息时，你可以选择 Enter 是发送还是换行；运行长任务时，Stop 会真正停住后续工作，关闭再打开应用也不会自行继续。等你准备好后，直接发送“继续”，Agent 会从确切的暂停位置恢复，而不是把已经完成的步骤重做一遍。

同时，复杂对话会更稳地利用不同模型的上下文容量，`@` 引用在输入、发送和重新打开历史后保持一致，损坏的旧配置备份也不再卡住应用启动。

## 新增

- **发送快捷键可以按输入习惯切换**：在「设置 → 对话与上下文 → 基础设置」里，可保留默认的 Enter 发送、Shift+Enter 换行，也可以改成 Enter 换行、Ctrl+Enter 发送。主窗口、QuickChat 和远程连接会使用同一偏好；升级后默认行为不变。

## 变更

- **Stop 之后，长任务会一直保持暂停**：Goal、Workflow、子 Agent 和稍后唤醒的工作都会停在同一位置，重启应用也不会悄悄复活。需要继续时，直接发送“继续”即可恢复这一次暂停对应的未完成工作；已经执行过的步骤不会被盲目重放。子 Agent 遇到临时服务故障时，恢复进度也会回到主会话中，方便你判断是等待还是停止。
- **复杂对话更不容易过早压缩或撞上容量限制**：中文、emoji、图片、大文件和大量工具同时出现时，Hope Agent 会更贴近当前模型的实际能力安排上下文。长对话能保留更多有用内容，接近边界时也更早做出安全处理。
- **所有 `@` 引用使用一致的轻量样式**：文件、笔记、Skill、Agent、Plan、插件和连接器在输入框与已发送消息里采用统一的行内展示，键盘操作和焦点状态更清楚；重新打开历史后仍能识别引用，而不是退化成普通文本。文件引用会固定到选择时的工作区，切换项目或会话后不会误指向另一个目录。
- **项目会话更准确地识别自己属于哪个项目**：Agent 会得到明确的项目身份，涉及多个项目或相似目录时，项目范围内的工具和自动化任务更容易落到正确位置。

## 修复

- **损坏的旧配置备份不再卡住启动**：升级时遇到无法解析的历史备份，Hope Agent 会安全隔离它并继续使用有效配置。配置保存也更能抵御崩溃、断电和多个进程同时启动，不会把只写了一半的内容当成有效配置。
- **图片能力不足时会给出可操作的模型配置提示**：当前模型看不了图片时，会明确引导你配置视觉模型，不再只返回难以处理的能力错误。

## 升级提示

直接更新即可，无需手动迁移配置。

发送快捷键仍默认使用 Enter 发送；只有你在设置中切换后，Enter 才会改为换行。

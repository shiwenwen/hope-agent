# Hope Agent v0.74.0

## 给助手取名，换上喜欢的头像

个人助手默认叫 Hope。点击聊天顶部的头像或设置图标，在「助手设置 → 助手资料」中修改名字、上传并裁剪图片、选择预设头像，或恢复默认头像。保存后，侧栏悬浮提示、聊天身份栏和欢迎语会一起更新，原对话、历史、交办事项和授权都会保留。

## 收起事项，继续聊天

交办工作和关注目标集中到「事项」中。宽窗口可以在右侧展开或收起，小窗口通过弹窗查看，让主对话有更多空间。需要接手工作时，仍可从事项打开原会话。

## 在助手设置中连接 Telegram

Bot 连接、本人配对、会话授权和通知集中到「助手设置 → IM 连接」，聊天区域不再放置连接表单。原工作 Bot 继续使用原来的 IM 设置。

Telegram Bot 的名字和头像由 Telegram 单独管理，修改 HA 中的助手资料不会同步修改 Bot。使用独立 Server 时，请将桌面和 Server 一起更新到本版。

## 更紧凑的侧栏与完整工作台

全局侧栏恢复纯图标并收窄，悬停可查看入口名称；助手头像固定在顶部，不会随窗口高度收进「更多」。助手对话中的工作台保留标签切换、关闭、悬浮和最大化操作；打开「事项」后，也可以重新展开原工作台。

详见[对话与会话手册](https://github.com/shiwenwen/hope-agent/blob/v0.74.0/docs/user-guide/03-对话与会话.md)与[完整变更](https://github.com/shiwenwen/hope-agent/blob/v0.74.0/CHANGELOG.md)。

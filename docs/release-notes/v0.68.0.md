## 从服务商列表挑选模型

添加自定义服务商或编辑已有服务商时，可以点击“发现模型”，读取当前连接提供的模型列表。勾选需要的型号，填写上下文和最大输出上限，并确认支持文本对话与工具调用后，再保存服务商。已有模型与当前选择会保留；列表不代表这些模型已通过真实对话验证。ChatGPT 登录仍使用原有模型目录。

## 把文件登记为可迭代的产物

在侧栏“产物”中选择文件，可将 HTML、Markdown 或分析产物登记为新产物；选中已有产物后，也可以从文件更新。源文件和历史版本会保留，“初版 / 已迭代”及日期帮助你识别交付状态。同名文件不会自动合并；远程界面上传的是你选中的文件。

## 单独调整摘要的推理档位

上下文设置增加摘要专用推理覆盖。遇到推理占满预算、摘要正文为空时，可选择摘要模型实际支持的较低档位或关闭方式。默认保持原有策略；不支持的设置会明确失败并保留历史，不自动换模型或提高输出上限，主对话的推理设置不变。

## 尝试企业微信文本渠道

可在渠道设置中填写企业微信智能机器人的 Bot ID 与 Secret，明确配置单聊、群聊允许列表后接收消息并回复最终文本。首版不支持媒体、卡片、主动通知或桌面回复补发，审批和提问需在应用内处理；同一个机器人请只运行一个客户端。未知回执不要自动重发，应先检查企业微信中的结果。本版仅完成本地协议验证，尚未完成真实企业租户验收。

## 更清楚的结果与错误提示

外部 MCP 工具只返回结构化数据时，回复中也能保留结果；作为 Hook 使用时，拒绝与停止指令继续生效。Linux 桌面的工作目录与项目文件夹选择只展示目录，并支持粘贴路径。Figma 导入会区分权限问题与限流等待；同时修复桌面依赖版本冲突并更新 TLS 安全补丁。

升级保留已保存的模型与默认选择。新建模板不再推荐临期退役的部分 OpenAI、MiniMax 型号；使用旧型号的用户请按服务商的账户资格与退役安排自行检查替代配置。模型列表、套餐路由和实际费用以服务商账户为准。

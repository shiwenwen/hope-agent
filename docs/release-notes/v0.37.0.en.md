# Hope Agent 0.37.0 — More reliable tool calls and desktop interactions

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.37.0/docs/release-notes/v0.37.0.md) · **English**

> Released: 2026-08-30

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.37.0/CHANGELOG.md#0370---2026-08-30) for the full list.

This release fixes follow-up responses after tool calls with OpenAI Responses and Codex, restores syntax highlighting in packaged file previews, and makes the desktop pet's context menu close naturally when you switch windows.

## Fixed

- **OpenAI and Codex tool calls no longer fail midway**: Conversations can continue after tools such as Knowledge Space finish successfully, and parallel tool calls now receive the correct results.
- **Packaged file previews show syntax colors and line numbers again**: JSON, code, and other text files no longer fall back to hard-to-read uncolored text. A temporary loading failure also no longer breaks later previews.
- **The pet menu closes when you switch windows**: The desktop pet's context menu no longer stays open after focus moves elsewhere, while normal interaction continues when the pet window remains active.

## Upgrade notes

Update directly. No data migration or settings changes are required.

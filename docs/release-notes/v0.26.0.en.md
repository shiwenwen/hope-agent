# Hope Agent 0.26.0 — Persistent Workspaces and Detachable Windows

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.26.0/docs/release-notes/v0.26.0.md) · **English**

> Release date: 2026-07-30

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.26.0/CHANGELOG.md#0260---2026-07-30) for details.

v0.26.0 is about using several workspaces at once: switching away from a primary sidebar workspace and back now returns you to where you were instead of its home page, and Knowledge Space and Design Space can be detached into their own windows to sit alongside the main one. Design Space previews also move from three coarse categories to a device list plus a custom viewport. On top of that, Azure Speech voice input no longer fails with a hard 400.

## Added

- **Knowledge Space and Design Space can be detached into their own desktop windows**: right-click the sidebar icon and choose "Open in separate window", or just double-click the icon. The workspace title bar can also detach the current workspace at any time and reattach it to the main window. Each space keeps at most one detached window — clicking again focuses the existing one. Before detaching, reattaching, or closing via the system button, Knowledge Space deals with unsaved notes first and lets you save, discard, or cancel.
- **Design Space device previews gain mainstream devices and a custom viewport**: the coarse desktop / tablet / mobile switcher is now a grouped device selector with the CSS logical viewports of common devices — iPad, Surface, iPhone, Pixel, Galaxy. Custom mode takes explicit width and height, or you can drag the preview's right edge, bottom edge, or bottom-right corner. The selected device and custom dimensions are remembered per artifact. While dragging, the display zoom is pinned to its starting value and the preview is anchored to its top-left corner, so centered fitting can't slide the handle out from under your pointer.

## Changed

- **Primary sidebar workspaces keep their state across switches**: Chat, Scheduled Tasks, Dashboard, Plan, Knowledge Space, Design Space, and the Artifact Library stay mounted after you first open them, so leaving and coming back keeps the same session, project, note, artifact, or filter. Settings and the Agent / model / skill / memory / channel configuration pages are still treated as ordinary navigation pages and make no promise about preserving uncommitted form drafts.
- **Top-level workspace navigation is now consistent**: the home screens of Scheduled Tasks, Dashboard, Plan, Knowledge Space, Design Space, and the Artifact Library no longer show a "Back to chat" button — you move between top-level entries through the main sidebar. Second-level pages such as a project or a task detail still keep a back action to their real parent.
- **The jump-to-bottom button shows streaming state**: when you have scrolled away from the newest message and a reply is still being generated, the button gets a blue comet animation around it that transitions from a faint trail into a soft glow, returning to its normal state once the reply finishes. The button also switches to a dedicated floating-surface background so it no longer blends into the transcript in dark mode.
- **Desktop development builds Browser Host and the Eval Sidecar on demand** (developer-facing): `pnpm desktop` offers an interactive mode picker, and the default `pnpm dev:desktop` no longer waits on either optional binary. Use `pnpm dev:desktop:browser`, `pnpm dev:desktop:eval`, or `pnpm dev:desktop:full` for Chrome-extension, evaluation, and full-capability work. Production builds and the legacy `pnpm tauri dev` entry still build both.

## Fixed

- **Azure Speech voice input no longer returns a hard 400 for a missing recognition language**: the configured default recognition options were stored but never applied to the request — the desktop client sent only the sample rate, so the Azure endpoint never received the required `language` parameter and returned HTTP 400 every time. Defaults now apply uniformly to desktop streaming, batch, IM, and Knowledge Space transcription, and you can set a BCP-47 tag such as `zh-CN` or `en-US` in settings. When Azure is missing a language, or a full URL was pasted into the region field, you now get an explicit configuration error before any network call.
- **Deep links into a detached Knowledge Space now work**: when Knowledge Space is already open in its own window, clicking a note source in a conversation's memory trail sends the full note along with the line / heading / block target to that window, instead of merely focusing it while leaving the previously open note on screen.
- **Portaled overlays no longer leak across persistent workspaces**: dialogs, menus, selects, popovers, tooltips, and the chat floating panels now belong to their owning workspace. Switching in the sidebar suspends portal content for hidden pages and releases focus and pointer locks, so an old page's overlay can no longer cover the new one — and the page body's state is still fully intact when you come back.
- **Persistent workspaces no longer restore stale content**: Design Space no longer falls back to its home page when you switch in the sidebar, and the Artifact Library and Scheduled Tasks refresh their lists, details, run history, and current conversation on re-entry — preserving your place while still picking up external changes.
- **Detached-window title bar layout and interaction are fixed**: on macOS, dynamically created Knowledge Space / Design Space windows now use the overlay title bar like the main window, so the toolbar starts right of the traffic lights instead of taking an extra row, and drag permissions for dynamic windows are in place so empty title-bar space moves the window as expected. Windows and Linux keep their native title bars with no macOS-specific padding. The sidebar context menu, workspace title bars, and the in-chat Canvas / files / Plan / control panel all now share one icon pair for detach and reattach: a box with an arrow to the top-right corner for detach, and a box with an arrow to the bottom-left for reattach — no longer overloading the sign-in, sign-out, or external-link glyphs.

## Upgrade notes

There are no config migrations and no breaking compatibility changes in this release — just update.

Workspace persistence and the navigation cleanup do change how the desktop app feels: top-level workspaces are now reached only through the main sidebar, and the "Back to chat" buttons on those home screens are gone. Detached windows are desktop-only; the HTTP / web frontend does not offer them.

If you use Azure Speech for voice input, it is worth opening Settings → Speech-to-Text → Default recognition language and setting a BCP-47 value such as `zh-CN`. That missing parameter was the cause of the hard 400; leaving it empty now surfaces an explicit configuration error before any network call.

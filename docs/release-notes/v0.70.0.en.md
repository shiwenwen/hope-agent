# Hope Agent 0.70.0 — More model choices and message reception fixes

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.70.0/docs/release-notes/v0.70.0.md) · **English**

> Release date: October 27, 2026

> See the [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.70.0/CHANGELOG.md#0700---2026-10-27) for the full list of changes.

## Find destinations and models more easily

Sidebar icons now keep their destination names visible. Hover over a long name for the full tooltip, or use “More” to reach collapsed destinations in a smaller window.

When adding a provider, you can choose stable or preview Pareto presets from Unbiased, Gemini 4 Argon from Google, and Z.ai GLM 5.3 Flash from Mistral. Configure them with the corresponding provider's API key. New GPT-6.1 Sol presets for ChatGPT sign-in use a 500K context window; saved context values and the selected model are not rewritten. Account eligibility, availability, and actual charges remain provider-controlled; preset parameters do not establish real-account validation.

## Reduce unintended replies and damaged incoming text

iMessage edits, unsends, and unknown update types no longer start a new reply or consume the original message's deduplication record. These changes do not currently edit or delete Hope Agent's message history.

Signal reception preserves Chinese text and emoji across network chunks and supports multiline messages. Stopping an account cancels connections and queue waits. Invalid or oversized messages disconnect and reconnect; disconnected-message replay is not yet supported. These fixes have local protocol validation; real-device and account behavior still require separate acceptance.

## External memory and security maintenance

When OpenViking cannot prove a memory listing is complete, the current sync stops pulling and starting new exports while preserving local memories and sync state. Continuation beyond 5,000 nodes is not supported yet. Keep the connection if you see this warning; do not delete local state to bypass it.

This version also patches content sanitization used by charts and PDFs, development and test dependencies, and certificate trust. If a certificate path is no longer trusted, fix the server's certificate chain rather than disabling verification.

## Review image models before upgrading

New xAI image templates keep Grok Imagine Image first and use the low-quality setting of Grok Imagine Image 2.0 as the second choice. Existing models and default chains remain unchanged. If you use `grok-imagine-image-quality`, review replacement models and pricing before its November 2, 2026 retirement. The current xAI integration supports generation without reference-image editing; actual image quality and charges for the new model have not been validated.

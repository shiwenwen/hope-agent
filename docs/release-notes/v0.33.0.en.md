# Hope Agent 0.33.0 — Scheduled tasks become conversations you can read, and selected text becomes a question

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.33.0/docs/release-notes/v0.33.0.md) · **English**

> Released: 2026-08-18

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.33.0/CHANGELOG.md#0330---2026-08-18) for the full list.

This release folds scheduled tasks into everyday chat. Every run now leaves a conversation you can open, read, follow up on, and continue — and you can turn the conversation you already have into a scheduled task that keeps working with your current model, project, and working directory. When something goes wrong, you can simply ask the agent why the last run failed, or stop just the run in progress without touching the schedule.

The agent can also start a brand-new conversation and get to work on your behalf, selecting text in a preview, document, or design now offers to copy or quote it back into chat, and a project can be linked to several folders at once.

## Added

- **Scheduled tasks run inside real conversations**: Every run leaves an ordinary chat you can open, complete with a source badge and normal unread handling, so you can read it, ask a follow-up, stop it, or continue it at any time. You can also schedule the conversation you are in straight from its header, or pick any existing conversation when creating a task so it keeps that conversation's agent, project, knowledge space, and working directory.
- **Ask the agent why the last run failed, or stop only that run**: The agent can read a task's recent runs — outcome, duration, error, and where the result was sent — and includes the latest result when listing tasks. Asking it to "stop the one that's running" ends only the current run and leaves the schedule intact.
- **See where a task will post before you save it**: The preflight shows which conversation the run lands in and its current title, lists problems with each delivery target one by one, and reports how many tasks are running and whether this one is running right now.
- **Find and repair broken tasks from the list**: Search matches both the task description and the latest error summary, a "needs attention" filter is available, and problem tasks state the reason inline (auto-disabled, last run failed, missed run, delivery target gone) with a direct way to recover, edit, or review run history.
- **Clean up temporary worktrees after each run**: Tasks that create a fresh worktree per run can keep it, delete it when the run left nothing behind, or always delete it. "Delete when unchanged" only applies when the run produced no edits and no commits, and a worktree you are still using is never removed automatically.
- **Deleting a task stops future runs without losing the history**: The task card in chat states that the task was deleted and can recreate it from the original configuration in one click. If the last run failed, you can also rerun it right from the card.
- **The agent can open a new conversation and start working**: It can create an ordinary chat, attach it to a project, include files, and send the first message. The new conversation behaves exactly like one you created yourself — full history, stop, and continue all work.
- **Select text to copy it or quote it into chat**: Selecting text in a file preview, code, Markdown, an Office document, a design, or an artifact reveals "copy / quote to chat" next to the selection. A quote lands in the composer as a removable block — code and text carry the file path and exact line range — and nothing is sent until you send it.
- **Switch between source and rendered view for HTML files**: Ordinary HTML opens as highlighted source and renders with one click. The rendered view does not run the page's scripts, load external resources, or navigate you away from the preview.
- **Link several folders to one project**: The main folder still decides the default working directory, relative paths, and project instructions, while you can add, switch between, search, and edit additional folders. Changing the working directory for a single conversation keeps the project's main folder available.
- **Import a desktop pet from any source, and enable it when you ask**: You preview what the pet package contains and confirm it before anything is installed. The pet window only opens when you explicitly ask to import and enable; asking only to import leaves your current setup unchanged.
- **Preset providers now include this generation's models**: Claude Opus 5, Grok 4.6, GLM-5.3, Gemini 3.7/3.6 Flash and 3.5 Flash-Lite, Doubao Seed 2.1, ERNIE 5.1/5.0, MiMo V2.5, Qwen3.8/3.7 Max, and Kimi K3 (Coding) appear directly in the matching provider's preset list, so a new provider no longer needs them typed in by hand.
- **Decide what a local evaluation may spend before it starts**: Set cost, time, token, request, and concurrency limits for the whole evaluation and for individual scenarios, or explicitly choose to run without limits — in which case you are told plainly that the cost is uncapped.

## Changed

- **When context compaction fails, it says why and offers a retry**: If tidying a long conversation times out or does not take effect, you now see what happened and what is still in context, plus a "compact again" button, instead of a message you cannot act on.
- **Correction: ordinary long tool output cannot be restored in full after compaction**: This release added result metadata and bounded previews, but persistence and paged readback of ordinary text bodies remain disabled for security. After compaction, pageable tools can continue through their own cursors; other tools must be run again when the omitted text is needed.

## Fixed

- **The stop button no longer gets stuck on "stopping"**: After a crash or force quit, a conversation could still look like its last turn was running, and stop did nothing until you restarted the app. Stop now settles that leftover state to the real outcome immediately, and repeated clicks only act once.
- **The standard session list no longer reserves blank space for hover buttons**: Pin and archive appear on hover, so titles get the full row width back.
- **GPT-5.6 Terra / Luna are billed at the new rates**: Both tiers were reduced on 2026-07-30 (Terra $2/$12, Luna $0.20/$1.20), and the preset rates now match.

## Upgrade notes

Update directly — no manual configuration migration is needed, and existing scheduled tasks keep running as before.

If you already added a provider containing GPT-5.6 Terra / Luna, update those two models' rates under Settings → Models. Otherwise usage reporting keeps using the old prices, which overstates Luna by roughly 5×.

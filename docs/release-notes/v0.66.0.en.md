# Hope Agent 0.66.0 — More models and Kimi search

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.66.0/docs/release-notes/v0.66.0.md) · **English**

> Release date: October 15, 2026

> See [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.66.0/CHANGELOG.md#0660---2026-10-15) for the complete list of changes.

## Choose GPT-6 with your ChatGPT account

After signing in with ChatGPT / Codex in model settings, you can select GPT-6 Astra, GPT-6.1 Sol, GPT-6 Sol, and GPT-6 Luna. Upgrading adds missing models while keeping your current selection, custom settings, and disabled state. Availability still depends on your plan and workspace permissions.

## Choose more stable models by provider

Model settings add Claude Haiku 5.5, Grok 4.7, MiniMax M3, and more stable candidates through Fireworks, OpenRouter, and Together. Entering a complete model ID prioritizes candidates with exactly matching capitalization. Together thinking content can also appear as the response streams.

Input capabilities, context limits, and prices still vary by provider; check each candidate's source. The catalog removes some candidates that are explicitly retired or restricted for new users, while saved connections keep their settings. Check availability and replacement billing with your provider. Catalog prices and dashboard estimates are not actual bills.

## Keep using Kimi web search

Your configured Kimi search key continues to work, with search returning links and snippets directly. If you request country, language, or recency filters, Hope explains that this service does not support them and tries subsequent enabled search providers instead of silently ignoring your request. Actual search quality and account charges still need verification in use.

See the [models and providers guide](https://github.com/shiwenwen/hope-agent/blob/v0.66.0/docs/user-guide/en/02-models-and-providers.md) for setup steps, thinking settings, and provider limitations.

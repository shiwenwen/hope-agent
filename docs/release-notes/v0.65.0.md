# Hope Agent 0.65.0 — 模型选择与请求安全

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.65.0/docs/release-notes/v0.65.0.en.md)

> 发布日期：2026 年 10 月 13 日

> 完整改动列表见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.65.0/CHANGELOG.md#0650---2026-10-13)。

## 选择长列表里的模型

服务商或模型较多时，可以滚动菜单并选择末尾项目。默认模型、备用模型和 Agent 的计划模式模型都支持这项操作，窗口较小时也能继续选择。

## 确认服务商的最终地址

模型、图像和音频请求不会再自动跟随端点重定向，避免把密钥和私有输入自动转发到其他地址。连接测试遇到重定向会提示失败；请向服务商确认最终 API 地址，更新 Base URL 后重试。

## 更可靠的 PDF 文本读取

PDF 文本按真实页面读取并保留空页。后续页面损坏时会报告失败，避免把只读到的前几页当作完整文档。

本版同时更新桌面、文档解析、网络与编辑器的安全依赖。已有配置和会话可继续使用；设计空间的视频导出方式保持原有方案，浏览器能力不足时仍需按提示安装导出依赖。

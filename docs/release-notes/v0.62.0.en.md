## Look up information without applying for an API key

New installations enable free multi-engine search by default, with no API key or extra software to install. Ask Hope Agent to find information on the web in a conversation. If Brave web search is unavailable, it tries 360 Search, followed by your other enabled search services.

Upgrading preserves your existing search order and disabled options. To use the new option first, open Settings → Web Search, enable Free multi-engine search, and drag it to the top.

Free search can still fail because of rate limits, network restrictions, or page changes. Country and language filters are best effort. A freshness filter skips 360 Search, which does not support that filter.

# Hope Agent 0.54.0 — More reliable model selection and long tasks

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.54.0/docs/release-notes/v0.54.0.md) · **English**

> Released: September 24, 2026

> See the [changelog](https://github.com/shiwenwen/hope-agent/blob/v0.54.0/CHANGELOG.md#0540---2026-09-24) for the complete list of changes.

## Design chats use the selected model

When you choose a model in Design Space, the conversation now uses it and remembers the choice when you reopen the session. Child tasks without their own model choice inherit the parent session's model. Messages about an upstream service being busy are clearer, too.

## Long tasks can continue more reliably

During a request with many completed tool calls, Hope Agent can condense earlier call history to make room for later steps while retaining your request and the latest complete results. Tasks with long tool chains are less likely to stop because they run out of context.

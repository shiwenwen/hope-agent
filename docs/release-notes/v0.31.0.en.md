# Hope Agent 0.31.0 — A readable session list, and replies that hold still

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.31.0/docs/release-notes/v0.31.0.md) · **English**

> Released: 2026-08-08

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.31.0/CHANGELOG.md#0310---2026-08-08) for the full list.

This release goes after two everyday annoyances. First, once you have a lot of sessions the sidebar stops telling you anything useful — now hovering one shows you which directory and branch it's on and how much has changed, without opening it, and the ones you keep coming back to can live in their own group at the top. Second, long replies were tiring to read: the assistant would generate, your question would get pushed up, and your eyes had to chase it. Now sending a message reserves about a screen for that turn first, so the reply grows downward and the part you're reading stays put.

## Added

- **Hover a session to see where it stands**: A detail card appears after a short delay with the title, time, project, working directory, model, and session type — plus that session's Git state, loaded on demand: worktree or local checkout, branch, files changed, lines added and removed, and any conflicts. You can pin or archive right from the card, and it's fully keyboard-accessible with Escape to dismiss. Deciding "can I pick this one back up?" no longer means opening it.
- **Pin the sessions you keep returning to**: Pinned sessions collect into their own group at the top of the sidebar (which stays out of the way when nothing is pinned), gathering across projects, regular chats, channels, and subagents, and leaving their original group so nothing shows up twice. Pinning takes effect immediately and rolls back on its own if it fails.
- **Pause, resume, and cancel now behave the same everywhere**: Subagents, background jobs, processes, teams, workflows, and scheduled tasks share one set of control semantics that clearly separate "request received", "already finished", and "refused". A cancel request could previously be reported back as "completed" — it no longer is. Background activity is also grouped into a more readable summary, and handled messages can be collapsed.
- **Tools from large MCP servers are easier to find**: You can now search within one specific MCP server instead of having its tools mixed in with the built-ins and every other server — the difference grows with the server. Settings now opens straight from a server's row and shows the connection and timeout values actually in effect, and there's one place to adjust the tool-loading strategy. Tool names keep more of their length, and previously shortened names still work.

## Changed

- **Sending a message no longer moves what you're reading**: Sending now reserves close to a screen for that turn and holds your message near the top, with the reply unfolding below it. Short replies no longer push your question upward as they stream; replies longer than a screen still follow the bottom as before. Scrolling through and searching history behaves as it did.
- **Answered questions stay auditable**: Expanding an answered prompt shows the original question, the context it came with, each option's description and any recommended marker, and what you actually picked or typed. Collapsed, it's still a one-line summary, and timeouts are still called out.

## Fixed

- **Model-fallback notices in history no longer render as raw JSON**: Re-expanding the collapsed section of a finished conversation now shows the model-fallback event properly.

## Upgrade notes

No configuration migration in this release — just update.

The pinned group only appears once you actually pin something, so your sidebar looks the same right after updating.

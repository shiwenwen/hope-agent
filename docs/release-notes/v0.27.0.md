# Hope Agent 0.27.0 — 镜像分发与请求恢复

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.27.0/docs/release-notes/v0.27.0.en.md)

> 发布日期：2026-07-31

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.27.0/CHANGELOG.md#0270---2026-07-31)。

v0.27.0 的主线是「装得上、跑得下去」。安装包与自动更新从此多一份 Cloudflare R2 镜像，不再必须能访问 GitHub；模型请求撞上限流、过载或超时时，会自己一路重试、换 Key、降级模型地找回来，并把过程显示成可以中途接管的进度，而不是一句报错就停在那里。macOS 那条「点了授权却什么都没发生」的权限链路也修好了。

## 新增

- **安装包与自动更新新增 Cloudflare R2 镜像，不再必须能访问 GitHub**：所有平台的安装包现在会同时发布到 `https://repo.hopeagent.ai/download/`（和 apt / dnf 软件源同一个域名），README 里每个手动下载入口都给了固定的镜像直链，历史版本按版本号长期保留、不会被新版顶掉。桌面端的自动更新也改成优先读镜像、GitHub 兜底——此前访问不了 GitHub 的用户既装不上也更新不了。自动更新下载的安装包一律经内置公钥验签，镜像与 GitHub 走的是完全相同的校验，所以就算镜像被篡改，也没法通过自动更新把非官方构建装进来。手动下载的安装包由系统安装，不经这道验签——这一点镜像与 GitHub 相同。
- **Agent 设置页支持一键恢复默认值**：Agent 标签页（模型、子 Agent、审批）以及「工具」「技能」两个能力子页，各自新增了「恢复默认值」。二次确认后，当前页会恢复成随版本内置的默认配置，但结果先落成草稿供你检查，点保存才真正生效。服务商与凭据、记忆、知识空间、任务与产物都不受影响。

## 变更

- **模型请求失败后会持续恢复并显示可控进度**：限流、过载、超时与未知错误会按用途做有界重试，再依次轮换同一服务商下可用的 Key、降级到备用模型，并在超时或未知故障耗尽整条模型链之后再额外试一轮；鉴权、计费、模型不存在这类确定性错误仍然快速跳过、不做无意义的重试。主对话与 IM 会显示重试、Key 轮换、模型降级和整链恢复的提示，桌面 / Web 的提示卡上带倒计时、立即重试和切换模型。工具一旦开始执行就不会再重启同一模型或整条模型链；并发安全的只读工具仍可以切到本轮还没试过的下一个模型，而可能改动外部状态的工具会停下全部自动重放。
- **添加已有项目时可选择是否创建 AGENTS.md**：所选目录里没有项目指令文件时，会显示一个默认开启的创建选项；关掉它就只添加项目，之后保存、只读查看、重启迁移或普通的元数据编辑都不会再静默补建。项目指令保存时还会校验读取时的文件存在状态与内容 hash，外部创建、删除或修改都能挡住陈旧草稿覆盖。
- **「关于」页面改为介绍当前实际能力**：开场与结尾文案重写，原先那三项亮点换成执行、记忆与知识、设计交付、长时跨端协作四个能力方向，并改成两列布局——Goal / Workflow、多 Agent 协作、知识空间、设计空间、定时任务与 ACP 不再缺席。12 种语言同步更新。更新检查与更新行为不变。
- **`@skill` 提及改为轻量行内样式**：去掉了背景块、边框、圆角和阴影，改用图标加彩色标签的行内排版，输入框与已发送消息保持一致；同时改按标签文字的真实基线对齐，提及后面接着输入的文字不再上下错位。浏览器控制类用 Chrome 蓝，Mac 控制类用系统前景色。
- **运行中的微光动画放慢**：共享的文字微光扫描周期从 2.5 秒放慢到 4 秒，桌面宠物气泡与对话列表里的运行中状态同步变化，不再频繁扫过分散注意力。

## 修复

- **macOS 系统权限授权闭环修复**：「辅助功能」点击授权现在会真正触发系统弹窗，并把 Hope Agent 注册进系统设置的列表里——此前跳转过去，列表里根本没有条目可开。录屏权限现在能识别「系统设置已开启、待重启应用生效」这个中间状态并显示专属提示，不再一直误报未授权；录屏与输入监控授权失败时也会给出排障提示。
- **系统权限面板可一键重置失效的授权记录**：辅助功能、屏幕录制、输入监控在未授权状态下新增了「重置记录」，二次确认后会清除 macOS 保存的授权决定并提供重启入口，之后重新授权即可，不用再手敲 `tccutil`。这条专治「系统设置里显示已允许、应用却始终报告未授权」——通常是旧版本留下的残留记录。已经授权的项不显示该操作，避免误删有效授权。
- **修复桌面端流式语音输入被 CSP 拦截**：PCM16 AudioWorklet 改为从同源静态资源加载，不再依赖被 Tauri `script-src` 禁止的 Blob URL；采集启动失败、运行中出错、用户取消以及组件卸载时，都会同步清理后端的 STT 会话，麦克风权限错误也统一了提示。
- **修复 Markdown 外链图标需悬停后才加载站点 favicon**：网页链接进入视口附近时就会自动加载站点图标，不用先把鼠标移上去或聚焦；屏幕外的历史消息保持懒加载，请求仍然复用现有的缓存、并发与数量限制，加载失败时继续显示网页占位图标。
- **修复离开记忆 claims 页面会被弹回设置**：从 claims 页切到主对话、数据大盘这类一级页面时，URL 里残留的 `#memory/...` 定位状态会被清掉，不再被重新当成一条新的深链而把你跳回「设置 → 记忆 → claims」。首次通过深链进入记忆页仍然正常。
- **修复标题栏面板角标被裁切**：后台任务与 Agent 面板按钮上的运行数角标，不再被横向滚动区域的边界切掉一角。

## 升级提示

本版没有配置迁移，也没有破坏兼容性的改动，直接更新即可。

**关于镜像，有一处时序要说明**：更新检查的端点是编译进二进制的，所以你现在这台 0.26.0 及更早版本的应用，这一次仍然只会去 GitHub 查更新。如果你访问不了 GitHub，请先从 README 的镜像直链手动下载 0.27.0 安装包覆盖安装；装上之后，往后的每次自动更新才会优先走镜像。

Agent 设置的「恢复默认值」恢复的是**当前版本内置的默认配置**，不是你上次保存的值；恢复后先看草稿、确认没问题再点保存，中途反悔直接离开即可。

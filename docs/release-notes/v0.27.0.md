# Hope Agent 0.27.0 — 镜像分发与请求恢复

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.27.0/docs/release-notes/v0.27.0.en.md)

> 发布日期：2026-07-31

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.27.0/CHANGELOG.md#0270---2026-07-31)。

这一版围绕「装得上、跑得下去」。安装包和自动更新多了一个国内可达的镜像地址，访问不了 GitHub 也不再被卡住；模型请求撞上限流或超时时会自己重试、换 Key、降级模型地救回来，而不是一句报错就停在那；macOS 上「点了授权却什么都没发生」也修好了。

## 新增

- **安装包和自动更新多了一个镜像地址，访问不了 GitHub 也能装、能更新**：所有平台的安装包会同时发布到 `https://repo.hopeagent.ai/download/`，README 上每个下载入口都给了镜像直链。桌面端检查更新时优先走镜像，不通再回 GitHub。历史版本长期保留，旧版本的下载链接不会因为发了新版而失效。自动更新仍然校验官方签名，用镜像不会降低这一点。
- **Agent 设置支持一键恢复默认值**：Agent 标签页，以及「工具」「技能」两个子页，各多了一个「恢复默认值」。点了之后先给你一份草稿，确认没问题再点保存才生效。服务商与密钥、记忆、知识空间、任务和产物都不会被动到。

## 变更

- **模型请求失败后会自己救回来，你也能随时接管**：遇到限流、过载或超时，会自动重试、换用同一服务商下的其它 Key、必要时降级到备用模型，主对话和 IM 里都能看到当前正在做什么。提示卡上有倒计时、「立即重试」和「切换模型」。鉴权失败、余额不足这类重试也没用的错误会直接报出来，不浪费你的时间。已经开始执行工具的那一轮不会被自动重放，避免同一个操作做两遍。
- **添加已有项目时可以选择不创建 AGENTS.md**：所选目录里没有项目指令文件时，会问你要不要创建，默认创建。关掉就只添加项目，之后也不会再在别的时机悄悄补上。
- **「关于」页面重写**：换成执行、记忆与知识、设计交付、长时跨端协作四个方向，补上了 Goal / Workflow、多 Agent 协作、知识空间、设计空间、定时任务和 ACP。12 种语言同步更新。
- **`@skill` 提及变轻了**：去掉背景块、边框和阴影，改成图标加彩色文字，和正文更协调；提及后面接着打的字也不会再上下错位。
- **运行中的微光动画放慢了**：扫描周期从 2.5 秒改成 4 秒，不再频繁闪动分散注意力。

## 修复

- **修复 macOS 点了「授权」却什么都没发生**：「辅助功能」现在会真正弹出系统授权框，并把 Hope Agent 加进系统设置的列表里——以前跳过去，列表里根本没有条目可开。录屏权限如果你已经在系统设置里打开、但还没重启应用，现在会明确提示「重启后生效」，不再一直显示未授权。
- **权限授权卡住时可以一键重置**：辅助功能、屏幕录制、输入监控在未授权状态下多了「重置记录」，确认后清掉 macOS 记住的旧决定，再授权一次就好，不用去敲 `tccutil` 命令。专治「系统设置里明明写着允许，应用却说没授权」——通常是旧版本留下的记录。已经正常授权的项不显示这个操作，不会误删。
- **修复桌面端语音输入无法启动**：实时语音输入在桌面版被安全策略挡住、录不了音，现在恢复正常。启动失败、中途出错或你手动取消时，后台的识别会话也会一并结束，麦克风权限的报错提示也统一了。
- **修复网页链接的图标要把鼠标移上去才显示**：消息里的网页链接快滚到时就会自动加载对方网站的图标。
- **修复从记忆页面离开会被弹回去**：在「设置 → 记忆」里看过 claims 之后，切到主对话或数据大盘，不会再被自动跳回记忆页。
- **修复标题栏按钮上的数字角标缺一角**：后台任务和 Agent 面板按钮上的运行数量角标现在完整显示。

## 升级提示

本版没有配置迁移，也没有破坏兼容性的改动，直接更新即可。

**镜像这一次还用不上**：你现在这台 0.26.0 或更早的版本，这次检查更新仍然只会去 GitHub。如果你访问不了 GitHub，请先从 README 上的镜像链接手动下载 0.27.0 装上，之后的每次更新才会优先走镜像。

Agent 设置里的「恢复默认值」恢复的是**这个版本自带的默认配置**，不是你上次保存的值。恢复之后先看草稿，确认没问题再点保存；反悔的话直接离开页面就行。

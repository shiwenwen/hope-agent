## 可选工具参数不再被错误补齐

通过 OpenAI Responses 接口或兼容服务使用工具时，Hope Agent 现在会保留可选参数的省略语义。像“永不超时”这类本来不需要附带秒数的操作，不会再被服务端自动补入冲突值而失败。

这项修复适用于内置工具及使用同一调用方式的其他函数工具，不需要修改现有 Provider 配置。

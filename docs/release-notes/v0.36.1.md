# Hope Agent 0.36.1 — 修复部分升级用户无法启动

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.36.1/docs/release-notes/v0.36.1.en.md)

> 发布日期：2026-08-26

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.36.1/CHANGELOG.md#0361---2026-08-26)。

这是一个紧急修复版本，解决部分使用较早版本的用户更新后，Hope Agent 图标持续跳动但主窗口无法打开的问题。

## 修复

- **旧数据库可以自动恢复**：启动时会清理此前升级失败留下的异常状态，再安全完成必要迁移。
- **保留现有数据**：修复过程不会删除已有会话、消息或工作树记录。
- **不受影响的用户可正常更新**：已经完成迁移或使用新数据库的安装不会发生额外变化。

## 升级提示

直接更新并重新打开 Hope Agent 即可。遇到启动失败的用户不需要删除 `sessions.db`，也不需要清空应用数据。

# Hope Agent 0.71.0 — New image and transcription presets, fewer configuration mishaps

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.71.0/docs/release-notes/v0.71.0.md) · **English**

> Release date: October 30, 2026

> See the [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.71.0/CHANGELOG.md#0710---2026-10-30) for the full list of changes.

## More aspect ratios when adding an image provider

New Google image providers in Settings prefer Nano Banana 2.1, with wider and taller aspect ratios. The image tool and Agent image-artifact generation accept up to 14 reference images; the Design home composer still accepts up to 5. Existing models and default chains are not changed automatically. The current integration does not support mask editing or video/PDF inputs. Actual image quality and billing for the new model have not been validated.

## Choose a transcription preset for your recording workflow

New xAI speech-recognition providers start with Grok Voice Transcribe 2.0 for record-then-transcribe input. New AssemblyAI providers prefer Universal-3.6 Pro Streaming for streaming transcription. You decide whether to replace existing configurations; AssemblyAI still cannot serve as the IM auto-transcription fallback. Actual recognition accuracy and billing for the new models have not been validated.

## Keep your draft while entering model parameters

When adding or editing a provider, accidentally clicking outside Discover models no longer closes the dialog or loses the parameters you entered. Choose Add when ready, or use Cancel, the close button, or Esc to exit. You still need to save the provider before the additions take effect.

## Share less sensitive information during Feishu troubleshooting

If Feishu cannot obtain an access token, the error shows only the status or service error code. Share that code when troubleshooting, without copying your App Secret or access token. This fix covers errors during token retrieval; other Feishu interfaces still require separate validation.

Upgrade note: existing image and transcription configurations are not migrated automatically. Review models and pricing manually in Settings as needed. See the [models and providers guide](https://github.com/shiwenwen/hope-agent/blob/v0.71.0/docs/user-guide/en/02-models-and-providers.md).

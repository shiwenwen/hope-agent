# Hope Agent 0.36.0 — 多入口对话执行更一致

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.36.0/docs/release-notes/v0.36.0.en.md)

> 发布日期：2026-08-26

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.36.0/CHANGELOG.md#0360---2026-08-26)。

这一版专注于对话执行的可靠性。无论请求来自桌面、Server、ACP、IM、定时任务还是子 Agent，Hope 现在都通过同一套执行生命周期处理开始、停止、恢复、持久化与完成状态，减少不同入口在异常恢复时出现不一致结果。

## 变更与修复

- **停止与完成状态更一致**：不同运行模式使用同一套轮次边界，停止请求、失败收敛和最终状态不再各走一套容易漂移的路径。
- **跨入口恢复更可靠**：需要持久化或在进程切换后继续处理的请求，共享相同的准入与完成规则，降低重复执行或状态遗失的风险。
- **桌面之外的入口与主对话保持一致**：Server、ACP、IM、定时任务和子 Agent 的请求采用与桌面主对话相同的核心执行约束。

## 升级提示

直接更新即可；无需迁移数据或调整设置。

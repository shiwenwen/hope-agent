# Hope Agent 0.52.0 — Reference existing conversations with more reliable connections

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.52.0/docs/release-notes/v0.52.0.md) · **English**

> Released: September 22, 2026

> See the [changelog](https://github.com/shiwenwen/hope-agent/blob/v0.52.0/CHANGELOG.md#0520---2026-09-22) for the complete list of changes.

## Bring an existing conversation into a new task

Type `@` in the composer to search for and select an existing regular conversation. Hope Agent can then read that conversation's context or send work to it when you ask. This works in the main chat, quick chat, and side chat.

## Keep reasoning out when Think is off

When Think is disabled, reasoning text returned by a compatible service is no longer shown or saved. The tool-result disk persistence setting, which is not currently available, can no longer appear adjustable and imply that full persistence has been enabled.

## Use external connections and model presets more reliably

MCP protocol negotiation, reauthorization, and sign-out are more dependable, while ACP connections stop more clearly when a permission request is cancelled. Web search redirects continue to respect network-access restrictions.

The direct DeepSeek preset now uses the image-capable `deepseek-flash` model and sends thinking levels according to the service's supported options. The retiring Fireworks Kimi K2.6 preset is no longer offered for new connections; existing custom configurations are unchanged.

Discord attachments are checked against the 20 MiB limit and continue to use the existing link fallback when they are larger.

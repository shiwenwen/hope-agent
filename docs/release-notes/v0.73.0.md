# Hope Agent v0.73.0

## 一个持续保留的个人助手

侧栏新增「个人助手」。在同一段私人对话里查找已有工作会话、把多件事分别交办，再继续聊新的事情。交办面板显示各项实际进展、结果和待处理事项，并能取消单项或打开原会话。也可以明确要求继续已暂停的工作会话，或关注已有目标的新阻塞和待验收变化。中断的普通任务不会自动重做，需要时请另行交办。

助手运行期间，工作可在后台推进；持续在线需要桌面应用保持运行，或使用独立 Server。首期支持尚未连接工作 Bot 的本地普通会话。启用个人助手后，该服务的 Web 入口需要主人令牌；桌面仍可用于设置。个人助手历史暂不支持编辑重发；更正请发送新消息，用工作面板取消已交办事项。详见[对话与会话手册](https://github.com/shiwenwen/hope-agent/blob/v0.73.0/docs/user-guide/03-对话与会话.md)。

## 从 Telegram 私聊交办工作

在个人助手中连接一个独立的 Telegram Bot，完成本人私聊配对，再为每个工作会话分别允许查状态、派工和停止单项交办。原工作 Bot 继续处理原有项目，搜索时不再显示个人助手的私人工作。手机只显示获准的状态；工作正文、私人主对话、审批和问答留在 HA 中。

通过这个 Bot 交办的工作可单独开启完成提醒，按个人资料中的有效时区在 22:00–08:00 静默，每天最多两次。未设置有效时区时，不会主动发送；可在 HA 查看状态。使用独立 Server 时，请将桌面和 Server 一起更新到本版。

## 长对话与消息兼容

长对话的摘要在条件允许时沿用当前会话的模型和推理设置；已单独配置的摘要模型继续生效。修复 Hetzner 与 OVHcloud 部分模型无法开始新对话的问题，并修正 QQ 审批和问答按钮的显示兼容性。

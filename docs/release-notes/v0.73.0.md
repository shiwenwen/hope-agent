# Hope Agent v0.73.0

## 桌面兼容维护

本版更新桌面通知与相关依赖，保留现有通知设置和深链打开方式。无需重新配置；本次维护不新增操作入口。

## 自动更新验证维护

服务端与桌面端统一签名验证依赖，继续要求更新包通过验证后才安装。已有更新设置和安装确认方式保持不变；这次维护不表示旧版存在已确认的签名绕过问题，也不代表已完成真实设备安装回归。

# Hope Agent 0.32.0 — Type your way, and actually stop long-running work

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.32.0/docs/release-notes/v0.32.0.md) · **English**

> Released: 2026-08-12

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.32.0/CHANGELOG.md#0320---2026-08-12) for the full list.

This release gives you more control over two things you do constantly. While writing, you can choose whether Enter sends or inserts a new line. During a long-running task, Stop now keeps the remaining work stopped even if you close and reopen the app. When you're ready, just send “continue” and the agent resumes from that exact pause instead of repeating steps it already finished.

Complex conversations also make more reliable use of each model's context capacity, `@` mentions stay consistent from composition through history, and a damaged old configuration backup can no longer block startup.

## Added

- **Choose the send shortcut that fits how you write**: Under Settings → Chat & Context → Basics, keep the default Enter to send and Shift+Enter for a new line, or switch to Enter for a new line and Ctrl+Enter to send. The main window, QuickChat, and remote connections share the same preference. Updating does not change the default.

## Changed

- **Long-running work stays paused after Stop**: Goals, workflows, subagents, and scheduled wakeups stop at the same point and do not silently come back after an app restart. Send “continue” when you want to resume the unfinished work attached to that pause; completed steps are not blindly replayed. If a subagent hits a temporary provider outage, its recovery progress is also visible in the parent conversation so you can decide whether to wait or stop.
- **Complex conversations are less likely to compact too early or hit a capacity error**: When Chinese text, emoji, images, large files, and many tools appear together, Hope Agent can plan the request around the model actually in use. Long chats keep more useful material, while requests near the boundary are handled earlier and more safely.
- **Every `@` mention now uses one lightweight inline style**: Files, notes, skills, agents, plans, plugins, and connectors look consistent while composing and after sending, with clearer keyboard and focus behavior. Reopening history preserves the mention instead of flattening it into ordinary text. File mentions stay attached to the workspace where you selected them, so changing projects or sessions cannot silently redirect a relative path.
- **Project conversations know exactly which project they belong to**: The agent receives an explicit project identity, helping project-scoped tools and automations target the right place when you have several projects or similar directories.

## Fixed

- **A damaged old configuration backup no longer blocks startup**: If an upgrade encounters a historical backup it cannot read, Hope Agent safely isolates it and continues with the valid configuration. Configuration saves are also more resilient to crashes, power loss, and concurrent app processes, so a half-written file is not treated as valid.
- **Image capability failures now point to an actionable model setting**: If the active model cannot inspect an image, Hope Agent guides you to configure a vision model instead of leaving you with an opaque capability error.

## Upgrade notes

Update normally; no manual configuration migration is required.

Enter still sends by default. It only becomes a new-line key after you change the setting.

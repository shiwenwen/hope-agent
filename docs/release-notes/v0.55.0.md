> 完整改动列表见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.55.0/CHANGELOG.md#0550---2026-09-26)。

## 从会话侧栏导入 Codex 对话

现在可以从会话侧栏导入运行 Hope Agent 的机器上保存的 Codex 对话。导入后可以搜索、查看和导出这些记录；再次导入会更新同一来源的记录，不会反复创建副本。导入的对话保持只读，不能作为新对话继续。

## 使用 Requesty 连接更多模型

添加服务商时可以直接选择 Requesty，填写 API Key 后选择其托管路由策略，或输入自定义模型 ID。使用欧洲路由的用户也可以自行设置对应的服务地址。

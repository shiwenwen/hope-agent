# Hope Agent 0.63.0 — 免费搜索与记忆写作偏好

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.63.0/docs/release-notes/v0.63.0.en.md)

> 发布日期：2026 年 10 月 6 日

> 完整改动列表见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.63.0/CHANGELOG.md#0630---2026-10-06)。

## 不用申请 Key，也能查网页资料

新安装默认启用免费多引擎搜索，无需 API Key 或额外安装。Brave 网页搜索不可用时会尝试 360 网页搜索，再尝试其他已启用的服务。免费入口仍可能受限流、网络限制或页面变化影响，不能保证每次成功；使用时效筛选时会跳过 360 网页搜索。

升级保留已有搜索顺序和关闭选择。要优先使用新选项，打开「设置 → 网页搜索」，启用「免费多引擎搜索」并拖到第一位。运行 `hope-agent server setup` 时也可以直接选择它，无需填写凭据。

## 让记忆按你的偏好写

在「设置 → 记忆 → 记忆设置」中，可以分别为对话提取、手动画像整理和 Dreaming 选择系统默认、精简或详细风格，并补充写作要求。Agent 的记忆设置可以覆盖全局偏好。原有记忆与隐私开关保持生效；写作偏好不会自动开启已关闭的记忆功能。

## 连接与设置更清楚

OpenViking 导出只有在后台处理明确完成后才显示成功；未确认的写入会保持待核对状态。iMessage 健康诊断会提示过旧的 imsg 版本，无法判断版本时显示未核验，需要你手动决定是否升级。新建模型列表也已精简，已保存的服务商和模型配置保持不变。

本版包含原计划在 0.62.0 发布的搜索功能。0.62.0 因发布构建失败未公开发布，请直接使用 0.63.0。

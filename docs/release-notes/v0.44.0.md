# Hope Agent 0.44.0 — 自定义模型快速补全

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.44.0/docs/release-notes/v0.44.0.en.md)

> 发布日期：2026-09-06

> 完整变更见 [更新日志](https://github.com/shiwenwen/hope-agent/blob/v0.44.0/CHANGELOG.md#0440---2026-09-06)。

添加或编辑自定义模型时，现在可以输入模型名称、模型 ID 或服务商名称，从内置目录中搜索并选择模型，自动填写上下文长度、图片输入和推理等能力，减少逐项查找与填写。也可以继续手动调整。

选择后保留你当前服务商的连接设置。若目录报价与你填写的价格不同，且币种一致，可以先查看来源和单价，再决定保留原价还是使用目录价格；不同币种的报价不会直接覆盖。

搜索建议来自内置目录，并不代表你的服务商一定提供该模型。使用中转服务时，请核对建议来源，并按服务商实际支持的模型 ID、能力和收费调整。

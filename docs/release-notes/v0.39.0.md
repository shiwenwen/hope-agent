# Hope Agent 0.39.0 — 顺着消息，在对话之间往返

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.39.0/docs/release-notes/v0.39.0.en.md)

> 发布日期：2026-09-01

> 完整变更见 [更新日志](https://github.com/shiwenwen/hope-agent/blob/v0.39.0/CHANGELOG.md#0390---2026-09-01)。

让 AI 把消息发到另一段对话后，你现在可以直接跟过去查看，也能从收到的消息回到来源，继续追踪前因后果。

## 直接打开消息所在的对话

- **从发送记录跟进结果**：点击发送回执即可打开目标对话并定位到那条消息，不必再去列表里逐个查找。
- **从收到的消息追溯来源**：点击来源入口即可返回发送方；如果消息来自侧聊，会同时打开所属主对话与对应侧聊面板。
- **在独立窗口里也能跳转**：从快捷聊天等独立窗口点击链接，会转到主窗口查看。消息已经送达但后续回答被停止时，发送记录与跳转入口仍会保留。

## 登录与模型设置提醒

登录信息未能保存时，应用会提示失败，避免显示登录成功后却无法继续使用。新建 Cloudflare 连接的默认配置得到修正，Copilot 默认候选移除了退役模型，部分模型的预设价格与思考强度选项也已调整。

已有服务商配置不会被自动覆盖。如果你之前手工配置过这些服务商，请在设置中检查连接、模型名称与单价。

## 首次使用本地模型

所有平台都需先从官网下载并手工安装 Ollama，再返回 Hope Agent 刷新状态、下载模型。已安装 Ollama 的用户可以继续使用；模型下载与注册仍可在应用内完成。

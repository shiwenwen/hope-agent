# Hope Agent 0.59.0 — 新模型与更顺畅的继续对话

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.59.0/docs/release-notes/v0.59.0.en.md)

> 发布日期：2026 年 10 月 1 日

> 完整改动列表见 [CHANGELOG](https://github.com/shiwenwen/hope-agent/blob/v0.59.0/CHANGELOG.md#0590---2026-10-01)。

## 选择新的 OpenAI 与 Claude 模型

在模型目录中搜索 GPT-6.1 Sol、GPT-6 Sol/Luna 或 Claude Opus/Sonnet 5.5，即可选择相应预设并开始对话。使用前请确认你的服务商账户已开通所选模型。

Together AI 已下线的 Kimi K2.6 Serverless 预设已从目录移除；使用该服务的用户可选择其他可用模型。

## 停止回复后继续提问

使用 OpenAI Chat 兼容模型时，即使上一条回复在生成内容前被停止，也可以继续在原会话中提问，无需新建会话。

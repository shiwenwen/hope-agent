## 直接询问中文城市的天气

现在可以直接问“北京今天天气怎么样”或“上海明天会下雨吗”，无需先把城市名改成英文。查询多个城市时，天气服务缺少某个地点的国家名称也不会让整次查询失败。

## 更方便地了解 Hope Agent

项目首页默认展示英文说明，并提供完整中文文档入口。更新后的对话、知识空间、设计空间和用量大盘截图，方便你了解各个功能适合哪些任务。

# Hope Agent 0.31.0 — 会话列表看得清，长回复读得稳

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.31.0/docs/release-notes/v0.31.0.en.md)

> 发布日期：2026-08-08

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.31.0/CHANGELOG.md#0310---2026-08-08)。

这一版集中在两处日常摩擦。一是会话多了以后侧栏难认：现在鼠标停一下就能看到这条会话在哪个目录、哪个分支、改了多少文件，不用点进去；常用的会话也能置顶到单独一组。二是长回复读起来累：以前助手一边生成，你的问题就一边被顶上去，视线得跟着跑；现在发完消息会先给这一轮留出一屏空间，回复往下长，你要看的地方不动。

## 新增

- **鼠标停在会话上就能看到它的来龙去脉**：延迟弹出的详情卡里有标题、时间、所属项目、工作目录、模型和会话类型，还会按需读取这条会话的 Git 状态——是 worktree 还是本地 checkout、在哪个分支、改了几个文件、增删多少行、有没有冲突。卡片里可以直接置顶或归档，也支持键盘操作和 Escape 关掉。判断「这条会话现在能不能接着干」不用再点进去了。
- **常用会话可以置顶到单独一组**：置顶的会话集中到侧栏最上方的独立分组（没有置顶时不占位置），跨项目、普通、频道和子 Agent 一起汇总，并从原来的分组里移走，不会看到两遍。点了立刻生效，失败会自动退回原状。
- **暂停、恢复、取消现在对所有后台运行都一致**：子 Agent、后台任务、进程、团队、工作流和定时任务共用同一套控制语义，能清楚区分「请求已收到」「已经结束了」和「这次被拒绝」。以前取消请求有可能被报成「已完成」，现在不会了。同时后台运行的活动会聚合成一条更好读的展示，处理完的消息可以折叠起来。
- **大型 MCP 服务的工具更容易被找到**：可以只在指定的某个 MCP 服务里搜工具，不再和内置工具、其它服务混在一起——服务越大越明显。设置里现在能从服务那一行直接进去，看到真正生效的连接与超时配置，也能统一调整工具加载策略。工具名能保留得更完整，之前被截短的名字仍然照常可用。

## 变更

- **发完消息，阅读焦点不再被顶走**：发送后会为这一轮先留出接近一屏的空间，把你的消息固定在靠近顶部的位置，回复在下方展开。短回复不会再一边生成一边把你的问题往上推；超过一屏的长回复仍然照常跟着底部走。翻历史、搜历史的滚动行为不变。
- **回答过的提问，事后能看清当时发生了什么**：展开已回答的提问卡，能看到原问题、当时的上下文、每个选项的说明和推荐标记，以及你最后选了哪个或输入了什么。折叠状态仍然只显示一行摘要，超时的情况照常标出。

## 修复

- **历史里的模型降级提示不再显示成一段 JSON**：已结束的对话重新展开折叠区时，模型降级事件会正常显示。

## 升级提示

本版无配置迁移，直接更新即可。

会话置顶分组只在你有置顶会话时才出现，升级后不会改变现有侧栏布局。

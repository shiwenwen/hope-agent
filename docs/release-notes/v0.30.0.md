# Hope Agent 0.30.0 — IM 里的原生回复、Nori，和 `/fork`

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.30.0/docs/release-notes/v0.30.0.en.md)

> 发布日期：2026-08-07

> 详见 [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.30.0/CHANGELOG.md#0300---2026-08-07)。

这一版主要花在两件事上：让 Slack 和 Telegram 里的 Hope Agent 看起来像个正经的原生机器人，而不是一串刷屏的纯文本；以及让你在一条对话走到岔路口时，不用在「毁掉现在这条」和「从头再来」之间二选一——`/fork` 复制一份接着聊就行。桌面端换了新的内置宠物 Nori，远程连服务器的场景也终于能提示服务端更新了。

## 新增

- **`/fork`：把当前对话复制一份，在副本里接着聊**：聊到一半想换个方向试试，又舍不得现在这条对话，输入 `/fork` 就能把已经聊完的部分整段复制成一条新会话，然后在新的那条里继续。原来那条原封不动留着，随时可以回去。桌面、网页、快捷聊天、设计对话和 IM 都会自动切到复制出来的新会话；万一 IM 那边没切成功，会告诉你用 `/session` 手动切，复制出来的会话不会丢。
- **Slack 与 Telegram 用上平台原生的回复样式**：生成过程中会一直更新同一条消息，不再一段一段刷屏。Slack 里能直接看到计划、任务进度和可以点的按钮；Telegram 支持富文本、图片和按钮。碰上平台确实不支持的样式会安全退回普通文本；投递结果不确定的时候宁可不补发，也不会让你收到两条一样的。
- **远程连过去也能提示服务端更新**：用浏览器或远程桌面连到一台跑着 Hope Agent 的机器时，现在能看到那台服务的更新状态、手动检查更新、确认安装并看到进度。要不要弹提示、允不允许检查，都听那台服务端自己的配置。关于页里的手动检查入口保留。

## 变更

- **内置桌面宠物换成了 Nori**：空闲时会跟着鼠标看，跳跃、奔跑和「审阅」这几个动作也重做了。如果你之前选的就是内置宠物，升级后会直接变成 Nori，不需要重新设置。
- **新建宠物默认用新一代画法**：新建出来的宠物会跟着光标转头看，动作也更连贯；如果你需要老版本的画法，创建时仍然可以显式选。宠物库里已有的老宠物可以一键生成一份新版副本——**原来那只不会被动过**，副本装好之后再切过去，你也可以继续用老的或把它导出。

## 修复

- **MCP 的工具在新会话里调不出来，修好了**：设置页里测试连接是通的、动态工具也看得见，但一开新会话，模型就只拿得到资源和提示词，实际的工具怎么都用不上。现在设置里多了三档工具加载策略可选，按需启动的服务器也不用再陷入「得先知道工具名才搜得到」的死结。
- **IM 忙的时候发消息，不会再收不到回复**：一条 IM 消息发过来时，如果它绑定的会话正在回上一条，这条消息不再被当成「忙碌」丢掉，而是排队按你发送的顺序逐条处理，每条都会得到回复。应用重启也不会丢掉排队的消息。如果你中途手动停了当前这轮，排队的消息会保留下来，等**下一条 IM 消息到达时**按原顺序接着处理——停止之后不会自己往下跑，需要再来一条消息把它唤醒。

## 升级提示

本版无配置迁移，直接更新即可。

内置宠物换成 Nori 是自动生效的。想换回别的，去设置里的宠物库重新选。

# Hope Agent 0.35.0 — More reliable web reading and complete design handoff

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.35.0/docs/release-notes/v0.35.0.md) · **English**

> Released: 2026-08-23

> See [`CHANGELOG.md`](https://github.com/shiwenwen/hope-agent/blob/v0.35.0/CHANGELOG.md#0350---2026-08-23) for the full list.

This release strengthens two workflows that often require repeated checking. When an agent reads a long web page, it now continues from the same captured page instead of silently switching to newer content halfway through. Design Space now goes beyond generating a screen: it can maintain scenarios, compare fixed viewports, publish a component manifest, and round-trip through Figma with an explicit confirmation step.

External connections are also easier to diagnose before work begins. Settings now explains compatibility and blocking conditions for external Memory, IM channels, ACP backends, and local tooling, instead of leaving those failures to surface halfway through a task.

## Added

- **Long web pages can be read consistently from start to finish**: The first read creates an immutable snapshot, and later reads continue from that exact content. A page refresh does not invalidate an existing cursor. Sources also appear in the workbench so you can revisit what the turn actually used.
- **More web content works without manual conversion**: Regular and dynamically rendered pages, PDFs, JSON, XML, and common text encodings follow the appropriate reading path. Under Settings → Tools → Web Fetch, you can control content budgets, cache duration, and whether browser rendering is allowed; the AI can choose prefer-cache, live, or cache-only freshness for each read.
- **Design Space now covers a complete handoff flow**: Save preview scenarios and fixed viewports, run model-independent visual comparisons, scan a code repository into a component manifest, and publish a confirmed manifest for the team.
- **Figma roundtrips are previewed and confirmed one operation at a time**: Before Hope writes to Figma or imports a new version from Figma, it shows the planned operation. No external call happens until you confirm it. If the outcome is uncertain, Hope asks you to reconcile it first instead of risking a duplicate write.
- **Fixed-version reviews do not drift as the design changes**: Server mode can create seven-day view-only or commenting credentials pinned to the design version current at creation, and revoke them at any time.
- **An IM conversation can explicitly request one file**: An agent can ask for a PDF, TXT, or Markdown file. Supported channels provide a native upload entry, and the file is delivered only to the exact account, conversation, and session that requested it.
- **A new read-only toolchain diagnostic is available**: Settings can check whether the browser, Docker, and common development tools are present and supported without installing, upgrading, or reconfiguring them.

## Changed and fixed

- **External Memory connections are checked for compatibility first**: Settings distinguishes supported, unverified, and unsafe versions and provides a separate connection test. Configuration changes no longer retain a stale verdict.
- **IM compatibility fallbacks are explicit**: Telegram, Slack, iMessage, Google Chat, and Discord expose per-account controls for newer reply behavior. Signal and WhatsApp show the detected bridge version and block versions known to be unsafe.
- **Project hooks are trusted per workspace**: Trust is bound to the exact path and the configuration content approved at that time. File changes, directory moves, and symlink aliases do not silently inherit an old grant.
- **Sandbox images are immutable**: The default image is pinned by digest, and custom images must use `name@sha256:<digest>`, preventing the same tag from resolving to different contents over time.
- **The Chinese and English user guides cover recent features**: The workbench, multi-folder projects, agent-created conversations, selection quotes, HTML preview, compaction retry, and evaluation budgets are now documented in step with the app.

## Upgrade notes

Update directly. Most users do not need to migrate any data.

If you use any of these advanced configurations, check them once after updating:

- Change a custom Docker sandbox image to a full name containing its `@sha256` digest.
- Re-authorize each project or local Hook workspace under Settings → Hooks.
- A legacy ACP backend without distribution metadata remains blocked. Supply its package or product identifier in Settings; the version is optional.
- If you use external Memory, select “Test connection” in Settings once to confirm the compatibility status.

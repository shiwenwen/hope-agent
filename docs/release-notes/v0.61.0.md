## 先看视频，再选择适合自己的任务

项目首页新增三分钟产品导览。中文页面提供中文配音与字幕，英文页面提供英文配音与字幕，帮助你了解目标推进、工具执行、长期记忆、知识空间与设计空间可以如何配合使用。

视频使用真实 Hope Agent 组件与固定演示数据制作，展示的是示例工作流。两种语言的项目首页也都提供官网入口，方便继续了解产品。

# Hope Agent v0.73.0

## Desktop compatibility maintenance

This release updates desktop notification and related dependencies while retaining notification settings and deep-link handling. No reconfiguration is needed, and this maintenance adds no new controls.

## Update verification maintenance

Server and desktop updates now share the same signature verification dependency. Update packages must still pass verification before installation. Update settings and installation confirmation remain unchanged. This maintenance does not establish a signature bypass in older releases or completed installation regression on real devices.

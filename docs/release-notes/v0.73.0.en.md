# Hope Agent v0.73.0

## A personal assistant you can return to

Open Personal assistant in the sidebar to find existing work chats, delegate several tasks, and keep talking in one private conversation. The work panel shows each task's actual progress, result, and items needing attention. You can cancel an individual task or open its work chat, explicitly continue a paused work chat, and follow new blocked or awaiting-acceptance changes in an existing goal. Interrupted one-off tasks are not automatically rerun; delegate them again if needed.

Work can continue in the background while the application runs. Staying online requires the desktop app to remain running or a standalone Server. This first version supports local regular work chats that are not connected to a work Bot. Once Personal assistant is enabled, the service’s Web entry requires a Server Owner Token; the desktop app remains available for setup. Personal-assistant history cannot be edited and resent; send a new correction and cancel delegated work from the work panel. See the [chat and sessions guide](https://github.com/shiwenwen/hope-agent/blob/v0.73.0/docs/user-guide/en/03-chat-and-sessions.md).

## Delegate work from a Telegram private chat

Connect a separate Telegram Bot from Personal assistant, pair your private chat, and grant each work chat permissions to check status, delegate tasks, and stop an individual delegation. Existing work Bots continue serving their projects; their searches exclude the personal assistant’s private work. The phone receives authorized status only; work content, the private home conversation, approvals, and questions remain in HA.

Completion notifications are a separate opt-in for work delegated through this Bot. They stay quiet from 22:00 to 08:00 in the valid timezone from your profile and are limited to two per day. Without a valid timezone, proactive notifications are not sent; check the status in HA. Update both the desktop app and standalone Server to this version when using a remote Server.

## Long conversations and messaging compatibility

When supported, conversation summaries use the current chat's model and reasoning settings. A separately configured summary model still takes precedence. This release also fixes failures to start new chats with some Hetzner and OVHcloud models, and the display of QQ approval and question buttons.

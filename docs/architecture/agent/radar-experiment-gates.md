# 技术雷达受控实验门

本文登记 2026-08 已成功雷达报告中必须先做需求或证据验证、不能直接默认发布的项目。它是冻结范围的工程决策记录，不会触发报告补跑、真实 Provider 调用、外部写入或本机软件升级。

2026-08-31 已按最新主分支重新核对本表 8 张决策卡，门控保持不变。新增专项结果、逐卡缺口与统一计划见[行动卡台账](action-card-ledger.md)；“本周期完成”仍只指本表明确的工程决策，不表示实验已运行。

## 通用准入契约

实验只有同时具备以下字段并得到 owner 明确启动，才可从“关闭”转为“隔离实验”：

| 字段 | 强制要求 |
| --- | --- |
| 开关 | 独立、默认关闭；关闭后不注册入口、不启动后台任务、不残留 durable 状态 |
| 数据边界 | 只用合成或已授权脱敏数据；无痕、项目、Knowledge/Memory scope 与凭据边界不降级 |
| 成本上限 | 调用次数、token/费用、并发与墙钟时间均预先固定，超限自动终止 |
| 停止条件 | 成功门槛、失败门槛和最大样本数在运行前冻结，不能看结果后改口径 |
| 证据 | 确定性 fixture 与真实服务证据物理分离；失败、取消与未完成样本也保留 |
| 回滚 | 关闭开关即可回到现行路径；不得要求迁移本地真相源或清理外部生产数据才能回滚 |

真实服务实验仍需逐项确认账号、费用与外部副作用。没有确认时，“保持关闭并登记重新评估条件”就是该行动卡在本周期的完成状态。

## 不变量

- 实验不得改写 `injected/selected` 的既成 prompt 事实，不得把候选层结果用作权限裁决。
- MCP 远端任务、本地后台 Job、Subagent 队列和 Workflow 维持四个独立状态域。
- Offline Batch 永不承接前台聊天；A2A 永不开放公网入站执行。
- Teams 未过需求门前不新增内建 Provider、设置项、OAuth scope 或默认插件依赖。
- Design 不恢复无限画布、实时源码共编或无人确认的外部写入。
- 任何实验开关都不能替代统一权限引擎、SSRF 检查、工作区信任或凭据脱敏。
